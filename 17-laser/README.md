# 17-laser — 정밀가공 레이저 센서 이상탐지

KAMP **정밀가공 자원최적화 AI 데이터셋**으로 레이저 가공 센서 신호를 분석한 학습용 프로젝트입니다.
정상 조건과 레이저 초점을 일부러 바꾼 이상 조건의 신호를 비교하고, 시계열 윈도우 기반으로 이상을 찾아냅니다.

초보자가 한 단계씩 따라갈 수 있도록 **모든 셀에 왜 필요한지를 한국어로 설명**해 두었습니다.

## 데이터

| 파일 | 행 수 | 설명 |
|---|---|---|
| `data/normal.xlsx` | 92,280 | 정상 가공 조건에서 수집한 센서 기록 |
| `data/anomaly.xlsx` | 11,800 | 레이저 초점을 의도적으로 바꾼 조건의 센서 기록 |

컬럼은 `Time`, `Intensity`, `Current` 세 개입니다.

**한 행은 한 시점의 센서 측정값입니다.** 제품 한 개, 구멍 한 개, LOT 한 개가 아닙니다.
파일에 제품·구멍·LOT 식별자가 없으므로 그런 경계를 임의로 만들지 않습니다.
파일 이름의 라벨은 **정상 조건 / 이상 조건** 라벨이지, 이상 행 하나하나가 불량품을 증명하지는 않습니다.

> 원본 데이터와 가이드북 PDF는 저작권 때문에 저장소에 포함하지 않았습니다.
> [KAMP 인공지능 중소벤처 제조 플랫폼](https://www.kamp-ai.kr/)에서 *정밀가공 자원최적화 AI 데이터셋*을
> 내려받아 `data/` 폴더에 `normal.xlsx`, `anomaly.xlsx`로 넣으면 노트북이 그대로 돌아갑니다.

## 노트북 구성 (`1.ipynb`)

| 단계 | 내용 |
|---|---|
| 1 | 패키지와 데이터 불러오기 |
| 2 | EDA — 자료형·결측·중복, 시간 간격, 통계 비교, 분포·시계열 그래프, 센서 간 상관 |
| 3 | 전처리 — 1초 초과 공백 처리 원칙 정하기 |
| 4 | 모델링을 위한 윈도우 생성 |
| 5 | 윈도우·변수 조합의 검증 성능 비교 |
| 6 | 분류기 성능 개선 |
| 7 | 정상 중심 검출기 성능 개선 |
| 8 | 최종 홀드아웃 평가 |
| 9 | 어떤 변수가 이상 판단에 영향을 주었는가 |
| 10 | 공정 최적화 관점의 해석 |
| 11 | 최종 판단과 한계 |

각 단계마다 **계산 검증 셀**을 따로 두어, 앞에서 뽑은 숫자가 맞는지 다른 방법으로 다시 확인합니다.

## 분석 규칙

이 프로젝트에서 지키기로 한 원칙입니다.

- **시간 순서를 보존한다.** 시계열이므로 무작위 분할을 쓰지 않는다
- **윈도우를 만들기 전에 학습 구간과 평가 구간을 먼저 나눈다**
- 윈도우가 다음 경계를 절대 넘지 않게 한다
  - 정상 파일과 이상 파일 사이
  - 긴 시간 공백
  - 학습 / 평가 구간 경계
- **날짜와 파일 이름을 모델 입력으로 쓰지 않는다** (그대로 정답이 새어 들어간다)
- 원본 엑셀 파일은 수정하지 않는다
- 가이드북은 40개 연속 측정을 한 윈도우로 쓰고 정상 데이터로 LSTM 오토인코더를 학습한다.
  이는 **참고 절차**이지 40이 최적이라는 근거는 아니다

## 실행 환경

```bash
.venv\Scripts\activate
pip install -r requirements.txt

```
