## 2-1. 단어·글자·자모

같은 문장을 세 가지로 잘라 본다.

```python
review = "현실과 구분 불가능한 cg. 시각적 즐거음은 최고! 더불어 ost는 더더욱 최고!!"
```

**(1) 공백으로 자르기**

```python
tokenized = review.split()
# ['현실과', '구분', '불가능한', 'cg.', '시각적', '즐거음은', '최고!', '더불어', 'ost는', '더더욱', '최고!!']
```

**문제가 바로 보인다.**

```
'최고!' 와 '최고!!' 가 서로 다른 단어가 된다
'cg.' 에 마침표가 붙어 있다
'ost는' 에 조사가 붙어 있다
```

**(2) 글자로 자르기**

```python
tokenized = list(review)
# ['현', '실', '과', ' ', '구', '분', ' ', ...]
```

어휘가 아주 작아지지만(한글 음절 ~2,500자) **한 글자에 의미가 거의 없다.**

**(3) 자모로 자르기**

```python
from jamo import h2j, j2hcj
decomposed = j2hcj(h2j(review))
tokenized = list(decomposed)
# ['ㅎ', 'ㅕ', 'ㄴ', 'ㅅ', 'ㅣ', 'ㄹ', 'ㄱ', 'ㅘ', ' ', ...]
```

| 단위 | 어휘 크기 | 시퀀스 길이 | 의미 |
|---|---|---|---|
| 단어 | 매우 큼 | 짧음 | 풍부 |
| 글자 | 작음 (~2,500) | 중간 | 적음 |
| 자모 | **아주 작음 (~50)** | **매우 김** | 거의 없음 |

**자모 분해는 오타에 강하다.** "안뇽하세요"와 "안녕하세요"가 자모로는 거의 같다.
그래서 오타가 많은 댓글·검색어 처리에 쓴다.

## 2-2. 형태소 분석기

한국어는 **교착어**라 어간에 조사와 어미가 계속 붙는다. 그래서 형태소 단위로 자른다.

```python
from konlpy.tag import Okt
okt = Okt()
sentence = "무엇이든 상상할 수 있는 사람은 무엇이든 만들어 낼 수 있다."

print(okt.nouns(sentence))
# ['무엇', '상상', '수', '사람', '무엇', '낼', '수']
print(okt.morphs(sentence))
# ['무엇', '이든', '상상', '할', '수', '있는', '사람', '은', '무엇', '이든', '만들어', '낼', '수', '있다', '.']
print(okt.pos(sentence))
# [('무엇', 'Noun'), ('이든', 'Josa'), ('상상', 'Noun'), ('할', 'Verb'), ...]
```

**`'사람은'`이 `'사람' + '은'`으로 갈라졌다.** 이게 형태소 분석기가 하는 일이다.
공백 분리로는 `'사람은'`과 `'사람이'`가 다른 단어가 되지만, 이제 `'사람'`으로 합쳐진다.

### Okt와 Kkma를 나란히 놓고 보기

```python
kkma = Kkma()
print(kkma.morphs(sentence))
# ['무엇', '이', '든', '상상', '하', 'ㄹ', '수', '있', '는', '사람', '은', '무엇', '이', '든',
#  '만들', '어', '내', 'ㄹ', '수', '있', '다', '.']
```

| | Okt | Kkma |
|---|---|---|
| 형태소 개수 | 15개 | **22개** |
| `'상상할'` | `상상` + `할` | `상상` + `하` + `ㄹ` |
| 품사 태그 | `Noun`, `Josa` (읽기 쉬움) | `NNG`, `JX`, `ETD` (세밀함) |
| 속도 | 빠름 | 느림 |
| `phrases()` | 있음 (`'상상할 수 있는 사람'`) | 없음 |
| `sentences()` | 없음 | 있음 |

**Kkma가 더 잘게 쪼갠다.** `'할'`을 `'하'+'ㄹ'`까지 분리한다.

**어느 쪽이 맞다고 할 수 없다.** 과제에 맞는 쪽을 고르는 문제다.

```
빠르고 실용적으로          → Okt
세밀한 문법 분석이 필요하면 → Kkma
속도가 최우선이면          → Mecab (별도 설치)
```

**중요한 건 일관성이다.** 학습할 때 쓴 분석기를 추론할 때도 써야 한다.

## 2-3. 영어 도구 (NLTK, spaCy)

```python
nltk.download('punkt')
nltk.download('averaged_perceptron_tagger_eng')

word_tokens = tokenize.word_tokenize(sentence)
# ['Those', 'who', 'can', 'imagine', 'anything', ',', 'can', 'create', 'the', 'impossible', '.']
sent_tokens = tokenize.sent_tokenize(sentence)   # 문장 단위로
pos = tag.pos_tag(word_tokens)
# [('Those', 'DT'), ('who', 'WP'), ('can', 'MD'), ('imagine', 'VB'), ...]
```

**`nltk.download`를 먼저 해야 한다.** 사전과 모델을 따로 내려받는 구조다.

```python
import spacy
nlp = spacy.load("en_core_web_sm")
doc = nlp(sentence)
for token in doc:
    print(f"[{token.pos_:5} - {token.tag_:3}] : {token.text}")
# [PRON  - DT ] : Those
# [VERB  - VB ] : imagine
```

| | NLTK | spaCy |
|---|---|---|
| 방식 | 함수를 하나씩 부른다 | **파이프라인이 한 번에** |
| 품사 | `tag_` 만 (Penn Treebank) | `pos_`(간단) + `tag_`(세밀) 둘 다 |
| 속도 | 느림 | 빠름 |
| 성격 | 교육·연구용 | 실무용 |

**영어는 `'impossible.'`처럼 마침표만 떼면 되지만**, 한국어는 조사를 떼야 해서 훨씬 어렵다.
영어 도구가 단순한 이유가 그것이다.

## 2-4. 말뭉치 가져오기 (Korpora)

```python
from Korpora import Korpora

corpus = Korpora.load("korean_petitions")
dataset = corpus.train
petition = dataset[0]

print(petition.category)   # 육아/교육
print(petition.title)      # 학교는 인력센터, 취업센터가 아닙니다. 정말 간곡히 부탁드립니다.
print(petition.num_agree)  # 동의 수
print(petition.text[:30])
```

**`Korpora`는 한국어 공개 말뭉치를 한 줄로 받아 온다.** 청와대 국민청원, 네이버 영화 리뷰(NSMC), KorNLI 등.

```python
petitions = corpus.get_all_texts()
with open("./dataset/corpus.txt", "w", encoding="utf-8") as f:
    for petition in petitions:
        f.write(petition + "\n")
```

이 파일(약 517MB)이 다음 절에서 토크나이저를 학습시키는 재료가 된다.

**`encoding="utf-8"`을 반드시 준다.** 윈도우에서 빼면 기본 인코딩이 cp949라 한글이 깨진다.

## 2-5. 서브워드 — SentencePiece BPE

형태소 분석기는 **사전에 없는 말에 약하다.** 신조어, 오타, 외국어가 섞이면 무너진다.
서브워드는 **말뭉치에서 자주 붙어 다니는 조각을 통계로 찾아낸다.** 사전이 필요 없다.

```python
from sentencepiece import SentencePieceTrainer

SentencePieceTrainer.Train(
    "--input=./dataset/corpus.txt"
    " --model_prefix=./models/petition_bpe"
    " --vocab_size=8000 model_type=bpe"
)
```

**BPE(Byte Pair Encoding)의 원리는 단순하다.**

```
1. 모든 글자를 조각으로 시작한다
2. 가장 자주 같이 나오는 두 조각을 합쳐 새 조각으로 만든다
3. 어휘 크기에 도달할 때까지 반복한다
```

자주 쓰는 말은 통째로 한 조각이 되고, 드문 말은 잘게 쪼개진다.

```python
tokenizer = SentencePieceProcessor()
tokenizer.load("./models/petition_bpe.model")

sentence = "안녕하세요, 토크나이저가 잘 학습되었군요!"
print(tokenizer.encode_as_pieces(sentence))
# ['▁안녕하세요', ',', '▁토', '크', '나', '이', '저', '가', '▁잘', '▁학', '습', '되었', '군요', '!']
print(tokenizer.encode_as_ids(sentence))
# [667, 6553, 994, 6880, 6544, 6513, 6590, 6523, 161, 110, 6554, 872, 787, 6648]
```

**`▁`(U+2581)는 띄어쓰기 표시다.** 밑줄이 아니다.
이 기호 덕분에 **원문을 정확히 복원할 수 있다.**

```python
print(tokenizer.decode_ids(encoded_sentences))
# ['이렇게 입력값을 리스트로 받아서', '쉽게 토크나이저를 사용할 수 있답니다']
```

**결과를 읽어 보면 학습이 잘 됐는지 보인다.**

```
'▁안녕하세요'  → 통째로 한 조각    (청원 글에 자주 나옴)
'▁토크나이저'  → 토/크/나/이/저    (청원 글에 없는 말이라 잘게 쪼개짐)
```

**학습에 쓴 말뭉치의 성격이 그대로 드러난다.** 청원 데이터로 학습했으니 IT 용어에는 약하다.

```python
vocab = {idx: tokenizer.id_to_piece(idx) for idx in range(tokenizer.get_piece_size())}
print(list(vocab.items())[:5])
# [(0, '<unk>'), (1, '<s>'), (2, '</s>'), (3, '니다'), (4, '▁이')]
print(len(vocab))   # 8000
```

**0~2번이 특수 토큰이다.** 3번이 `'니다'`인 게 한국어답다 — 청원 글의 존댓말 어미다.

## 2-6. 서브워드 — WordPiece

```python
from tokenizers import Tokenizer
from tokenizers.models import WordPiece
from tokenizers.normalizers import Sequence, NFD, Lowercase
from tokenizers.pre_tokenizers import Whitespace

tokenizer = Tokenizer(WordPiece())
tokenizer.normalizer = Sequence([NFD(), Lowercase()])
tokenizer.pre_tokenizer = Whitespace()
tokenizer.train(["./dataset/corpus.txt"])
tokenizer.save("./models/petition_wordpiece.json")
```

**세 단계로 나뉘어 있는 게 이 라이브러리의 구조다.**

| 단계 | 역할 |
|---|---|
| `normalizer` | 유니코드 정규화(NFD), 소문자화 |
| `pre_tokenizer` | 먼저 공백으로 크게 나눈다 |
| `model` | 그 안에서 서브워드를 찾는다 |

```python
encoded = tokenizer.encode("안녕하세요, 토크나이저가 잘 학습되었군요!")
print(encoded.tokens)
# ['안녕하세요', ',', '토', '##크', '##나이', '##저', '##가', '잘', '학습', '##되었', '##군요', '!']
print(encoded.ids)
# [8760, 11, 8693, 8415, 16269, 7536, 7488, 7842, 15016, 8670, 8734, 0]
```

**`##`는 "앞 조각에 이어 붙는다"는 표시다.** SentencePiece의 `▁`와 반대 방향의 표현이다.

| | SentencePiece | WordPiece |
|---|---|---|
| 공백 표시 | `▁`를 **단어 시작**에 붙임 | `##`를 **단어 중간**에 붙임 |
| 공백 처리 | 공백도 토큰의 일부 | 미리 공백으로 나눔 |
| 복원 | 완벽 | `##`를 합쳐서 복원 |
| 쓰는 모델 | T5, ALBERT, XLNet | **BERT, ELECTRA** |

### 주의 — 마지막 `!`가 `<unk>`가 됐다

```
tokens : [..., '##군요', '!']
ids    : [...,    8734,   0]      ← 0 은 <unk>
```

**`!`가 어휘에 없다.** `tokenizer.train()`을 옵션 없이 불러서
`vocab_size` 기본값과 특수 토큰 설정이 이 말뭉치와 안 맞았기 때문이다.

```python
from tokenizers.trainers import WordPieceTrainer
trainer = WordPieceTrainer(vocab_size=8000,
                           special_tokens=["[UNK]", "[CLS]", "[SEP]", "[PAD]", "[MASK]"])
tokenizer.train(["./dataset/corpus.txt"], trainer)
```

**`trainer`를 명시하는 게 맞다.** 그래야 어휘 크기와 특수 토큰을 통제할 수 있다.

**토큰화 결과에 `<unk>`가 얼마나 나오는지 반드시 세어 본다.**
많으면 어휘가 작거나 학습 말뭉치가 대상 데이터와 다르다는 뜻이다.

## 이 장 정리

### 흐름

```
공백/글자/자모   2-1   무엇을 한 단위로 볼 것인가
   ↓
형태소 분석기    2-2   조사·어미를 떼어낸다 (Okt / Kkma)
   ↓
말뭉치          2-4   Korpora 로 학습 재료를 모은다
   ↓
서브워드        2-5~6  말뭉치에서 조각을 통계로 찾는다 (BPE / WordPiece)
```

### 어떤 토큰화를 쓸 것인가

| 상황 | 선택 |
|---|---|
| 형태소 정보가 필요하다 | Okt, Kkma, Mecab |
| 신조어·오타가 많다 | **서브워드** |
| 사전학습 모델을 쓴다 | **그 모델의 토크나이저를 그대로** |
| 오타에 아주 강해야 한다 | 자모 분해 |

**사전학습 모델을 쓸 때는 선택의 여지가 없다.**
BERT에는 BERT의 토크나이저를 써야 한다. 어휘 번호가 모델 가중치와 짝이기 때문이다.

### 특수 토큰

| 토큰 | 역할 |
|---|---|
| `<unk>` / `[UNK]` | 어휘에 없는 말 |
| `<pad>` / `[PAD]` | 길이를 맞추는 채움 |
| `<s>` `</s>` / `[CLS]` `[SEP]` | 문장 시작·끝 |

### 자주 틀리는 것

- 학습과 추론에서 **다른 토크나이저**를 쓴다
- 파일을 열 때 `encoding="utf-8"`을 빼먹는다 (윈도우에서 한글이 깨진다)
- `tokenizer.train()`에 `trainer`를 안 주고 기본값에 맡긴다
- `<unk>` 비율을 확인하지 않는다
- 한국어를 `split()`으로만 자른다
- `▁`(U+2581)를 밑줄로 착각한다
