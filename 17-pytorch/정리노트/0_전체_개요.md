## 전체 흐름 한 줄 요약

**글자를 숫자로 바꾸고(1~2장) → 그 숫자에 의미를 담고(3장 임베딩) → 문맥을 읽는 구조를 얹는다(3장 RNN, 4장 트랜스포머) → 남이 학습해 둔 걸 가져다 쓴다(4장 미세조정).**

각 장이 앞 장의 한계를 해결하는 순서로 되어 있습니다.

| 단계 | 한계 | 다음 장의 해법 |
| --- | --- | --- |
| 1장 — 숫자 데이터 다루기 | 텍스트는 숫자가 아니다 | 2장 토큰화 |
| 2장 — 토큰 ID로 변환 | ID는 순서 번호일 뿐 의미가 없다 | 3장 임베딩 |
| 3장 — 임베딩 + RNN | 순차 처리라 느리고, 먼 단어를 기억 못 한다 | 4장 셀프 어텐션 |
| 4장 — 트랜스포머 | 처음부터 학습하기엔 데이터가 부족하다 | 4장 후반 사전학습 모델 미세조정 |

## 손실값 기준점

학습이 되고 있는지 판단할 때 쓰는 표입니다. 첫 에폭 손실이 이 근처면 정상 출발.

| 과제 | 무작위 수준 손실 |
| --- | --- |
| C개 클래스 분류 | `ln(C)` |
| 이진 분류 | `ln(2) = 0.693` |
| 언어 생성 (어휘 V) | `ln(V)` |
