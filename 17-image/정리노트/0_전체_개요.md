# 컴퓨터 비전 학습 정리 — 전체 개요

`17-image` 폴더의 실습 노트북 정리본이다. 파일이 추가될 때마다 이어서 정리한다.

---

## 전체 흐름

```
1. OpenCV 기초          이미지 = 숫자 행렬. 읽고, 돌리고, 자른다
   ↓
2. 이미지 전처리         모델에 넣기 전에 다듬는다
   ↓
3. 신경망 기초           퍼셉트론 → CNN → GAN·VAE
   ↓
4. 대표 아키텍처         Inception, ResNet, EfficientNet, ViT, Swin
   ↓
5. 객체 검출             무엇이 어디에 몇 개 있는가
   ↓
(이후)                  세그멘테이션
```

챕터 번호는 실습 파일의 앞자리와 맞춘다.

| 묶음 | 챕터 | 파일 |
|---|---|---|
| — | 0 | (개요) |
| 고전 영상처리 | 1 | `1.ipynb` |
| 고전 영상처리 | 2 | `2.ipynb` |
| 딥러닝 기반 비전 | 3 | `3_0.ipynb`, `3_1.ipynb`, `3_2.ipynb` |
| 딥러닝 기반 비전 | 4 | `4_0.ipynb` ~ `4_4.ipynb` |
| 딥러닝 기반 비전 | 5 | `5_0.ipynb` ~ `5_2.ipynb` |

정리노트 폴더와 노션 모두 이 두 묶음으로 나눠 두었다.

```
정리노트/
  0_전체_개요.md
  고전_영상처리/      1, 2장
  딥러닝_기반_비전/    3, 4, 5장
```

같은 개념을 **파이토치**로 다시 보는 건 별도 과목 `딥러닝 정리`다.
이 과목은 처음부터 끝까지 텐서플로/케라스를 쓴다.

1~2장은 **고전 컴퓨터 비전**이다. 사람이 직접 규칙(커널, 임계값)을 정한다.
3장부터는 **딥러닝**이다. 그 규칙을 모델이 스스로 학습한다.

고전 기법을 먼저 배우는 이유는, CNN이 하는 일이 결국
**2장에서 손으로 만든 필터를 자동으로 학습하는 것**이기 때문이다.
Sobel 커널을 직접 만들어 본 사람은 CNN의 첫 번째 층이 무엇을 배우는지 바로 이해한다.

4장과 5장은 같은 구성을 반복한다. **직접 만들어 보고, 잘 만들어진 걸 가져다 쓴다.**
직접 만드는 쪽은 구조를 이해하기 위한 것이고, 실무에서 쓰는 건 대개 가져다 쓰는 쪽이다.

그리고 5장의 검출 모델은 4장의 분류 모델을 **백본으로 얹어서** 만든다.
장이 따로 노는 게 아니라 부품으로 이어진다.

| | GAN (3-6) | VAE (5-2) |
|---|---|---|
| 구조 | 생성자 + 판별자 경쟁 | 인코더 + 디코더 |

| 결과 | 선명하다 | 흐릿하다 |
| 공통점 | 둘 다 `model.fit()`을 못 쓰고 **`GradientTape`로 직접 학습** | |

| 절 | 모델 | 방식 | 데이터 | 테스트 정확도 |

## 한눈에 보는 선택 기준

### 노이즈별 필터

| 노이즈 | 생김새 | 필터 |
|---|---|---|
| 솔트 앤 페퍼 | 흰 점, 검은 점이 튄다 | `cv2.medianBlur` |
| 가우시안 | 전체가 자글자글하다 | `cv2.GaussianBlur` |
| 경계를 살려야 함 | — | `cv2.bilateralFilter` |

### 색 공간

| 목적 | 선택 |
|---|---|
| 화면 표시 | RGB |
| 데이터 줄이기, 형태만 필요 | Grayscale |
| 조명이 바뀌어도 색으로 찾기 | **HSV** |

### 엣지 검출

| 상황 | 선택 |
|---|---|
| 실무 | **Canny** |
| 원리 이해, 방향별 기울기가 필요 | Sobel |

### 활성화 함수와 손실 함수

| 문제 | 출력층 활성화 | 손실 함수 |
|---|---|---|
| 이진 분류 | `sigmoid` | `binary_crossentropy` |
| 다중 분류 (정수 레이블) | `softmax` | **`sparse_categorical_crossentropy`** |
| 다중 분류 (원-핫 레이블) | `softmax` | `categorical_crossentropy` |
| 회귀 | 없음 | `mean_squared_error` |

은닉층은 특별한 이유가 없으면 `relu`.

### 정규화 범위와 출력 활성화

| 정규화 | 범위 | 짝이 되는 출력 활성화 |
|---|---|---|
| `x / 255` | 0 ~ 1 | `sigmoid` |
| `(x - 127.5) / 127.5` | -1 ~ 1 | `tanh` |

생성 모델에서 이 둘을 어긋나게 두면 판별자가 진짜와 가짜를 범위만 보고 구분해 버린다.

## 실습 코드에서 발견한 오류

복습할 때 같은 실수를 반복하지 않기 위해 정리해 둔다.
아래 항목은 모두 노트북 출력과 코드로 직접 확인했다.

| 위치 | 내용 | 영향 |
|---|---|---|
| `2.ipynb` 가우시안 노이즈 | `np.random.normal()` 결과에 `.astype('uint8')`을 바로 적용 → 음수가 255로 래핑 | **가우시안이 아니라 솔트 노이즈가 생성됨.** 약 15%의 픽셀이 흰색으로 |
| `2.ipynb` FFT 마스크 | 주석은 "저주파만 통과"인데 실제로는 중앙(저주파)을 0으로 만듦 | **하이패스 필터.** 주석과 반대 동작 |
| `2.ipynb` Prewitt | `cv2.filter2D(img, -1, kx)` — `uint8` 입력에 `ddepth=-1` | **음수 응답이 0으로 잘려 한쪽 방향 엣지를 통째로 놓침** |
| `3.ipynb` reshape | `tf.reshape(x, -1, 1)` — 1이 `name` 인자로 들어감 | shape가 `(100, 1)`이 아니라 `(100,)` 그대로 |
| `3_1.ipynb` EarlyStopping | `restore_best_weights=True`가 없음 | `evaluate`가 **최고 가중치가 아닌 마지막 가중치**로 평가됨 |
| `4_4.ipynb` Swin | `num_classes = 100`인데 CIFAR-10(10종)을 씀 | 출력 뉴런 90개가 학습되지 않고 확률을 나눠 가짐 |
| `5_1.ipynb` YOLO 출력층 | `add_dense_layer`가 인자 `activation`을 무시하고 `leaky_relu` 고정 | **출력층에 활성화가 걸린다.** 좌표는 선형이어야 함 |
| `5_1.ipynb` `nms()` | 이름은 NMS인데 점수 필터링만 함 | 같은 물체에 **박스가 겹쳐 여러 개** 그려짐 |
| `5_1.ipynb` 클래스 목록 | 학습 라벨을 **테스트 XML**에서 뽑은 목록으로 만듦 | 테스트에 없는 클래스가 학습에 있으면 `ValueError` |

세부 설명과 수정 코드는 각 챕터의 해당 절에 적어뒀다.
