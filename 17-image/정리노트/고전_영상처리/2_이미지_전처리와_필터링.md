# 2. 이미지 전처리와 필터링

**실습 파일**: `2.ipynb`

가장 분량이 많은 장이다. 이미지를 모델에 넣기 전에 하는 처리들을 훑는다.

```
읽기 → 색 공간 변환 → 정규화
                          ↓
              노이즈 제거 (공간 영역 필터)
                          ↓
              주파수 영역 분석 (FFT)
                          ↓
              특징 추출 (피라미드, 엣지)
```

## 2-1. TensorFlow로 이미지 읽기

### 개념

OpenCV 말고 텐서플로로도 이미지를 읽을 수 있다.
읽는 순간부터 **텐서**라서 그대로 학습 파이프라인에 연결된다는 게 장점이다.

읽기가 두 단계로 나뉜다.

1. `tf.io.read_file()` — 파일을 **바이트 문자열**로 읽는다 (아직 이미지가 아니다)
2. `tf.image.decode_png()` — 바이트를 **픽셀 텐서**로 해석한다

### 핵심 코드

```python
import tensorflow as tf

image = tf.io.read_file('like_lenna.png')
print(image)
# <tf.Tensor: shape=(), dtype=string, numpy=b'\x89PNG\r\n\x1a\n...'>

image = tf.image.decode_png(image, channels=3)
print(image)
# <tf.Tensor: shape=(224, 224, 3), dtype=uint8, ...>
```

`channels=3`은 흑백 파일이어도 3채널로 만들라는 뜻이다.
모델 입력 채널 수를 맞출 때 편하다.

| 함수 | 용도 |
|---|---|
| `tf.image.decode_png` | PNG |
| `tf.image.decode_jpeg` | JPEG |
| `tf.image.decode_image` | 자동 판별 (대신 shape가 확정 안 될 수 있음) |

### OpenCV와의 차이

| | OpenCV | TensorFlow |
|---|---|---|
| 결과 타입 | 넘파이 배열 | 텐서 |
| 색 순서 | **BGR** | **RGB** |
| 그리기 | `cvtColor` 필요 | `plt.imshow()` 바로 가능 |

텐서플로는 RGB라서 별도 변환 없이 `plt.imshow(image)`로 바로 그려진다.

## 2-2. 색 공간 변환

### 개념

같은 이미지도 어떤 좌표계로 표현하느냐에 따라 다루기 쉬운 정보가 달라진다.

| 색 공간 | 구성 | 특징 |
|---|---|---|
| **RGB** | 빨강, 초록, 파랑 | 화면 표시의 표준 |
| **Grayscale** | 밝기 1채널 | 데이터가 1/3로 줄어든다 |
| **HSV** | 색상(Hue), 채도(Saturation), 명도(Value) | **조명 변화에 강하다** |

### 흑백 변환

```python
grayscale_image = tf.image.rgb_to_grayscale(rgb_image)
print(grayscale_image.shape)   # (100, 100, 1)  ← 채널이 1로

plt.imshow(grayscale_image, cmap='gray')
plt.axis('off')
plt.show()
```

**단순 평균이 아니다.** 사람 눈은 초록에 가장 민감하므로 가중 평균을 쓴다.

```
Gray = 0.299·R + 0.587·G + 0.114·B
```

### HSV 변환

```python
hsv_image = tf.image.rgb_to_hsv(rgb_image)

hue_channel = hsv_image[:, :, 0]   # 색상 채널만

plt.imshow(hue_channel, cmap='hsv')
plt.colorbar(label='Hue Value')
plt.axis('off')
plt.show()
```

**HSV를 쓰는 이유**: RGB에서는 같은 빨간 물체도 그늘에 있으면 값이 완전히 달라진다.
HSV는 색상(H)과 밝기(V)가 분리돼 있어서, **조명이 바뀌어도 H는 거의 그대로**다.

그래서 "빨간 공만 찾아라" 같은 색 기반 검출에는 RGB보다 HSV가 훨씬 유리하다.

### 참고: 랜덤 이미지 생성

```python
rgb_image = tf.random.uniform([100, 100, 3], maxval=255, dtype=tf.float32)
plt.imshow(rgb_image)
```

이때 경고가 뜬다.

```
Clipping input data to the valid range for imshow with RGB data
([0..1] for floats or [0..255] for integers). Got range [0.036..254.99]
```

**matplotlib의 규칙**: 실수(float)면 0~1, 정수(int)면 0~255를 기대한다.
float인데 0~255 범위를 넣어서 나온 경고다. `/255.0`으로 나누거나 `astype('uint8')`로 바꾸면 사라진다.

## 2-3. 정규화와 표준화

### 개념

픽셀 값 0~255를 그대로 넣으면 학습이 불안정하다. 값의 범위를 줄여줘야 한다.

| | 수식 | 결과 범위 |
|---|---|---|
| **정규화 (Normalization)** | `x / 255.0` | 0 ~ 1 |
| **표준화 (Standardization)** | `(x - 평균) / 표준편차` | 평균 0, 표준편차 1 |

### 코드

```python
# 정규화
normalize_image = rgb_image / 255.0
rgb_image[0][0], normalize_image[0][0]
# [178.48, 87.29, 154.81]  →  [0.6999, 0.3423, 0.6071]
```

```python
# 표준화
mean = tf.reduce_mean(rgb_image)
stddev = tf.math.reduce_std(rgb_image)

standard_image = (rgb_image - mean) / stddev
rgb_image[0][0], standard_image[0][0]
# [178.48, 87.29, 154.81]  →  [0.6867, -0.5500, 0.3657]
```

표준화는 음수가 나온다. 평균보다 어두운 픽셀이 음수가 되는 것이다.

### 어느 쪽을 쓰나

- **정규화**: 가장 흔하다. 처음부터 직접 학습시킬 때
- **표준화**: 사전학습 모델(ResNet, VGG 등)을 쓸 때. 그 모델이 학습할 때 쓴 평균·표준편차를 그대로 써야 한다

**표준화 값은 반드시 학습 데이터의 것을 쓴다.** 테스트 데이터로 평균을 다시 구하면 안 된다.

## 2-4. 노이즈와 필터링 — 솔트 앤 페퍼

### 개념

**솔트 앤 페퍼 노이즈**는 픽셀이 무작위로 흰 점(salt, 255)이나 검은 점(pepper, 0)으로 튀는 잡음이다.
센서 오류나 전송 오류에서 생긴다.

### 노이즈 생성 함수

```python
import numpy as np

def generate_salt_noise(image):
    num_salt = np.ceil(0.05 * image.size)          # 전체 픽셀의 5%
    coords = [np.random.randint(0, i-1, int(num_salt))
              for i in image.shape]                 # y좌표들, x좌표들
    salted_image = image.copy()                     # 원본 보호
    salted_image[coords[0], coords[1]] = 255        # 흰 점
    return salted_image

def generate_peper_noise(image):
    num_peper = np.ceil(0.05 * image.size)
    coords = [np.random.randint(0, i-1, int(num_peper))
              for i in image.shape]
    pepered_image = image.copy()
    pepered_image[coords[0], coords[1]] = 0         # 검은 점
    return pepered_image
```

**`image.copy()`가 핵심이다.** 1장에서 본 뷰 문제 때문에, 복사하지 않으면 원본이 오염된다.

`coords`는 리스트 컴프리헨션으로 `[y좌표 배열, x좌표 배열]`을 만든다.
`salted_image[coords[0], coords[1]]`처럼 넘파이 팬시 인덱싱으로 여러 픽셀을 한 번에 바꾼다.

### 미디언 블러로 제거

```python
import cv2

lenna_image   = cv2.imread('like_lenna.png', cv2.IMREAD_GRAYSCALE)
salted_lenna  = generate_salt_noise(lenna_image)
pepered_lenna = generate_peper_noise(salted_lenna)
filtered_lenna = cv2.medianBlur(pepered_lenna, 5)
```

**미디언 블러가 솔트 앤 페퍼에 특히 강한 이유**

주변 5×5 픽셀을 정렬해서 **가운데 값**을 고른다.
극단적으로 튀는 0이나 255는 정렬하면 맨 끝으로 밀려나 절대 선택되지 않는다.

평균 블러였다면 255 하나가 주변 전체를 밝게 오염시켰을 것이다.

| 필터 | 방식 | 솔트 앤 페퍼에 |
|---|---|---|
| `cv2.blur` | 평균 | 약함 (노이즈가 번진다) |
| `cv2.GaussianBlur` | 가중 평균 | 약함 |
| **`cv2.medianBlur`** | 중앙값 | **강함** |

`medianBlur`의 커널 크기는 **홀수**여야 한다. 가운데 값을 고르려면 개수가 홀수여야 하기 때문이다.

### 4단계 비교 시각화

```python
fig, axes = plt.subplots(1, 4, figsize=(20, 6))

for ax, img in zip(axes, [lenna_image, salted_lenna, pepered_lenna, filtered_lenna]):
    ax.imshow(img, cmap='gray')
    ax.axis('off')

plt.tight_layout()
plt.show()
```

원본 → 소금 → 소금+후추 → 복원. 미디언 블러가 대부분의 점을 지워낸 게 보인다.

## 2-5. 가우시안 노이즈와 가우시안 블러

### 개념

**가우시안 노이즈**는 모든 픽셀에 정규분포를 따르는 작은 값이 더해지는 잡음이다.
솔트 앤 페퍼처럼 몇 개가 극단적으로 튀는 게 아니라, **전체가 자글자글하게** 흔들린다.

이런 잡음에는 미디언보다 **가우시안 블러**가 맞다.

### 실습 코드

```python
image = cv2.imread('like_lenna.png', cv2.IMREAD_GRAYSCALE)

mean, sigma = 0, 1
gaussian_noise = np.random.normal(mean, sigma, image.shape).astype('uint8')
noise_image = cv2.add(image, gaussian_noise)

plt.imshow(noise_image, cmap='gray')
plt.axis('off')
plt.show()
```

**이 코드에는 버그가 있다**

`np.random.normal(0, 1, ...)`은 **절반이 음수**다.
그걸 `.astype('uint8')`로 바꾸면 음수가 잘리는 게 아니라 **한 바퀴 돌아 큰 값이 된다.**
`-1`은 `255`가, `-2`는 `254`가 된다.

실제로 값을 세어보면 이렇다.

| 값 | 개수 (224×224 = 50,176 중) |
|---|---|
| 0 | 34,475 |
| **255** | **6,760** |
| 1 | 6,661 |
| **254** | **1,085** |

약 15%의 픽셀에 254~255가 더해지고, `cv2.add`는 포화 연산이라 그 픽셀들이 전부 흰색이 된다.
**의도한 가우시안 노이즈가 아니라 사실상 솔트 노이즈가 만들어진다.**

올바른 코드는 실수로 계산한 뒤 마지막에 자르는 것이다.

```python
gaussian_noise = np.random.normal(mean, sigma, image.shape)
noise_image = np.clip(image.astype(np.float32) + gaussian_noise, 0, 255).astype('uint8')
```

그리고 `sigma=1`은 0~255 범위에서 거의 보이지 않는 수준이다. 눈에 띄게 하려면 10~25 정도를 준다.

### 시그마를 바꿔가며 블러

```python
sigma_values = [1, 5, 10]
denoise_image = []

for sigma in sigma_values:
    denoise = cv2.GaussianBlur(noise_image, (0, 0), sigma)
    denoise_image.append(denoise)

fig, axes = plt.subplots(1, 4, figsize=(20, 10))
axes[0].imshow(noise_image, cmap='gray'); axes[0].axis('off')

for ax, img, sigma in zip(axes[1:], denoise_image, sigma_values):
    ax.imshow(img, cmap='gray')
    ax.axis('off')
```

**`(0, 0)`을 커널 크기로 주는 게 포인트다.**
커널을 0으로 두면 OpenCV가 **시그마 값으로부터 알맞은 커널 크기를 자동 계산**한다.
시그마만 조절하면 되니 훨씬 편하다.

| 시그마 | 결과 |
|---|---|
| 작다 (1) | 노이즈가 거의 안 지워진다 |
| 중간 (5) | 노이즈는 줄고 형태는 남는다 |
| 크다 (10) | 노이즈는 사라지지만 **엣지도 뭉개진다** |

**블러의 딜레마**: 노이즈를 지우려면 세게 흐려야 하는데, 그러면 필요한 경계선까지 사라진다.
이 트레이드오프를 피하려고 나온 게 `cv2.bilateralFilter`(경계는 살리고 평탄한 곳만 흐리게)다.

## 2-6. 기하 변환

### 회전 함수로 묶기

```python
def rotate_image(image, angle, center=None):
    rows, cols, _ = image.shape
    if center is None:
        center = (cols // 2, rows // 2)     # (x, y) 순서 주의

    M = cv2.getRotationMatrix2D(center, angle, 1)
    rotated = cv2.warpAffine(image, M, (cols, rows))
    return rotated

rotated_img = rotate_image(image, 45)
```

`center`의 기본값을 `None`으로 두고 함수 안에서 중심을 계산하는 패턴이다.
`(cols // 2, rows // 2)` — **가로가 먼저**다. shape에서 꺼낸 순서와 반대다.

### 원근 변환 (Perspective Transform)

**개념**: 비스듬히 찍힌 사진을 정면에서 본 것처럼 펴는 변환이다.
문서 스캔 앱이 바로 이 기술이다.

회전(어파인 변환)은 평행선이 평행하게 유지되지만,
원근 변환은 **사다리꼴을 직사각형으로** 바꿀 수 있다.

```python
new_img = cv2.imread('perspective_test.jpg')

# 1) 원본에서 펴고 싶은 네 꼭짓점 (좌상 → 우상 → 우하 → 좌하 순서)
ordered_corners = np.array([[57, 630], [936, 330], [1404, 792], [550, 1431]],
                           dtype='float32')

# 2) 결과 크기 계산 — 마주 보는 변 중 긴 쪽을 택한다
ordered_width = int(max(np.linalg.norm(ordered_corners[0] - ordered_corners[1]),
                        np.linalg.norm(ordered_corners[2] - ordered_corners[3])))

ordered_height = int(max(np.linalg.norm(ordered_corners[0] - ordered_corners[3]),
                         np.linalg.norm(ordered_corners[1] - ordered_corners[2])))

# 3) 목적지 좌표 — 직사각형
ordered_rect_corners = np.array([[0, 0],
                                 [ordered_width, 0],
                                 [ordered_width, ordered_height],
                                 [0, ordered_height]], dtype='float32')

# 4) 변환 행렬 만들고 적용
ordered_scan_matrix = cv2.getPerspectiveTransform(ordered_corners, ordered_rect_corners)
ordered_scanned_img = cv2.warpPerspective(new_img, ordered_scan_matrix,
                                          (ordered_width, ordered_height))
```

**꼭 지킬 것 세 가지**

1. **네 점의 순서가 두 배열에서 같아야 한다.** 원본이 좌상→우상→우하→좌하면 목적지도 같은 순서.
   순서가 어긋나면 이미지가 꼬여서 나온다
2. `dtype='float32'` 필수. 정수형을 넣으면 에러가 난다
3. `np.linalg.norm(a - b)`는 두 점 사이의 **직선 거리**다. 이걸로 실제 변의 길이를 재서 출력 크기를 정한다

| 변환 | 함수 | 필요한 점 | 성질 |
|---|---|---|---|
| 어파인 | `getAffineTransform` + `warpAffine` | 3개 | 평행선 유지 |
| **원근** | `getPerspectiveTransform` + `warpPerspective` | **4개** | 평행선이 모일 수 있음 |

## 2-7. 주파수 영역 — 푸리에 변환

### 개념

지금까지는 픽셀 위치를 직접 다루는 **공간 영역** 작업이었다.
푸리에 변환은 이미지를 **주파수 영역**으로 옮긴다.

- **저주파** = 값이 천천히 변하는 부분 = **넓고 평탄한 영역, 전체 밝기**
- **고주파** = 값이 급격히 변하는 부분 = **경계선, 잔디, 노이즈 같은 세부**

### 변환하고 스펙트럼 보기

```python
img = cv2.imread('like_lenna.png', cv2.IMREAD_GRAYSCALE)

f = np.fft.fft2(img)                 # 2차원 푸리에 변환
fshift = np.fft.fftshift(f)          # 저주파를 중앙으로 이동
magnitude_spectrum_original = 20 * np.log(np.abs(fshift))

plt.subplot(121); plt.imshow(img, cmap='gray')
plt.subplot(122); plt.imshow(magnitude_spectrum_original, cmap='gray')
plt.show()
```

세 줄 각각의 역할

| 코드 | 하는 일 |
|---|---|
| `np.fft.fft2(img)` | 주파수 영역으로 변환. 결과는 **복소수** |
| `np.fft.fftshift(f)` | 원래는 네 귀퉁이에 있는 저주파를 **중앙으로** 모아준다. 보기 좋게 하려고 |
| `20 * np.log(np.abs(f))` | 복소수의 크기를 구하고 로그 스케일로. 값 차이가 너무 커서 로그 없이는 중앙 점 하나만 보인다 |

**스펙트럼 읽는 법**: 중앙이 밝을수록 평탄한 이미지, 바깥이 밝을수록 디테일이 많은 이미지다.

### 필터링

```python
rows, cols = img.shape
crow, ccol = rows // 2, cols // 2
radius = 30

mask = np.ones((rows, cols), np.uint8)
mask[crow - radius:crow + radius, ccol - radius:ccol + radius] = 0
fshift_filtered = fshift * mask
```

**실습 코드의 주석이 반대다.**
주석에는 "고주파 성분만 제거 - 저주파만 통과"라고 적혀 있지만, 실제 동작은 그 반대다.

`fftshift` 이후 **중앙이 저주파**다. 위 마스크는 중앙 60×60을 0으로 만드니
**저주파를 죽이고 고주파를 남기는 하이패스 필터**다. 결과 이미지에 윤곽선만 남는 이유가 이것이다.

반대로 저주파만 통과(로우패스, 흐림 효과)시키려면 마스크를 뒤집는다.

```python
mask = np.zeros((rows, cols), np.uint8)
mask[crow-radius:crow+radius, ccol-radius:ccol+radius] = 1   # 중앙만 1
```

| 마스크 | 남는 것 | 효과 |
|---|---|---|
| 중앙을 0으로 | 고주파 | **하이패스** — 윤곽선만 남음 |
| 중앙만 1로 | 저주파 | **로우패스** — 흐려짐 (블러) |

### 역변환으로 되돌리기

```python
f_ishift = np.fft.ifftshift(fshift_filtered)   # shift 원상복구
img_back = np.fft.ifft2(f_ishift)              # 역 푸리에 변환
img_back = np.abs(img_back)                    # 복소수 → 실수

plt.imshow(img_back, cmap='gray')
plt.show()
```

**순서가 정확히 거꾸로다.** `fft2 → fftshift → 마스크 → ifftshift → ifft2`.
`ifftshift`를 빼먹으면 결과가 이상하게 나온다.

역변환 결과는 아주 작은 허수부가 남은 복소수라서 `np.abs()`로 실수만 취한다.

## 2-8. 이미지 피라미드

### 개념

같은 이미지를 여러 해상도로 만들어 쌓은 것이다. 밑이 넓고 위가 좁아서 피라미드다.

**왜 필요한가**: 사진 속 얼굴은 크기가 제각각이다.
검출기 크기를 바꾸는 것보다 **이미지 크기를 바꿔가며 같은 검출기를 여러 번 돌리는 게** 쉽다.

### 가우시안 피라미드 — 줄여나가기

```python
def gaussian_pyramid(image, levels):
    pyramid = [image]
    for i in range(levels - 1):
        image = cv2.pyrDown(image)     # 가우시안 블러 후 절반으로 축소
        pyramid.append(image)
    return pyramid

levels = 5
pyramid = gaussian_pyramid(img_rgb, levels)

fig, axes = plt.subplots(1, levels, figsize=(20, 8))
for i, ax in enumerate(axes):
    ax.imshow(pyramid[i])
    ax.axis('off')
```

`cv2.pyrDown()`은 그냥 리사이즈가 아니다. **가우시안 블러를 먼저 걸고** 절반으로 줄인다.
블러 없이 줄이면 계단 현상(에일리어싱)이 생기기 때문이다.

224 → 112 → 56 → 28 → 14 순으로 줄어든다.

### 라플라시안 피라미드 — 잃어버린 디테일 모으기

```python
def laplacian_pyramid(gaussian_pyramid):
    laplacian = []
    for i in range(len(gaussian_pyramid) - 1):
        next_level = cv2.pyrUp(gaussian_pyramid[i + 1])   # 한 단계 위를 다시 키움

        # 홀수 크기 때문에 1픽셀 어긋나는 경우 보정
        if next_level.shape[0] > gaussian_pyramid[i].shape[0]:
            next_level = next_level[:-1, :, :]
        if next_level.shape[1] > gaussian_pyramid[i].shape[1]:
            next_level = next_level[:, :-1, :]

        lap = cv2.subtract(gaussian_pyramid[i], next_level)   # 원본 - 복원본
        laplacian.append(lap)

    laplacian.append(gaussian_pyramid[-1])   # 마지막은 원본 그대로
    return laplacian
```

**원리**: 줄였다가(`pyrDown`) 다시 키우면(`pyrUp`) 원본으로 완전히 돌아오지 않는다.
축소할 때 블러로 날아간 **디테일이 사라져 있다.**

`원본 - 복원본`을 하면 **그 사라진 디테일만** 남는다. 그게 라플라시안이다.

**shape 보정 코드가 필요한 이유**: 홀수 크기를 절반으로 줄였다 두 배로 키우면 1픽셀이 어긋난다.
(예: 25 → 13 → 26) `cv2.subtract`는 크기가 다르면 에러라서 미리 잘라 맞춘다.

### 언제 쓰나

- **이미지 블렌딩**: 두 사진을 자연스럽게 합칠 때 (경계선이 티 나지 않게)
- **이미지 압축**: 라플라시안은 대부분 0에 가까워 압축이 잘 된다
- **다중 스케일 객체 검출**

## 2-9. 엣지 검출

### 개념

엣지는 **밝기가 급격히 변하는 지점**이다. 수학적으로는 **미분(기울기)이 큰 곳**이다.
물체의 경계가 대체로 여기에 해당하므로, 형태를 파악하는 첫 단계가 된다.

### Canny — 가장 널리 쓰이는 방법

```python
img = cv2.imread('like_lenna.png', cv2.IMREAD_GRAYSCALE)
blurred_img = cv2.GaussianBlur(img, (5, 5), 1.4)

canny_edge = cv2.Canny(blurred_img, threshold1=50, threshold2=150)
```

**블러를 먼저 거는 게 중요하다.** 미분은 노이즈를 증폭시킨다.
노이즈 하나하나가 급격한 변화로 인식되어 가짜 엣지가 잔뜩 생긴다.

Canny 내부 동작

1. 가우시안 블러 (노이즈 제거)
2. 기울기 계산 (Sobel)
3. 비최대 억제 — 두꺼운 엣지를 1픽셀로 얇게
4. **이중 임계값** — 아래 설명

### 이중 임계값의 의미

| 조건 | 판정 |
|---|---|
| 기울기가 `threshold2`(150) 초과 | **확실한 엣지** |
| 기울기가 `threshold1` ~ `threshold2` 사이 | 확실한 엣지에 **이어져 있으면** 엣지로 인정 |
| 기울기가 `threshold1`(50) 미만 | 버림 |

약한 엣지도 강한 엣지와 연결돼 있으면 살려주는 방식이라, 선이 중간에 끊기지 않는다.

### 임계값 비교

```python
thresholds = [(10, 50), (50, 100), (100, 150), (150, 200)]
canny_res = []

for threshold1, threshold2 in thresholds:
    canny_img = cv2.Canny(blurred_img, threshold1=threshold1, threshold2=threshold2)
    canny_res.append(canny_img)

fig, axes = plt.subplots(1, len(thresholds), figsize=(20, 5))
for i, ax in enumerate(axes):
    ax.imshow(canny_res[i], cmap='gray')
    ax.axis('off')
```

| 임계값 | 결과 |
|---|---|
| 낮다 (10, 50) | 선이 너무 많다. 노이즈까지 엣지로 |
| 높다 (150, 200) | 선이 끊기고 약한 경계를 놓친다 |

정답은 없다. 이미지마다 보면서 맞춘다. 보통 `threshold2 = threshold1 × 2~3` 비율로 잡는다.

### Prewitt — 커널을 직접 만들기

```python
kx = np.array([[-1, 0, 1], [-1, 0, 1], [-1, 0, 1]])   # 세로선 검출 (x 방향 변화)
ky = np.array([[-1, -1, -1], [0, 0, 0], [1, 1, 1]])   # 가로선 검출 (y 방향 변화)

gx = cv2.filter2D(img, -1, kx)
gy = cv2.filter2D(img, -1, ky)

prewitt_res = cv2.addWeighted(gx, 0.5, gy, 0.5, 0)
plt.imshow(prewitt_res, cmap='gray')
```

**커널 읽는 법**: `kx`는 왼쪽(-1)과 오른쪽(+1)의 밝기 차를 재는 것이다.
좌우가 같으면 0, 다르면 큰 값 → 세로 방향 경계선이 잡힌다.

**주의: `ddepth=-1`이면 음수가 잘린다.**

`cv2.filter2D(img, -1, kx)`에서 `-1`은 "입력과 같은 타입으로"라는 뜻이다.
입력이 `uint8`이라 **음수 응답이 전부 0으로 잘린다.**

실제로 위→아래로 어두워지는 경계에 `ky`를 적용해 보면

```
uint8 (ddepth=-1) : [0, 0, 0, 0, 0]        ← 엣지를 통째로 놓침
CV_64F            : [0, -765, -765, 0, 0]  ← 제대로 잡힘
```

**한 방향의 경계선을 통째로 잃는다.** 이렇게 고쳐야 한다.

```python
gx = cv2.filter2D(img, cv2.CV_64F, kx)
gy = cv2.filter2D(img, cv2.CV_64F, ky)
magnitude = np.sqrt(gx**2 + gy**2)
prewitt_res = np.uint8(np.clip(magnitude, 0, 255))
```

### Sobel — 실무 표준

```python
gx_sobel = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)   # x 방향 미분
gy_sobel = cv2.Sobel(img, cv2.CV_64F, 0, 1, ksize=3)   # y 방향 미분

sobel_res = cv2.addWeighted(gx_sobel, 0.5, gy_sobel, 0.5, 0)
plt.imshow(sobel_res, cmap='gray')
```

| 인자 | 의미 |
|---|---|
| `cv2.CV_64F` | 출력 타입. **음수를 담기 위해 실수형** |
| `1, 0` | x로 1차 미분, y로 0차 (= x 방향만) |
| `0, 1` | y 방향만 |
| `ksize` | 커널 크기. 3, 5, 7 (홀수) |

**Sobel과 Prewitt의 차이**: Sobel은 가운데 줄에 가중치 2를 준다.

```
Prewitt kx        Sobel kx
-1  0  1         -1  0  1
-1  0  1         -2  0  2      ← 가운데를 더 크게
-1  0  1         -1  0  1
```

가까운 픽셀에 더 무게를 두므로 **노이즈에 조금 더 강하다.** 그래서 실무에서는 Sobel을 쓴다.

**`addWeighted`로 합치는 건 정확하지 않다.**
`gx`와 `gy`는 부호가 있는 값이라 서로 **상쇄될 수 있다.**
대각선 엣지에서 `gx = +100`, `gy = -100`이면 합이 0이 되어 엣지가 사라진다.

정확한 기울기 크기는 피타고라스로 구한다.

```python
magnitude = np.sqrt(gx_sobel**2 + gy_sobel**2)
# 또는 빠른 근사
magnitude = cv2.magnitude(gx_sobel, gy_sobel)
```

### 세 방법 비교

| 방법 | 특징 | 결과 |
|---|---|---|
| Prewitt | 가장 단순한 1차 미분 | 두껍고 노이즈에 약함 |
| Sobel | 가중치를 준 1차 미분 | 두껍지만 좀 더 안정적 |
| **Canny** | Sobel + 얇게 + 이중 임계값 | **1픽셀 두께의 깔끔한 선** |

실무에서는 Canny를 쓴다. Prewitt과 Sobel은 그 안에서 무슨 일이 일어나는지 이해하려고 배운다.

## 이 장 정리

### 전처리 순서

1. 읽기 → **BGR/RGB 확인**
2. 색 공간 변환 (필요하면 HSV, Grayscale)
3. 크기 통일 (`resize`)
4. **정규화 또는 표준화**
5. 노이즈 제거 (필요하면)
6. 데이터 증강 (회전, 반전 등)

### 노이즈별 대응

| 노이즈 | 생김새 | 필터 |
|---|---|---|
| 솔트 앤 페퍼 | 흰 점, 검은 점이 튄다 | **`medianBlur`** |
| 가우시안 | 전체가 자글자글하다 | **`GaussianBlur`** |
| 경계를 살려야 함 | — | `bilateralFilter` |

### 자주 틀리는 것

- `np.random.normal()` 결과에 **`.astype('uint8')`을 바로 쓰면 음수가 255로 뒤집힌다**
- `fftshift` 후 **중앙은 저주파**다. 중앙을 지우면 하이패스
- `filter2D`에 `ddepth=-1` + `uint8` 입력이면 **음수 엣지를 잃는다.** `cv2.CV_64F`를 쓴다
- 엣지 크기는 `addWeighted`가 아니라 **`sqrt(gx² + gy²)`**
- 미분 전에는 **블러를 먼저** 건다
- `GaussianBlur`의 커널을 `(0, 0)`으로 주면 시그마로 자동 계산된다
