## 4-1. 데이터를 처음 받았을 때 찍어 보는 것

```python
import pandas as pd

df = pd.read_csv('./data/auto-mpg.csv', header=None)
df.columns = ['mpg', 'cylinders', 'displacement', 'horsepower',
              'weight', 'acceleration', 'model year', 'origin', 'name']
```

**이 파일은 열 이름 줄이 없어서 `header=None`으로 읽고 이름을 직접 붙였다.** 3장에서 본 그 인자다.

### 다섯 줄 점검

```python
df.head()      # 위에서 5줄
df.tail()      # 아래에서 5줄
df.shape       # (398, 9)
df.info()      # 자료형 + 결측 개수
df.dtypes      # 자료형만
```

`info()` 결과:

```
<class 'pandas.DataFrame'>
RangeIndex: 398 entries, 0 to 397
Data columns (total 9 columns):
 #   Column        Non-Null Count  Dtype
---  ------        --------------  -----
 0   mpg           398 non-null    float64
 ...
```

`dtypes` 결과:

```
mpg             float64
cylinders         int64
displacement    float64
horsepower          str      ← 이상하다
weight          float64
acceleration    float64
```

### `horsepower`가 문자열인 이유

마력은 당연히 숫자다. 그런데 문자열로 읽혔다. **원본에 `?`로 적힌 결측이 섞여 있기 때문이다.** 숫자 열에 문자가 하나라도 있으면 열 전체가 문자열이 된다.

`describe(include='all')`이 그 증거를 보여 준다.

```
        horsepower
count          398
unique          94        ← 숫자 열이라면 나오지 않을 항목
top          150.0
freq            22
```

**`unique`, `top`, `freq`는 범주형에만 계산되는 값이다.** 숫자 열에 이것들이 찍혔다면 문자열로 읽혔다는 뜻이다.

```python
df['mpg'].dtypes      # dtype('float64')    특정 열만 확인
```

**`info()`나 `dtypes`를 안 찍고 넘어가면, 나중에 `df['horsepower'].mean()`이 에러를 내거나 이상한 값을 준다.** 5장에서 이 열을 고치는 방법을 다룬다.

## 4-2. `describe` — 기술 통계

```python
df.describe()
```

```
              mpg   cylinders  displacement       weight  acceleration
count  398.000000  398.000000    398.000000   398.000000    398.000000
mean    23.514573    5.454774    193.425879  2970.424623     15.568090
std      7.815984    1.701004    104.269838   846.841774      2.757689
min      9.000000    3.000000     68.000000  1613.000000      8.000000
25%     17.500000    4.000000    104.250000  2223.750000     13.825000
```

| 줄 | 뜻 | 읽는 법 |
| --- | --- | --- |
| `count` | 결측이 아닌 개수 | 398보다 작으면 결측이 있다 |
| `mean` / `std` | 평균 / 표준편차 | |
| `min` / `max` | 최솟값 / 최댓값 | 말이 안 되는 값이 있는지 |
| `25% / 50% / 75%` | 사분위수 | 50%가 중앙값 |

**`mean`과 `50%`(중앙값)를 비교하는 게 요령이다.** 크게 차이 나면 분포가 한쪽으로 쏠렸거나 이상치가 있다는 뜻이다. mpg는 평균 23.51, 중앙값 23.0으로 거의 같으니 대칭에 가깝다.

**`count`가 열마다 다르면 결측의 위치를 바로 알 수 있다.** 여기서는 전부 398이라 겉보기엔 결측이 없다 — 하지만 `horsepower`의 `?`는 결측으로 인식되지 않아 숫자로 세어지지도 않는다. **`count`만 믿으면 안 된다.**

### `include`로 대상을 고른다

```python
df.describe()                            # 숫자 열만 (기본)
df.describe(include='number')            # 같은 뜻
df.describe(include='object')            # 문자열 열만
df.describe(include=['number','object']) # 둘 다
df.describe(include='all')               # 전부
```

`include='object'` 결과:

```
       horsepower        name
count         398         398
unique         94         305
```

**`name`이 305개 고유값이다.** 398대 중 305종이면 차 이름은 분석용 특징이 되기 어렵다. 이런 열은 보통 버리거나 브랜드만 잘라 쓴다.

**참고 — 판다스 4 경고**
```
Pandas4Warning: For backward compatibility, 'object' ... string-migration-select-dtypes
```
판다스가 문자열 dtype을 `object`에서 전용 `str`로 옮기는 중이라, `include='object'`가 앞으로는 문자열 열을 못 잡을 수 있다. 새 코드에서는 `include='str'`을 쓰라는 안내다.

## 4-3. 개수 세기

```python
df.count()
# mpg             398
# cylinders       398
# ...
type(df.count())      # pandas.Series
```

**`count()`는 열별로 "결측이 아닌 개수"를 센다.** 전체 행 수(`len(df)`)와 비교해서 결측을 찾는다.

### 범주별 개수 — `value_counts`

```python
df['origin'].value_counts()
# origin
# 1    249
# 3     79
# 2     70
```

```python
df['origin'].value_counts(normalize=True)
# 1    0.625628
# 3    0.198492
# 2    0.175879

(df['origin'].value_counts(normalize=True) * 100).round(1)
# 1    62.6
# 3    19.8
# 2    17.6
```

**`normalize=True`면 비율, 곱하기 100에 `.round(1)`이면 퍼센트다.**

origin은 1=미국, 2=유럽, 3=일본이다. **미국 차가 62.6%로 절반이 넘는다.** 분류 모델을 만든다면 이 불균형을 고려해야 한다.

`value_counts`는 **기본적으로 결측을 세지 않는다.** 결측도 보려면 `dropna=False`를 준다.

## 4-4. 통계 함수와 상관계수

```python
df.mean(numeric_only=True).round(1)
df['mpg'].mean().round(1)
df.mpg.mean().round(1)              # 점 표기도 된다
df[['mpg','weight']].mean().round(1)
```

**`numeric_only=True`가 꼭 필요하다.** 안 주면 문자열 열(`horsepower`, `name`) 때문에 에러가 나거나 경고가 뜬다. 4-1에서 본 그 문제가 여기서 터진다.

| 함수 | mpg 값 |
| --- | --- |
| `mean()` | 23.5 |
| `median()` | 23.0 |
| `max()` | 46.6 |
| `min()` | 9.0 |
| `std()` | 7.815984 |

### 상관계수

```python
df.corr(numeric_only=True)
df[['mpg','weight']].corr()
```

```
                   mpg  cylinders  displacement    weight  acceleration
mpg           1.000000  -0.775396     -0.804203 -0.831741      0.420289
cylinders    -0.775396   1.000000      0.950721  0.896017     -0.505419
displacement -0.804203   0.950721      1.000000  0.932824     -0.543684
weight       -0.831741   0.896017      0.932824  1.000000     -0.417457
acceleration  0.420289  -0.505419     -0.543684 -0.417457      1.000000
```

**읽는 법**

| 값 | 뜻 |
| --- | --- |
| `+1`에 가까움 | 같이 커진다 |
| `0`에 가까움 | 관계 없음 |
| `−1`에 가까움 | 하나가 커지면 다른 하나가 작아진다 |

여기서 읽히는 것들:

- **`mpg` ↔ `weight` = −0.83** — 무거운 차일수록 연비가 나쁘다. 가장 강한 관계다
- **`mpg` ↔ `displacement` = −0.80**, **`mpg` ↔ `cylinders` = −0.78** — 배기량과 실린더도 같은 방향
- **`displacement` ↔ `cylinders` = 0.95** — 거의 같은 정보다

**마지막 것이 중요하다.** 실린더 수, 배기량, 무게 셋이 서로 0.9 이상으로 얽혀 있다. 회귀 모델에 셋을 다 넣으면 **다중공선성** 때문에 계수 해석이 무의미해진다. 하나만 고르거나 합쳐야 한다.

**상관계수는 인과가 아니다.** 무게가 연비를 떨어뜨린다고 단정할 수 없다. 다만 물리적으로 그럴듯하니 가설로 삼는 것이다.

`corr()`은 기본이 피어슨 상관계수라 **선형 관계만** 잡는다. U자 같은 관계는 0에 가깝게 나온다.

## 4-5. 판다스 내장 그래프

`matplotlib`을 직접 안 불러도 `df.plot()` 한 줄이면 그려진다.

```python
df = pd.read_excel('./data/남북한발전전력량 (1).xlsx')

df_ns = df.iloc[[0, 5], 3:]      # 0행(남한 합계)과 5행(북한 합계), 3번째 열부터
df_ns.index = ['South', 'North']
df_ns = df_ns.astype(int)
```

**`.astype(int)`가 필요한 이유** — 엑셀에서 읽으면 숫자가 문자열로 들어오는 경우가 많다. 3장에서 본 그 문제다. 형을 바꿔야 그래프가 그려진다.

`iloc[[0,5], 3:]`은 **행은 번호 리스트로, 열은 3번째부터 끝까지**를 고른다.

### 선그래프 — 축을 뒤집어야 한다

```python
df_ns.plot()         # 연도가 열이라 x축이 South/North가 된다
```

```python
tdf_ns = df_ns.T     # 전치
print(tdf_ns.head())
#       South  North
# 1991   1186    263
# 1992   1310    247
# 1993   1444    221

tdf_ns.plot();
```

**판다스는 인덱스를 x축, 열을 선으로 그린다.** 연도가 열에 있으면 그림이 뒤집히므로 `.T`로 세운다. **시계열은 "시간이 인덱스"여야 한다**는 게 규칙이다.

끝의 세미콜론(`;`)은 주피터에서 `<Axes: >` 같은 객체 표시를 숨긴다.

### `kind`로 종류를 바꾼다

```python
tdf_ns.plot(kind='bar')                    # 세로 막대
tdf_ns.plot(kind='barh')                   # 가로 막대
tdf_ns.plot(kind='bar', stacked=True)      # 누적 막대
tdf_ns.plot(kind='hist')                   # 히스토그램
df.plot(x='weight', y='mpg', kind='scatter')   # 산점도
```

| `kind` | 언제 쓰나 |
| --- | --- |
| `line` (기본) | 시간에 따른 변화 |
| `bar` / `barh` | 범주별 크기 비교. 항목 이름이 길면 `barh` |
| `bar(stacked=True)` | 전체 대비 구성 비율 |
| `hist` | 한 변수의 분포 |
| `scatter` | 두 변수의 관계 |
| `box` | 분포 + 이상치 |

**산점도에는 `x`와 `y`를 반드시 지정한다.** 다른 종류는 인덱스를 자동으로 x축에 쓰지만 산점도는 아니다.

### 서식

```python
tdf_ns.plot(kind='hist',
            alpha=0.5,          # 투명도 0~1
            figsize=(6, 2),     # 크기 (가로, 세로) 인치
            grid=True,          # 격자
            color='skyblue',    # 색
            edgecolor='black')  # 테두리
```

**겹치는 그래프에는 `alpha`가 필수다.** 불투명하면 뒤엣것이 가려진다.

### `.plot(kind='hist')`와 `.hist()`는 다르다

```python
tdf_ns.plot(kind='hist', figsize=(6,2))   # 한 축에 겹쳐 그린다
tdf_ns.hist(figsize=(6,2))                # 열마다 축을 따로 만든다
tdf_ns.hist(bins=20, grid=False, figsize=(6,2))
```

출력의 `with 1 Axes` / `with 2 Axes` 차이가 그것이다. **비교하려면 `plot(kind='hist')`, 각각 보려면 `.hist()`다.**

`bins`는 막대 개수다. 너무 적으면 뭉개지고 너무 많으면 들쭉날쭉해진다.

## 4-6. 노트북에서 발견한 오류

`01_선그래프.ipynb`의 세 번째 셀이 `KeyError`로 멈춰 있다.

```python
mask = (df['전출지별'] == '서울특별시') & (df['전입지별'] != '서울특별시')
df_seoul = df[mask]
df_seoul = df_seoul.drop(['전출지별'], axis=1)
df_seoul.rename({'전입지별': '전입지'}, axis=1)    # ← 결과를 안 받았다
df_seoul.set_index('전입지')                      # ← KeyError
df_seoul
```

```
KeyError: "None of ['전입지'] are in the columns"
```

**`rename`의 결과를 변수에 담지 않아서 열 이름이 안 바뀌었다.** 그 상태로 `set_index('전입지')`를 부르니 그런 열이 없다는 에러가 난다. 2장에서 본 "결과를 받아야 한다" 규칙이다.

고치면 이렇다.

```python
df_seoul = df_seoul.rename({'전입지별': '전입지'}, axis=1)
df_seoul = df_seoul.set_index('전입지')
```

또는 체이닝으로:

```python
df_seoul = (df[mask]
            .drop(['전출지별'], axis=1)
            .rename({'전입지별': '전입지'}, axis=1)
            .set_index('전입지'))
```

**체이닝으로 쓰면 결과를 안 받는 실수가 구조적으로 불가능해진다.**

이 셀이 실패해서 **서울 전출입 선그래프는 노트북에 없다.** 그 실습은 미완이다.

### `ffill`로 병합 셀 메우기

같은 노트북의 앞 셀은 정상이다.

```python
df = df.ffill()
```

```
전출지별  전입지별
전국     전국
NaN     서울특별시      →    전국    서울특별시
NaN     부산광역시      →    전국    부산광역시
```

**엑셀 병합 셀은 첫 행에만 값이 있고 나머지가 `NaN`이다.** `ffill`(forward fill)이 위 값을 아래로 흘려보낸다. 3장에서 본 `남북한발전전력량.xlsx`도 같은 처리가 필요하다.

## 이 장 정리

### 데이터를 받으면 이 순서로 본다

```python
df.shape                 # 1. 크기가 예상과 맞나
df.head()                # 2. 열 이름과 첫 줄이 제대로 잡혔나
df.info()                # 3. 자료형과 결측
df.describe()            # 4. 분포 — mean vs 50%, min/max가 말이 되나
df['범주열'].value_counts()  # 5. 범주 비율
df.corr(numeric_only=True)   # 6. 변수 간 관계
```

### 이상 신호와 원인

| 신호 | 의심할 것 |
| --- | --- |
| 숫자 열의 dtype이 `str`/`object` | `?`, `-`, `N/A` 같은 결측 표기가 섞였다 |
| `describe`에 `unique`/`top`이 나온다 | 그 열은 범주형으로 인식됐다 |
| `count`가 열마다 다르다 | 결측이 있다 |
| `mean`과 `50%`가 크게 다르다 | 쏠린 분포 또는 이상치 |
| 두 변수의 상관이 0.9 이상 | 같은 정보. 다중공선성 |
| 고유값이 행 수에 가깝다 | 식별자에 가깝다. 특징으로 부적합 |

### 자주 틀리는 것

- `info()`/`dtypes`를 안 찍고 분석을 시작한다
- `numeric_only=True`를 빼먹는다 → 문자열 열에서 에러
- `count`만 보고 결측이 없다고 판단한다 → `?` 같은 표기는 안 잡힌다
- 시계열에서 시간을 열에 둔 채 그린다 → `.T`로 인덱스에 올린다
- 산점도에 `x`, `y`를 안 준다
- `rename` / `set_index` 결과를 안 받는다 → `KeyError`
- 상관계수를 인과로 읽는다
