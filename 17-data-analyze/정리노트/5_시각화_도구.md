## 5-1. 한글 폰트 설정

```python
plt.plot(sr_one.index, sr_one.values, linestyle='--')
plt.title('서울 -> 경기 인구 이동')
plt.xlabel('기간')
plt.ylabel('이동 인구수')
plt.show()
```

```
UserWarning: Glyph ... missing from font(s) DejaVu Sans.
```

**한글이 전부 네모(□)로 나온다.** matplotlib의 기본 폰트에 한글이 없다.

```python
from matplotlib import font_manager, rc

font_path = './data/malgun.ttf'
font_name = font_manager.FontProperties(fname=font_path).get_name()
rc('font', family=font_name)
```

| 줄 | 하는 일 |
| --- | --- |
| `FontProperties(fname=...)` | 폰트 파일을 읽는다 |
| `.get_name()` | 그 폰트의 **내부 이름**을 얻는다 (`'Malgun Gothic'`) |
| `rc('font', family=...)` | 전역 기본 폰트로 지정 |

**파일 경로가 아니라 폰트 이름을 넘겨야 한다.** `rc('font', family='./data/malgun.ttf')`는 동작하지 않는다.

윈도우라면 `C:\Windows\Fonts\malgun.ttf`를 복사해 두면 된다. 맥은 `AppleGothic`, 리눅스는 나눔고딕을 쓴다.

**마이너스 기호도 깨진다.** 한 줄 더 필요하다.

```python
plt.rcParams['axes.unicode_minus'] = False
```

> **중요 — 폰트 설정은 그림을 그리기 전에 한다.**
> `quiz.ipynb`에는 `plt.plot(...)`과 `plt.title(...)`을 먼저 하고 그 아래에서 `rc('font', ...)`를 부르는 셀이 있다. 그 셀은 `TypeError: 'value' must be an instance of str or bytes, not a int`로 중단됐다. 설정은 **노트북 맨 위에서 한 번** 해 두는 게 맞다.

## 5-2. matplotlib 기본

데이터 준비부터 보자.

```python
df = pd.read_excel('./data/시도별_전출입_인구수.xlsx')
df = df.ffill()                       # 엑셀 병합 셀 메우기

mask = (df['전출지별'] == '서울특별시') & (df['전입지별'] != '서울특별시')
df_seoul = df[mask]
df_seoul = df_seoul.drop(['전출지별'], axis=1)
df_seoul = df_seoul.rename({'전입지별': '전입지'}, axis=1)
df_seoul = df_seoul.set_index('전입지')

sr_one = df_seoul.loc['경기도']
```

**4장에서 `KeyError`로 실패했던 그 코드의 고친 버전이다.** `rename`과 `set_index`의 결과를 제대로 받았다.

`전출지별 == '서울특별시'`이면서 `전입지별 != '서울특별시'`인 행만 고른다. 서울에서 서울로 가는 이동을 빼는 것이다.

### 그리기

```python
plt.plot(sr_one.index, sr_one.values)   # x, y를 따로
plt.plot(sr_one)                        # 시리즈를 그대로 (인덱스가 x축)
plt.show()
```

둘 다 된다. 시리즈를 그대로 넣으면 인덱스가 자동으로 x축이 된다.

### 꾸미기

```python
plt.style.use('ggplot')                      # 전체 스타일

plt.figure(figsize=(14, 5))                  # 크기
plt.xticks(size=10, rotation='vertical')     # x축 눈금 세로로

plt.plot(sr_one.index, sr_one.values,
         marker='o',                 # 점 모양
         markerfacecolor='red',      # 점 안쪽 색
         markeredgecolor='blue',     # 점 테두리 색
         markeredgewidth=2,
         markersize=10)

plt.title('서울 -> 경기 인구 이동', size=30)
plt.xlabel('기간', size=20)
plt.ylabel('이동 인구수', size=20)
plt.legend(labels=['서울 -> 경기'], loc='best', fontsize=15)
plt.show()
```

| 함수 | 역할 |
| --- | --- |
| `plt.style.use('ggplot')` | 배경·색 세트를 한 번에 |
| `plt.figure(figsize=(가로, 세로))` | 그림 크기 (인치) |
| `plt.xticks(rotation='vertical')` | 눈금이 겹칠 때 세운다 |
| `linestyle='--'` | 점선 |
| `marker='o'` | 데이터 점 표시 |
| `plt.legend(loc='best')` | 범례. `'best'`면 알아서 빈 곳에 |

**x축 라벨이 겹치면 `rotation`을 먼저 시도한다.** 연도가 48개면 가로로는 절대 안 들어간다.

> **주의 — `plt.figure()`를 `plt.plot()` 뒤에 부르면 빈 그림이 하나 더 생긴다.** 위 코드에서는 `figure` → `plot` 순서라 괜찮다.

## 5-3. Figure와 Axes — 객체 지향 방식

`plt.plot()` 방식은 "현재 그림"에 그린다. 그림이 여러 개면 헷갈린다.

```python
fig = plt.figure()
print(fig)               # Figure(640x480)      ← 도화지만 있고 축이 없다

fig, axe = plt.subplots()
print(fig)               # Figure(640x480)
print(axe)               # Axes(0.125,0.11;0.775x0.77)
```

| 객체 | 뜻 |
| --- | --- |
| **Figure** | 도화지 전체 |
| **Axes** | 그 안의 그래프 하나 (축이 있는 영역) |

**`plt.subplots()`가 둘을 한 번에 만들어 준다.** 실무에서는 거의 이 방식을 쓴다.

```python
fig, axe = plt.subplots(figsize=(8, 2))
axe.plot(samsung_revenue['quarter'], samsung_revenue['value'])
plt.show()
```

### 여러 개 배치

```python
fig, axes = plt.subplots(1, 2)          # 1행 2열
print(axes)      # [<Axes: > <Axes: >]           ← 1차원 배열

fig, axes = plt.subplots(2, 2)
print(axes)      # [[<Axes: > <Axes: >]
                 #  [<Axes: > <Axes: >]]         ← 2차원 배열
```

**`subplots(1, 2)`는 1차원, `subplots(2, 2)`는 2차원 배열을 준다.** 접근 방법이 달라진다.

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 2))
axes[0].plot(samsung_revenue['quarter'], samsung_revenue['value'])
samsung_revenue['value'].plot(ax=axes[1])          # 판다스 plot도 ax를 받는다
plt.show()

fig, axes = plt.subplots(2, 2, figsize=(12, 2), constrained_layout=True)
axes[0, 1].plot(...)                               # 2차원은 [행, 열]
plt.show()
```

**판다스의 `.plot(ax=...)`으로 matplotlib 축에 얹을 수 있다.** 두 방식을 섞어 쓸 수 있다는 뜻이다.

`constrained_layout=True`는 라벨이 겹치지 않게 간격을 자동 조정한다. `plt.tight_layout()`도 같은 역할이다.

### 데이터 정렬을 잊지 않는다

```python
samsung_revenue = pd.read_csv('./data/삼성전자_분기별_매출액.csv')
samsung_revenue = samsung_revenue.sort_values('quarter')
#             value  quarter
# 5  77203607000000  2022-Q2
# 4  76781680000000  2022-Q3
# 3  70464575000000  2022-Q4
# 2  63745371000000  2023-Q1
```

**시계열은 그리기 전에 반드시 정렬한다.** 순서가 섞여 있으면 선이 앞뒤로 튀는 그림이 나온다. `'2022-Q2'` 같은 문자열도 사전순 정렬이 시간순과 일치해서 이 경우는 잘 맞는다.

## 5-4. seaborn 분포 그래프

seaborn은 matplotlib 위에 얹힌 라이브러리다. **`data=`에 데이터프레임을 주고 열 이름으로 지정**하는 게 특징이다.

```python
import seaborn as sns
titanic = sns.load_dataset('titanic')
```

### `displot` — 분포를 나눠서 본다

```python
sns.displot(data=titanic, x='fare', col='pclass', kind='hist')
# Figure size 1500x500 with 3 Axes       ← 객실 등급 3개만큼 옆으로

sns.displot(data=titanic, x='fare', row='survived', kind='kde', fill=True)
# Figure size 500x1000 with 2 Axes       ← 생존 여부 2개만큼 아래로

sns.displot(data=titanic, x='fare', col='pclass', row='survived')
# Figure size 1500x1000 with 6 Axes      ← 3 × 2 = 6개
```

**`col`과 `row`가 seaborn의 핵심이다.** 범주별로 그래프를 자동으로 쪼개 준다. matplotlib으로 하면 `subplots`와 반복문을 직접 짜야 한다.

| `kind` | 그림 |
| --- | --- |
| `hist` | 막대 히스토그램 |
| `kde` | 부드러운 곡선 (커널 밀도) |
| `ecdf` | 누적 분포 |

`fill=True`는 곡선 아래를 채운다.

### 두 변수의 분포

```python
sns.displot(x='fare', y='age', data=titanic, kind='kde')
sns.displot(x='fare', y='age', data=titanic, kind='kde', fill=True)
sns.displot(x='fare', y='age', data=titanic, kind='hist')
```

**`x`와 `y`를 둘 다 주면 2차원 분포가 된다.** 등고선처럼 밀집 구역이 보인다.

### 히트맵 — 교차표를 색으로

```python
table = titanic.pivot_table(index=['sex'], columns=['class'],
                            aggfunc='size', observed=False)
# class   First  Second  Third
# sex
# female     94      76    144
# male      122     108    347

sns.heatmap(table,
            annot=True,      # 숫자 표시
            fmt='d',         # 정수 형식
            cmap='YlGnBu',   # 색 팔레트
            linewidth=.5,
            cbar=False)      # 색 막대 숨기기
```

**`aggfunc='size'`는 개수를 센다.** 3등석 남성이 347명으로 가장 많다.

`annot=True`와 `fmt='d'`는 짝이다. `fmt`를 빼면 `3.5e+02` 같은 지수 표기가 나온다.

## 5-5. seaborn 범주형 그래프

### 점으로 흩뿌리기

```python
sns.set_style('whitegrid')
fig, axes = plt.subplots(1, 2, figsize=(15, 5))

sns.stripplot(x='class', y='age', data=titanic, ax=axes[0])
sns.swarmplot(x='class', y='age', data=titanic, ax=axes[1], hue='sex', size=4)

axes[0].set_title('Strip Plot')
axes[1].set_title('Swarm Plot')
```

| | `stripplot` | `swarmplot` |
| --- | --- | --- |
| 점 배치 | 무작위로 조금씩 흔든다 | **겹치지 않게** 좌우로 밀어낸다 |
| 데이터 양 | 많아도 된다 | 많으면 느리고 경고가 뜬다 |

**`hue='sex'`를 주면 색으로 한 차원을 더 넣는다.** seaborn 전반에서 통하는 인자다.

### 막대그래프 — `estimator`와 `errorbar`

```python
fig, axes = plt.subplots(2, 2, figsize=(10, 6), constrained_layout=True)

sns.barplot(x='sex', y='survived', data=titanic, ax=axes[0,0])
sns.barplot(x='sex', y='survived', data=titanic, errorbar=None, ax=axes[0,1])
sns.barplot(x='sex', y='survived', hue='class', data=titanic, ax=axes[1,0],
            errorbar=('ci', 95), estimator='median')
sns.barplot(x='sex', y='survived', hue='class', dodge=False, data=titanic, ax=axes[1,1])
```

**`barplot`의 막대 높이는 원값이 아니라 집계값이다.** 기본은 평균이다. `survived`가 0/1이므로 평균이 곧 생존율이 된다.

| 인자 | 뜻 |
| --- | --- |
| `estimator` | 집계 방법. 기본 `'mean'`, `'median'`·`'sum'`도 가능 |
| `errorbar=None` | 오차막대 끄기 |
| `errorbar=('ci', 95)` | 95% 신뢰구간 |
| `hue` | 색으로 나누기 |
| `dodge=False` | 나눈 막대를 **겹쳐서** 그린다 |

**`estimator='median'`을 0/1 데이터에 쓰면 중앙값이 0 아니면 1이라 막대가 뭉뚝해진다.** 비율을 보려면 평균이 맞다. 인자를 바꿔 보는 실습으로 이해하면 된다.

`dodge=False`는 막대를 나란히 두지 않고 포개므로, 비교용으로는 기본값(`True`)이 낫다.

### 상자그림과 바이올린

```python
fig, axes = plt.subplots(2, 2, figsize=(15, 10))

sns.boxplot(x='alive', y='age', data=titanic, ax=axes[0,0])
sns.boxplot(x='alive', y='age', hue='sex', data=titanic, ax=axes[0,1])
sns.violinplot(x='alive', y='age', data=titanic, ax=axes[1,0])
sns.violinplot(x='alive', y='age', hue='sex', data=titanic, ax=axes[1,1])
```

| | 보여 주는 것 |
| --- | --- |
| `boxplot` | 사분위수 + 이상치 점 |
| `violinplot` | 분포의 **모양**까지 |

**상자그림은 봉우리가 둘인 분포를 놓친다.** 상자 모양이 같아도 실제 분포가 전혀 다를 수 있다. 바이올린이 그걸 드러낸다.

### 산점도 + 분포

```python
sns.jointplot(x='fare', y='age', data=titanic)              # 산점도 + 히스토그램
sns.jointplot(x='fare', y='age', kind='reg', data=titanic)  # + 회귀선
sns.jointplot(x='fare', y='age', kind='hex', data=titanic)  # 육각형 밀도
sns.jointplot(x='fare', y='age', kind='kde', data=titanic)  # 등고선
```

**가운데 산점도와 위·오른쪽 히스토그램을 한 번에 준다.** 출력의 `with 3 Axes`가 그 셋이다.

`kind='hex'`는 점이 너무 많아 뭉칠 때 쓴다.

### 스타일

```python
sns.set_style('darkgrid')    # 회색 배경 + 흰 격자
sns.set_style('whitegrid')   # 흰 배경 + 회색 격자
sns.set_style('ticks')       # 격자 없이 눈금만
```

**`set_style`은 전역 설정이라 이후 모든 그래프에 적용된다.**

## 5-6. folium 지도

```python
import folium

seoul_map = folium.Map(location=[37.55, 126.98], zoom_start=12)
seoul_map
```

**`location`은 `[위도, 경도]` 순서다.** 3장 카카오 API에서 `y`가 위도, `x`가 경도였던 것과 이어진다. 순서를 바꾸면 엉뚱한 나라가 나온다.

`zoom_start`가 클수록 확대된다 (12면 도시 수준).

```python
seoul_map2 = folium.Map(location=[37.55, 126.98],
                        tiles="Cartodb Positron",
                        zoon_start=12)      # ← 오타
```

> **주의 — `zoon_start`는 오타다.** `zoom_start`여야 한다. folium은 모르는 인자를 조용히 무시하므로 **에러 없이 기본 배율(10)로 그려진다.** 확대가 안 되는데 이유를 못 찾는 전형적인 경우다.

`tiles`는 지도 배경이다. `"Cartodb Positron"`은 흰 바탕이라 마커가 잘 보인다.

### 마커 찍기

```python
df = pd.read_excel('./data/서울지역_대학교_위치.xlsx')

seoul_map = folium.Map(location=[37.55, 126.98],
                       tiles="Cartodb Positron", zoom_start=12)

for name, lat, lng in zip(df.index, df['위도'], df['경도']):
    folium.Marker([lat, lng], popup=name).add_to(seoul_map)

seoul_map
```

**`zip`으로 여러 열을 동시에 돌리는 것이 관용구다.** 각 행에서 `.add_to(지도)`로 마커를 붙인다.

**주의 — 팝업에 학교 이름이 안 나온다.**
엑셀의 실제 구조는 이렇다.
```
columns: ['Unnamed: 0', '위도', '경도']
index:   [0, 1, 2, ...]

     Unnamed: 0         위도          경도
0  KAIST 서울캠퍼스   37.592573  127.046737
1         KC대학교   37.548345  126.854797
```
학교 이름은 **첫 번째 열**에 있고 인덱스는 0, 1, 2…다. `zip(df.index, ...)`를 쓰면 팝업에 `0`, `1`, `2`가 찍힌다.

고치는 방법은 둘 중 하나다.
```python
df = pd.read_excel('./data/서울지역_대학교_위치.xlsx', index_col=0)   # 이름을 인덱스로
# 또는
for name, lat, lng in zip(df['Unnamed: 0'], df['위도'], df['경도']):
```
**`read_excel` 직후에 `df.head()`와 `df.index`를 찍어 봤다면 바로 보였을 문제다.** 4장에서 말한 그 습관이다.

지도를 파일로 남기려면 `seoul_map.save('./data/seoul.html')`이다. 실제로 `04_시각화도구/data/seoul.html`이 저장돼 있다.

## 이 장 정리

### 도구를 고르는 기준

| 상황 | 도구 |
| --- | --- |
| 데이터를 빠르게 훑는다 | `df.plot()` (4장) |
| 세밀하게 조정해 보여 준다 | matplotlib |
| 범주별로 쪼개서 비교한다 | **seaborn** (`col`, `row`, `hue`) |
| 위경도가 있다 | folium |

### matplotlib 두 가지 방식

```python
# pyplot 방식 — 빠르다
plt.plot(x, y)
plt.title('제목')
plt.show()

# 객체 지향 방식 — 여러 그래프에 안전하다
fig, axes = plt.subplots(2, 2, figsize=(12, 8), constrained_layout=True)
axes[0, 0].plot(x, y)
axes[0, 0].set_title('제목')      # plt.title 이 아니라 axes.set_title
plt.show()
```

**Axes에서는 `set_` 접두사가 붙는다.** `plt.title` → `axes.set_title`, `plt.xlabel` → `axes.set_xlabel`.

### 노트북 맨 위에 둘 설정

```python
import matplotlib.pyplot as plt
from matplotlib import font_manager, rc

font_path = './data/malgun.ttf'
rc('font', family=font_manager.FontProperties(fname=font_path).get_name())
plt.rcParams['axes.unicode_minus'] = False
```

### 자주 틀리는 것

- 한글이 □로 나온다 → 폰트 설정. **그리기 전에** 한다
- 마이너스가 깨진다 → `axes.unicode_minus = False`
- `rc('font', family=...)`에 파일 경로를 넣는다 → 폰트 **이름**이 필요하다
- 시계열을 정렬 없이 그린다 → 선이 앞뒤로 튄다
- `subplots(1,2)`와 `(2,2)`의 인덱싱을 헷갈린다 → 1차원 `axes[0]` / 2차원 `axes[0,1]`
- folium에 `[경도, 위도]` 순서로 넣는다 → `[위도, 경도]`
- folium 인자 오타(`zoon_start`) → **조용히 무시된다**
- `zip(df.index, ...)`로 이름을 꺼내려 한다 → 인덱스가 이름이 아닐 수 있다
- x축 라벨이 겹친다 → `rotation='vertical'`
- `annot=True`에 `fmt`를 안 준다 → 지수 표기가 나온다
