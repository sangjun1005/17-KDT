## 3-1. 정확도의 함정

> `3/3_1.ipynb`

### 개념

정확도(Accuracy) = 맞힌 개수 / 전체 개수. 직관적이지만 두 가지 상황에서 무너진다.

1. 데이터에 편향이 있을 때 (타이타닉: 여성 생존율이 압도적)
2. 한쪽 클래스가 극단적으로 적을 때 (불균형 데이터)

### 실험 1: 아무것도 학습하지 않는 분류기

```python
from sklearn.base import BaseEstimator
import numpy as np

class MyDummyClassifier(BaseEstimator):
    def fit(self, X, y=None):
        pass                      # 학습을 아예 안 한다

    def predict(self, X):
        pred = np.zeros((X.shape[0], 1))
        for i in range(X.shape[0]):
            if X['Sex'].iloc[i] == 1:   # 남성이면
                pred[i] = 0             # 사망
            else:
                pred[i] = 1             # 여성이면 생존
        return pred
```

결과: **정확도 0.7877**

성별만 보고 찍었는데 79%가 나온다.
앞 장에서 열심히 학습시킨 결정트리가 78%였으니, 학습이 사실상 무의미했다는 뜻이다.

## 3-2. 오차 행렬 (Confusion Matrix)

### 개념

정확도 하나로는 안 되니 예측 결과를 네 칸으로 쪼개서 본다.

```python
from sklearn.metrics import confusion_matrix
confusion_matrix(y_test, fakepred)
# array([[405,   0],
#        [ 45,   0]])
```

|  | 예측 0 (Negative) | 예측 1 (Positive) |
|---|---|---|
| **실제 0** | TN (405) | FP (0) |
| **실제 1** | FN (45) | TP (0) |

- **TN**: 아니라고 예측했고 실제로 아님 (맞음)
- **FP**: 맞다고 예측했는데 아님 — 거짓 경보
- **FN**: 아니라고 예측했는데 맞음 — 놓침
- **TP**: 맞다고 예측했고 실제로 맞음 (맞음)

오른쪽 열이 전부 0이다. 이 모델은 **1을 단 한 번도 예측하지 않았다.**
정확도 0.9라는 숫자 뒤에 이 사실이 숨어 있었다.

## 3-3. 정밀도와 재현율

### 개념

오차 행렬의 네 칸으로 만드는 두 지표다. 둘 다 **Positive(1) 예측에만 관심을 둔다.**

- **정밀도(Precision) = TP / (TP + FP)**
  모델이 1이라고 한 것 중에 진짜 1의 비율. → "네가 맞다고 한 거, 얼마나 믿을 만해?"

- **재현율(Recall) = TP / (TP + FN)**
  실제 1 중에서 모델이 잡아낸 비율. → "실제로 있는 거, 얼마나 놓치지 않고 찾았어?"

### 어느 쪽이 더 중요한가

**재현율이 중요한 경우** — 놓치면 큰일 나는 문제

- 암 진단: 암 환자를 정상이라고 하면(FN) 치명적. 정상인을 암이라고 해도(FP) 재검사하면 된다
- 금융 사기 탐지: 사기를 놓치면 돈이 나간다
- 스팸 반대편: 보험 사기, 침입 탐지

**정밀도가 중요한 경우** — 잘못 걸면 피해가 큰 문제

- 스팸 메일 분류: 중요한 업무 메일을 스팸으로 보내면(FP) 큰일. 스팸 몇 개 놓치는 건(FN) 참을 만하다

### 코드

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, confusion_matrix

def get_clf_eval(y_test, pred):
    confusion = confusion_matrix(y_test, pred)
    accuracy  = accuracy_score(y_test, pred)
    precision = precision_score(y_test, pred)
    recall    = recall_score(y_test, pred)
    print(confusion)
    print(accuracy, precision, recall)
```

타이타닉 + 로지스틱 회귀 결과:

```
[[108  10]
 [ 14  47]]
정확도 0.866   정밀도 0.825   재현율 0.770
```

FN이 14명. 실제로 생존했는데 사망으로 예측한 사람이 14명이라는 뜻이다.

## 3-4. 임계값 조정으로 정밀도/재현율 맞바꾸기

### 개념

분류 모델은 사실 0/1을 바로 내놓지 않는다. **1일 확률**을 계산한 다음
그게 0.5보다 크면 1로 바꿔서 준다. 이 0.5가 임계값(threshold)이다.

이 기준을 낮추면 1로 판정되는 게 늘어난다 → 재현율 올라감, 정밀도 내려감.
높이면 반대다. **둘은 한쪽을 올리면 다른 쪽이 내려가는 트레이드오프 관계다.**

### predict_proba로 확률 확인

```python
pred_prob = lr_clf.predict_proba(X_test)
print(pred_prob[:3])
# [[0.449 0.551]     ← 0일 확률 0.449, 1일 확률 0.551 → 1로 예측
#  [0.863 0.137]
#  [0.864 0.136]]
```

`predict_proba`는 (샘플 수, 클래스 수) 형태를 준다. 보통 `[:, 1]`(Positive 확률)만 쓴다.

### Binarizer로 임계값 바꾸기

```python
from sklearn.preprocessing import Binarizer

custom_threshold = 0.4
pred_prob_1 = pred_prob[:, 1].reshape(-1, 1)

binarizer = Binarizer(threshold=custom_threshold).fit(pred_prob_1)
custom_predict = binarizer.transform(pred_prob_1)

get_clf_eval(y_test, custom_predict)
```

### 임계값별 결과 (타이타닉)

```python
thresholds = [0.4, 0.45, 0.50, 0.55, 0.60]

def get_eval_by_threshold(y_test, pred_proba_c1, thresholds):
    for custom_threshold in thresholds:
        binarizer = Binarizer(threshold=custom_threshold).fit(pred_proba_c1)
        custom_predict = binarizer.transform(pred_proba_c1)
        print('임곗값:', custom_threshold)
        get_clf_eval(y_test, custom_predict)

get_eval_by_threshold(y_test, pred_prob[:, 1].reshape(-1, 1), thresholds)
```

| 임계값 | 정확도 | 정밀도 | 재현율 |
|---|---|---|---|
| 0.40 | 0.821 | 0.704 | **0.820** |
| 0.45 | 0.855 | 0.787 | 0.787 |
| 0.50 | 0.866 | 0.825 | 0.770 |
| 0.55 | — | — | — |
| 0.60 | 0.877 | **0.898** | 0.721 |

임계값이 올라갈수록 정밀도는 0.70 → 0.90, 재현율은 0.82 → 0.72.
정확히 반대로 움직인다.

### 시각화

```python
from sklearn.metrics import precision_recall_curve

precisions, recalls, thresholds = precision_recall_curve(y_test, pred_prob_c1)
```

주의: `precisions`, `recalls`는 `thresholds`보다 **길이가 1 더 길다**.
그래서 그릴 때 `precisions[0:threshold_boundary]`로 잘라 맞춘다.

```python
def precision_recall_curve_plot(y_test, pred_prob_c1):
    precisions, recalls, thresholds = precision_recall_curve(y_test, pred_prob_c1)
    threshold_boundary = thresholds.shape[0]

    plt.plot(thresholds, precisions[0:threshold_boundary], linestyle='--', label='precision')
    plt.plot(thresholds, recalls[0:threshold_boundary], label='recall')
    plt.xlabel('Threshold value')
    plt.legend(); plt.grid(); plt.show()
```

두 곡선이 교차하는 지점 근처가 균형점이다. 다만 실제로는 균형점이 아니라
**문제가 뭘 요구하느냐**에 따라 임계값을 정한다.

## 3-5. F1 스코어

### 개념

정밀도와 재현율을 하나로 합친 값. **조화평균**을 쓴다.

```
F1 = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)
```

산술평균이 아니라 조화평균인 이유: 한쪽이 극단적으로 낮으면 F1도 확 떨어진다.
정밀도 1.0, 재현율 0.01이면 산술평균은 0.505지만 F1은 0.0198이다.
**한쪽만 잘하는 모델을 걸러내기 위한 지표**다.

```python
from sklearn.metrics import f1_score
f1 = f1_score(y_test, pred)
print(f1)   # 0.7966
```

## 3-6. ROC 곡선과 AUC

### 개념

임계값을 0부터 1까지 전부 바꿔가면서 그린 곡선이다.

- **TPR (= 재현율)**: 실제 1 중에 1로 맞힌 비율. 높을수록 좋다
- **FPR**: 실제 0 중에 1로 잘못 예측한 비율. 낮을수록 좋다

가로축 FPR, 세로축 TPR로 그린다. **왼쪽 위로 붙을수록 좋은 모델**이다.
대각선은 찍기(랜덤)와 같은 수준을 뜻한다.

**AUC**는 이 곡선 아래 면적이다.

| AUC | 의미 |
|---|---|
| 1.0 | 완벽 |
| 0.9~ | 매우 좋음 |
| 0.8~ | 좋음 |
| 0.5 | 찍는 것과 동일 |

### 코드

```python
from sklearn.metrics import roc_curve, roc_auc_score

pred_proba_class1 = lr_clf.predict_proba(X_test)[:, 1]
fprs, tprs, thresholds = roc_curve(y_test, pred_proba_class1)

print(roc_auc_score(y_test, pred_proba_class1))   # 0.8987
```

```python
def roc_curve_plot(y_test, pred_proba_c1):
    fprs, tprs, thresholds = roc_curve(y_test, pred_proba_c1)
    plt.plot(fprs, tprs, label='ROC')
    plt.plot([0, 1], [0, 1], 'k--', label='Random')   # 대각선 = 랜덤
    plt.xlim(0, 1); plt.ylim(0, 1)
    plt.xlabel('FPR(1-Specificity)'); plt.ylabel('TPR(Recall)')
    plt.legend(); plt.show()
```

**중요**: `roc_auc_score`와 `precision_recall_curve`에는 `predict()` 결과가 아니라
**`predict_proba()`의 확률값**을 넣어야 한다. 0/1을 넣으면 곡선을 그릴 수 없다.

## 3-7. 실습: 피마 인디언 당뇨병 예측

> `3/3_2.ipynb`

### 평가 함수 완성형

```python
def get_clf_eval(y_test, pred=None, pred_proba=None):
    confusion = confusion_matrix(y_test, pred)
    accuracy  = accuracy_score(y_test, pred)
    precision = precision_score(y_test, pred)
    recall    = recall_score(y_test, pred)
    f1        = f1_score(y_test, pred)
    roc_auc   = roc_auc_score(y_test, pred_proba)   # 확률값을 받는다
    print('Confusion Matrix', confusion)
    print(accuracy, precision, recall, f1, roc_auc)
```

이 함수는 4장 이후에도 계속 재사용된다.

### 1) 기본 모델

```python
X = diabetes_data.iloc[:, :-1]
y = diabetes_data.iloc[:, -1]

X_train, X_test, y_train, y_test = train_test_split(

pred = lr_clf.predict(X_test)
pred_proba = lr_clf.predict_proba(X_test)[:, 1]

get_clf_eval(y_test, pred, pred_proba)
```

```
정확도 0.708   정밀도 0.588   재현율 0.556   F1 0.571   AUC 0.830
```

재현율 0.556. **당뇨 환자의 절반 가까이를 놓치고 있다.** 의료 문제에서는 심각한 수치다.

## 이 장 정리

| 지표 | 계산 | 언제 보나 |
|---|---|---|
| 정확도 | (TP+TN)/전체 | 클래스가 균형 잡혔을 때만 |
| 정밀도 | TP/(TP+FP) | 잘못 걸면 손해일 때 (스팸 분류) |
| 재현율 | TP/(TP+FN) | 놓치면 손해일 때 (암 진단, 사기 탐지) |
| F1 | 정밀도·재현율 조화평균 | 둘 다 균형 있게 볼 때 |
| ROC-AUC | ROC 곡선 아래 면적 | 임계값과 무관한 전체 성능 비교 |

기억할 것

- 불균형 데이터에서 정확도는 거짓말을 한다
- 정밀도와 재현율은 트레이드오프다. 문제에 따라 어느 쪽을 살릴지 정한다
- 임계값 조정만으로도 성능이 크게 바뀐다
- `roc_auc_score`에는 `predict_proba()` 결과를 넣는다
