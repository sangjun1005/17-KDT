# RAG — 전체 개요

`17-KDT/17-RAG` — **검색으로 지식을 넣는다.** 모델을 다시 학습시키지 않고.
그리고 그 과정에서 허깅페이스·로컬 LLM·이미지 생성까지 한 바퀴 돈다.

> **2026-10-07 — 서비스까지 갔다.**
> 노트북 **1개**(`TotalAI.ipynb`, **8.87MB**), 코드 셀 **56개 중 55개 실행됨**.
> `execution_count` 가 **2~58 로 이어진다** — 위에서 아래로 한 번에 돈 기록이다.
> 10-06 에 지적한 **환각이 사라졌고**, **LoRA 로 마스코트를 가르쳤고**,
> `moa_server.py` 로 **브라우저에서 쓸 수 있는 서비스**가 됐다.
>
> 10월 2일에는 임베딩 부품만 있었다(9셀). 열흘 사이에 **부품 → RAG → 개인화 → 서비스**로 올라갔다.

## RAG 가 무엇인가

```plain text
질문 "회비는 얼마고 누구한테 내요?"
  1. 질문을 벡터로                        (1장 — 임베딩)
  2. 문서 벡터와 비교해 가까운 k개를 찾는다   (4장 — Chroma 검색)
  3. 찾은 문서를 프롬프트에 붙여 LLM 에게      (3장 — Ollama 생성)
"한 학기에 15,000원이며, 총무 박서연에게 계좌이체로 내면 됩니다."
  + 출처 : 01_동아리소개.txt
```

| 항목 | 미세조정 (2장) | **RAG (4장)** |
| --- | --- | --- |
| 지식을 넣는 곳 | 모델 가중치 | **프롬프트** |
| 지식이 바뀌면 | 다시 학습 | **문서만 갈아 끼운다** |
| 출처 | 알 수 없다 | **찾은 문서를 보여 준다** |
| 환각 | 줄지 않는다 | **근거를 주므로 줄어든다 (조건부)** |
| 이 노트북의 실측 | 3,000개·14.4초로 +28.7%p | 3문항 정확 · **없는 것은 없다고 답했다** |

**"RAG 를 쓰면 환각이 줄어든다"에는 조건이 붙는다.**
검색이 맞아야 하고, 지시가 **실제로 전달돼야** 하고, 모델이 그 지시를 따를 만큼 커야 한다.
4장이 그 조건이 깨졌을 때와 복구됐을 때를 **나란히** 보여 준다.

## 쓴 모델 네 개

| 모델 | 장 | 역할 | 규모 |
| --- | --- | --- | --- |
| `intfloat/multilingual-e5-small` | 1·2·4 | **텍스트 임베딩** + 미세조정 백본 | **117,662,210** (384차원·12층) |
| `resnet18` | 1 | 이미지 분류 → 임베딩 | 약 1,100만 (512차원) |
| **`gemma3:4b`** (Ollama) | 3·4·5 | **대화·요약·JSON·프롬프트 번역** | 약 **40억** |
| `stable-diffusion-v1-5` | 5·6·7 | 글 → 그림 | 약 10억 (fp16) |
| `stable-diffusion-inpainting` | 5 | 마스크 부분만 다시 그린다 | 약 10억 (UNet 입력 **9채널**) |
| **마스코트 LoRA** | 6·7 | SD1.5 에 꽂는 보정 | **6.4MB** (어텐션의 약 2%) |

**모델 여섯 개가 한 노트북에 들어 있고, 7장에서 그중 네 개가 한 서버에 올라간다.**

**코드 생성 LM 3장에서 직접 만든 모델이 1,112만이었다.** `gemma3:4b` 는 그것의 **360배**다.
같은 "다음 토큰 맞히기"인데 한쪽은 문법만 맞고, 한쪽은 한국어로 대화한다 —
**규모가 무엇을 바꾸는지**가 두 과목에 걸쳐 보인다.

## 환각이 사라졌다 — 두 줄을 고쳐서

**10-06 에 4장 셀 32는 환각을 냈다.** `회장님 나이` 를 물었을 때 문서에 없는 **"20살"** 을
괄호 근거까지 붙여 지어냈다. 원문에는 "컴퓨터공학과 3학년"만 있다.

**10-07 재실행에서는 이렇게 답했다.**

```plain text
회장님 김도윤 님은 컴퓨터공학과 3학년이십니다. 정확한 나이는 제가 가진 자료에는 없습니다.
```

**같은 모델, 같은 온도(0.1), 같은 질문이다.** 고친 것은 두 줄이다.

| 고친 것 | 효과 |
| --- | --- |
| `'contect'` → `'content'` | 시스템 프롬프트가 **모델에 실제로 전달된다** |
| `RAG_SYSTEM` 의 문자열 사이 콤마 제거 | `tuple` 이 아니라 `str` 이 된다 |

> **지시를 글자 그대로 따르지는 않았다.** 요구한 고정 문구("제가 가진 자료에는 없는 내용이에요…")가
> 아니라 **문서에 있는 학년을 먼저 알려 주고 나이만 없다고** 답했다.
> 더 쓸모 있는 답이지만 **지시한 형식은 아니다** — 문구가 중요하면 `fmt='json'` 으로 제약해야 한다.

**검색은 두 실행 모두 제대로 됐다.** 달라진 것은 생성 단계뿐이다 —
**"RAG 가 환각을 줄인다"는 말에 붙는 조건을 실물로 확인한 셈이다** (4장 4-6).

## 핵심 정리

- **임베딩은 마법이 아니다.** 마스크 평균 풀링 + L2 정규화, 그러면 내적이 코사인이 된다.
- **코사인 값을 절대값으로 읽으면 안 된다.** 무관한 문장의 바닥이 0.7~0.8 이고,
  **0.003 도 안 되는 차이에서는 순위조차 못 믿는다** (4장 상금 질문 — 접두어를 고쳐도 1위는 여전히 틀렸다).
- **한국어는 토큰이 많이 든다.** `머신러닝` 이 4토큰. 청킹은 글자 수가 아니라 토큰 수로.
- **전처리·라벨·형식은 모델에서 읽는다.** `weights.transforms()`, `config.id2label`, `image_processor.size`.
- **미세조정은 전부 움직이고, 프롬프트 튜닝은 입력 앞 벡터 20개만 움직인다.**
  4.7%p 를 내주고 파라미터를 1/14,000 로 줄였다.
- **LLM 은 상태가 없다.** 기억처럼 보이는 것은 내가 `messages` 를 다시 보내기 때문이다.
- **`format='json'` 은 부탁이 아니라 제약이다.** 문법을 깨는 토큰의 확률을 0으로 만든다.
  단 **스키마는 따로 검증해야 한다.**
- **RAG = 검색 + 증강 + 생성.** 세 조각 중 하나만 틀려도 환각이 돌아온다.
- **청크에 제목·출처를 붙여라.** "어느 문서의 회비인지"가 함께 가야 한다.
- **검색이 완벽하지 않아도 LLM 이 걸러낸다.** 1위가 틀렸던 질문을 `k=3` 으로 맞게 답했다.
- **확산 모델의 노브는 둘이다.** 스텝(품질/시간)과 guidance(충실도/과포화).
  둘 다 극단으로 가면 망가진다.
- **에러가 안 났다고 설정이 먹은 게 아니다.** 라이브러리가 모르는 키를 조용히 무시하면
  **설정이 없는 것과 같다.** `messages` 의 `system` 이 실렸는지, 접두어가 맞는지는 눈으로 확인한다.
  **그 두 줄을 고치자 환각이 사라졌다** — 조용한 버그의 대가가 얼마나 큰지를 보여 주는 사례다.
- **PEFT 는 두 층위로 쓴다.** 입구에서(프롬프트 튜닝, 2장) 또는 안에서(LoRA, 6장).
  둘 다 **원래 가중치를 얼리고 작은 것만 학습해 작은 파일로 저장한다** — 30KB, 6.4MB.
- **서비스로 내보내면 질문이 달라진다.** 정확도보다 **언제 모델을 올리나, 동시 요청을 어떻게 막나,
  무엇을 JSON 으로 주나**가 문제가 된다 (7장).
- **학습한 것을 저장하지 않으면 서비스가 못 뜬다.** 7장 서버는 `work/models/moa-sentiment` 를 읽는데
  **그 폴더를 만드는 셀이 노트북에 없다** — 가장 조용하고 치명적인 재현성 구멍이다.
