## RAG 가 무엇인가

```
질문 "연차는 며칠인가요?"
  ① 질문을 벡터로                        ← 1장이 여기까지
  ② 문서 벡터와 비교해 가까운 k개를 찾는다   ← 아직
  ③ 찾은 문서를 프롬프트에 붙여 LLM 에게      ← 아직
"취업규칙 제12조에 따라 연 15일입니다"
```

| | 미세조정 | **RAG** |
| --- | --- | --- |
| 지식을 넣는 곳 | 모델 가중치 | **프롬프트** |
| 지식이 바뀌면 | 다시 학습 | **문서만 갈아 끼운다** |
| 출처 | 알 수 없다 | **찾은 문서를 보여 줄 수 있다** |
| 환각 | 줄지 않는다 | **근거를 주므로 줄어든다** |

**검색이 엉망이면 뒤가 전부 엉망이다.** 그래서 1장이 임베딩 품질 확인에 전부를 쓴다.

## 1장에서 얻은 것

**① 문장 하나를 벡터 하나로 만드는 올바른 방법**

```python
mask   = enc["attention_mask"].unsqueeze(-1).float()
pooled = (hidden * mask).sum(dim=1) / mask.sum(dim=1)   # <pad> 를 평균에서 뺀다
vecs   = F.normalize(pooled, p=2, dim=1)                # 길이 1 → 내적 = 코사인
sim    = vecs @ vecs.T                                  # 유사도 행렬 한 줄
```

**② 코사인 값을 읽는 법** — 무관한 문장의 바닥이 **0.7~0.8** 이다. **절대값이 아니라 순위를 본다.**

**③ 한국어는 토큰이 많이 든다** — `'유정이를'` 하나가 **4토큰**. 문서 분할은 **글자 수가 아니라 토큰 수**로.

**④ 전처리 설정은 모델에서 읽는다** — `weights.transforms()`. 비전 트랜스포머 폴더의 `image_processor` 와 같은 교훈.

**⑤ bi-encoder 와 cross-encoder 는 역할이 다르다** — 전자로 거르고 후자로 줄 세운다.
`text-classification` 다운로드 상위 5개 중 **4개가 재순위화 모델**인 것이 그 증거다.

## 이 과목의 위치

| 연결되는 곳 | 무엇이 이어지나 |
| --- | --- |
| 파이토치 NLP 2장 | 토큰화 — 여기서 `▁` 프리토크나이즈를 한국어로 다시 본다 |
| 파이토치 NLP 3장 | 임베딩 — 거기는 학습했고 여기는 **사전학습된 문장 임베딩을 꺼내 쓴다** |
| 파이토치 NLP 4장 | 트랜스포머 인코더 — e5 의 내부가 그것(BERT) 이다 |
| 코드 생성 LM 1장 | BPE·프리토크나이즈 — SentencePiece 의 `▁` 가 같은 발상 |
| 코드 생성 LM 3장 | 온도 — GRPO 가 학습에 `1.0`, 평가에 `0` 을 쓴 이유가 여기서 설명된다 |
| 코드 생성 LM 3장 | `ln(1000)` = 6.9078 — 학습 시작 손실과 엔트로피 최대값이 같은 식이다 |
| 코드 생성 LM 6장 | FastAPI 서비스 — RAG 를 웹으로 내보내면 같은 구조가 된다 |
| 딥러닝 4장 | 전이학습 — ResNet18 헤드를 떼어 임베딩으로 쓰는 것이 그 응용 |
| 비전 트랜스포머 1장 | `image_processor` 에서 전처리를 읽는다 — 여기 `weights.transforms()` 와 같다 |

## 실행 상태 주의

| 항목 | 주의 |
| --- | --- |
| 전체 | **RAG 본체가 없다.** 이 폴더에 검색 성능 숫자는 없다 |
| `data/data/knowledge/` | **빈 폴더.** 문서를 넣는 것이 다음 할 일이다 |
| `execution_count` | 35 → **37** → **39** 로 뛴다. 중간 셀 2개가 삭제됐다 |
| 셀 5 | 유사도 숫자가 **그림에만 있다.** 값을 기록으로 남기려면 `print` 가 필요하다 |
| 셀 6 | `entropy` 를 계산하고 **출력하지 않는다** |
| `embed` | 접두어가 `query: ` 뿐이다. **문서에는 `passage: `** 를 써야 한다 |
| `set_seed` | `torch.cuda.manual_seed_all` 이 없어 **GPU 난수가 안 고정된다** |
| `requirements` | macOS M4 Max 기준인데 **이 PC 는 CUDA** 다 |
