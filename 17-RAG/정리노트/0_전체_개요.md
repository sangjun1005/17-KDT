# RAG — 전체 개요

`17-KDT/17-RAG` — **검색으로 지식을 넣는다.** 모델을 다시 학습시키지 않고.
그리고 그 과정에서 허깅페이스·로컬 LLM·이미지 생성까지 한 바퀴 돈다.

> **2026-10-06 — 완성됐다.**
> 노트북 **1개**(`TotalAI.ipynb`, 1.79MB), 코드 셀 **38개 중 37개 실행됨**.
> 지식 문서 5개 → 청크 18개 → Chroma 적재 → `gemma3:4b` 로 질의응답까지 돈다.
> 10월 2일에는 임베딩 부품만 있었고(9셀), 지금은 **RAG 본체와 이미지 생성까지** 들어왔다.

## 구성

| 장 | 셀 | 내용 | 실행 상태 |
| --- | --- | --- | --- |
| 1. 임베딩과 멀티모달 기초 | 0~8 | 토크나이저 → 마스크 평균 풀링 → 코사인 → ResNet18 → 온도 → 허브 API | **실행됨** |

| 3. 로컬 LLM — Ollama | 20~26 | 서버 자동 기동 → `chat` → 시스템 프롬프트 → 멀티턴 → 스트리밍 → JSON 강제 | **실행됨** (`gemma3:4b`) |

## RAG 가 무엇인가

```text
질문 "회비는 얼마고 누구한테 내요?"
  1. 질문을 벡터로                        (1장 — 임베딩)
  2. 문서 벡터와 비교해 가까운 k개를 찾는다   (4장 — Chroma 검색)
  3. 찾은 문서를 프롬프트에 붙여 LLM 에게      (3장 — Ollama 생성)
"한 학기에 15,000원이며, 총무 박서연에게 계좌이체로 내면 됩니다."
  + 출처 : 01_동아리소개.txt
```

| 항목 | 미세조정 (2장) | **RAG (4장)** |
| --- | --- | --- |
| 지식을 넣는 곳 | 모델 가중치 | **프롬프트** |
| 지식이 바뀌면 | 다시 학습 | **문서만 갈아 끼운다** |
| 출처 | 알 수 없다 | **찾은 문서를 보여 준다** |
| 환각 | 줄지 않는다 | **근거를 주므로 줄어든다 (조건부)** |
| 이 노트북의 실측 | 3,000개·15초로 +28.7%p | 3문항 정확 · **1문항 환각** |

**"RAG 를 쓰면 환각이 줄어든다"에는 조건이 붙는다.**
검색이 맞아야 하고, 지시가 **실제로 전달돼야** 하고, 모델이 그 지시를 따를 만큼 커야 한다.
4장이 그 조건 하나가 깨졌을 때 무슨 일이 생기는지를 실물로 보여 준다.

## 쓴 모델 네 개

| 모델 | 장 | 역할 | 규모 |
| --- | --- | --- | --- |
| `intfloat/multilingual-e5-small` | 1·2·4 | **텍스트 임베딩** + 미세조정 백본 | **117,662,210** (384차원·12층) |
| `resnet18` | 1 | 이미지 분류 → 임베딩 | 약 1,100만 (512차원) |
| **`gemma3:4b`** (Ollama) | 3·4·5 | **대화·요약·JSON·프롬프트 번역** | 약 **40억** |
| `stable-diffusion-v1-5` | 5 | 글 → 그림 | 약 10억 (fp16) |

**코드 생성 LM 3장에서 직접 만든 모델이 1,112만이었다.** `gemma3:4b` 는 그것의 **360배**다.
같은 "다음 토큰 맞히기"인데 한쪽은 문법만 맞고, 한쪽은 한국어로 대화한다 —
**규모가 무엇을 바꾸는지**가 두 과목에 걸쳐 보인다.

## 환각이 한 건 나왔다

**4장 셀 32의 출력이 환각이다.** `회장님 나이` 를 물었을 때 문서에 없는 **"20살"** 을
괄호 근거까지 붙여 지어냈다. 원문에는 "컴퓨터공학과 3학년"만 있다.

**검색은 제대로 됐다.** 임원진 단락이 실제로 걸렸다 — **환각은 생성 단계에서 났다.**
그 호출에서는 `RAG_SYSTEM` 의 "자료에 없으면 지어내지 말라"가 **모델에 닿지 않았다.**

> **같은 모델이 3장에서는 지어내지 않았다.**
> 후기 4개로 "잘한 점 3가지"를 요구했을 때 **"내용이 부족해 제시할 수 없음"**이라고 답했다.
> **지어내지 않을 능력은 있었다** — 4장의 환각은 모델의 한계가 아니라 지시 전달 문제다.

**코드는 그 뒤 고쳐졌다.** 다만 **노트북 출력과 벡터 DB 는 아직 옛것이므로**
같은 질문으로 다시 돌려 확인해야 한다 (4장 4-6).

## 전체 흐름

```text
[1장] 문장 -> 벡터
   e5-small, 마스크 평균 풀링, L2 정규화, 코사인
   ResNet18 로 이미지도 벡터가 된다는 것을 확인
      |
[2장] 같은 모델을 과제에 맞춘다
   pipeline (세 줄 추론) -> 직접 호출 -> 어텐션 지도
   NSMC 미세조정 49.9% -> 78.6%  (전부 학습)
   프롬프트 튜닝        -> 73.9%  (8,450개만 학습)
      |
[3장] 생성 모델을 띄운다
   Ollama gemma3:4b, localhost
   시스템 프롬프트 / 멀티턴 / 스트리밍 / JSON 강제
      |
[4장] 1장 + 3장 = RAG
   문서 5개 -> 청크 18개 -> Chroma(cosine)
   질문 -> 검색 k=3 -> [참고자료] 로 끼운다 -> 답변 + 출처
   ** 지시가 닿지 않은 호출에서 회장 나이를 지어냈다 (4-6) **
      |
[5장] 글 -> 그림
   SD1.5 fp16, DPMSolverMultistep 20스텝
   3장의 LLM 을 한국어->영어 프롬프트 번역기로 재사용
   스텝(2·5·10·25) / guidance(1·4·7.5·15) 비교
```

## 이 과목의 위치

| 연결되는 곳 | 무엇이 이어지나 |
| --- | --- |
| 파이토치 NLP 2장 | 토큰화 — 2장에서 WordPiece(`##`) vs SentencePiece(공백 표시)를 나란히 본다 |
| 파이토치 NLP 3장 | 임베딩 — 거기는 학습했고 여기는 **사전학습된 문장 임베딩을 꺼내 쓴다** |
| 파이토치 NLP 4장 | 트랜스포머 인코더 — e5 의 내부가 BERT 다 (`model_type: bert`) |
| 코드 생성 LM 1장 | BPE·프리토크나이즈 — SentencePiece 와 같은 발상 |
| 코드 생성 LM 3장 | 온도 — GRPO 가 학습에 `1.0`, 평가에 `0` 을 쓴 이유가 1장에서 설명된다 |
| 코드 생성 LM 3장 | 직접 만든 1,112만 모델 vs `gemma3:4b` 40억 — **규모의 차이** |
| 코드 생성 LM 3장 | `ln(1000)`=6.9078 — 엔트로피 최대값과 학습 시작 손실이 같은 식 |
| 코드 생성 LM 3·4장 | 슬라이딩 윈도우 — 3장의 멀티턴 문맥 잘림과 같은 문제 |
| 코드 생성 LM 5장 | SDPA / FlashAttention — 2장에서 `attn_implementation='eager'` 로 되돌려야 하는 이유 |
| 코드 생성 LM 6장 | FastAPI 서비스 · 입력 검증 — 3장의 JSON 스키마 검증과 같은 발상 |
| 딥러닝 4장 | 전이학습 — 2장의 세 가지 방법(헤드만/전부/프롬프트)이 그 확장 |
| 딥러닝 8장 | 셀프 어텐션 — 2장의 어텐션 지도가 그 시각화 |
| 비전 트랜스포머 1장 | `image_processor` 에서 전처리를 읽는다 — 1장 `weights.transforms()` 와 같다 |
| 비전 트랜스포머 1·2장 | 미세조정 설정 비교 — ViT `lr 1e-5` vs e5 `5e-5`, `save_strategy` 차이 |
| 비전 트랜스포머 2장 | 한 번에 하나만 바꾸는 통제 비교 — 5장의 스텝·guidance 실험이 같은 설계 |

## 핵심 정리

- **임베딩은 마법이 아니다.** 마스크 평균 풀링 + L2 정규화, 그러면 내적이 코사인이 된다.
- **코사인 값을 절대값으로 읽으면 안 된다.** 무관한 문장의 바닥이 0.7~0.8 이고,
  **0.0003 차이에서는 순위조차 못 믿는다** (4장 상금 질문).
- **한국어는 토큰이 많이 든다.** `머신러닝` 이 4토큰. 청킹은 글자 수가 아니라 토큰 수로.
- **전처리·라벨·형식은 모델에서 읽는다.** `weights.transforms()`, `config.id2label`, `image_processor.size`.
- **미세조정은 전부 움직이고, 프롬프트 튜닝은 입력 앞 벡터 20개만 움직인다.**
  4.7%p 를 내주고 파라미터를 1/14,000 로 줄였다.
- **LLM 은 상태가 없다.** 기억처럼 보이는 것은 내가 `messages` 를 다시 보내기 때문이다.
- **`format='json'` 은 부탁이 아니라 제약이다.** 문법을 깨는 토큰의 확률을 0으로 만든다.
  단 **스키마는 따로 검증해야 한다.**
- **RAG = 검색 + 증강 + 생성.** 세 조각 중 하나만 틀려도 환각이 돌아온다.
- **청크에 제목·출처를 붙여라.** "어느 문서의 회비인지"가 함께 가야 한다.
- **검색이 완벽하지 않아도 LLM 이 걸러낸다.** 1위가 틀렸던 질문을 `k=3` 으로 맞게 답했다.
- **확산 모델의 노브는 둘이다.** 스텝(품질/시간)과 guidance(충실도/과포화).
  둘 다 극단으로 가면 망가진다.
- **에러가 안 났다고 설정이 먹은 게 아니다.** 라이브러리가 모르는 키를 조용히 무시하면
  **설정이 없는 것과 같다.** `messages` 의 `system` 이 실렸는지, 접두어가 맞는지는 눈으로 확인한다.
