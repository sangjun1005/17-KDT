# 2. 예산 배분과 체크리스트 (2일차 · M5)

**자료**: `LGES_애리조나_슬리터_예산배분표.pdf` (3쪽) · `체크리스트.pdf` (5쪽)

> **WBS에 금액을 붙이면 예산표가 되고, 완료 기준을 붙이면 체크리스트가 된다**
> 둘 다 새 문서가 아니라 **WBS의 다른 얼굴**이다.
> 예산표의 각 줄에 WBS 코드가 있고, 체크리스트의 각 항목 비고란에도 WBS 코드가 있다.
>
> 이렇게 묶어 두면 **"어느 작업이 늦어지면 어느 돈이 묶이는지"**가 바로 보인다.

## 2-1. 예산 구조 — 160억을 어떻게 나누나

| 구분 | 금액 | 계약 대비 |
| --- | --- | --- |
| **계약금액** | **160.0억** | 100% |
| 직접 실행예산 (WBS 1.1~1.8) | 133.0억 | 83.1% |
| **예비비** | **6.0억** | 3.8% |
| 실행예산 합계 | **139.0억** | 86.9% |
| **예상 이익** | **21.0억** | **13.1%** |

**예비비를 안 쓰면 이익이 27.0억(16.9%)이 된다.**

```plain text
계약 160억
 ├─ 실행예산 139억  ┬─ 직접비 133억  (WBS 1.1~1.8)
 │                 └─ 예비비   6억   (리스크 5종에 미리 배분)
 └─ 이익    21억 (13.1%)
```

**예비비를 "남는 돈"이 아니라 예산 안에 넣어 둔 것이 중요하다.**
예비비를 따로 빼 놓지 않으면 문제가 생겼을 때 **이익을 깎아 쓰게 된다.**

## 2-2. WBS별 배분과 비용 성격

| 코드 | 항목 | 금액 | 비중 |
| --- | --- | --- | --- |
| 1.1 | 확정된 설계 | 7.0 | 5.0% |
| **1.2** | **입고된 자재** | **82.0** | **59.0%** |
| 1.3 | 조립된 슬리터 4기 | 15.0 | 10.8% |
| 1.4 | FAT 통과 장비 | 2.1 | 1.5% |
| 1.5 | 현지 도착 장비 | 7.2 | 5.2% |
| 1.6 | SAT 통과 라인 | 12.5 | 9.0% |
| 1.7 | 인수·보증 이관 | 2.9 | 2.1% |
| 1.8 | 프로젝트 관리 | 4.3 | 3.1% |
| — | 예비비 | 6.0 | 4.3% |

**자재가 59%다.** 그중 **장납기 10종이 34억(24.5%)** 으로 단일 최대 항목이다.

> **"장납기 10종이 원가와 일정을 동시에 좌우한다"** — 예산표의 결론이다.
> 1장에서 본 **크리티컬 패스의 시작**이 **원가의 최대 항목**이기도 하다.
> 그래서 계약 직후 발주와 **가격 확정**이 원가 관리의 출발점이 된다.

### 비용 성격별

| 성격 | 금액 | 비중 | 내용 |
| --- | --- | --- | --- |
| **재료비** | **82.0** | **59.0%** | 장납기 10종 · 일반 구매품 · 가공품 · 예비 나이프 |
| 노무비 | 26.2 | 18.8% | 설계·조립·프로그램·파견·PM |
| 외주비 | 11.8 | 8.5% | 규격 검토 · 외주 조립 · 포장 · 현지 협력사 |
| 경비 | 13.0 | 9.4% | FAT · 운송 · 보험 · 비자 · 장비 임대 · 보증 충당금 |
| 예비비 | 6.0 | 4.3% | |

**같은 금액을 두 가지 축으로 본다** — WBS별(어느 작업에)과 성격별(무슨 돈으로).
WBS별은 **일정과 연결**되고, 성격별은 **조달·회계와 연결**된다.

### 눈에 띄는 산정 근거

| 항목 | 금액 | 근거 |
| --- | --- | --- |
| 해상·내륙 운송 (부산→롱비치→AZ) | 5.0 | 운임 **견적 확인 필요** |
| 현지 협력사 설치 (리깅·배선) | 5.0 | 미국 현지 노임 **확인 필요** |
| 파견 인건비·체재비·항공 | 6.0 | **6명 × 9주** 가정 |
| 보증 충당금 (24개월) | 2.4 | **계약금의 1.5%** 가정 |
| 이행·선급금 보증증권 수수료 | 0.8 | 보증보험 요율 **확인 필요** |

**"확인 필요"가 명시된 항목이 네 개다.** 가정으로 채운 자리를 숨기지 않았다.

**수입 관세가 빠져 있는 것도 근거가 적혀 있다** — **DAP 조건이라 관세는 매수인(LGES) 부담**이다.
인코텀즈가 원가에 직접 영향을 준다.

## 2-3. 예비비 — 리스크별로 미리 나눠 둔다

**6억을 통으로 두지 않고 다섯 개 리스크에 배분했다.**

| 리스크 | 연결 WBS | 금액 | 사용 예 |
| --- | --- | --- | --- |
| 나이프·샤프트 **장납기 지연** | 1.2.1 | 1.0 | 긴급 발주 프리미엄, **항공 운송 전환** |
| **FAT 버 불합격** 재작업 | 1.4 | **1.5** | 나이프 재가공·재시험, 고객 재입회 |
| **운송 지연**·현장 체재 연장 | 1.5.4 · 1.6 | **1.5** | 체재비·장비 임대 연장, 협력사 대기비 |
| 미국 **전기 규격 반려** | 1.1.3 | 1.0 | 제어반 설계 변경, UL 508A 패널 재제작 |
| **환율 변동** | 전체 | 1.0 | 달러 계약 대비 원화 원가 변동 |

**각 리스크가 WBS 코드에 붙어 있다.** "FAT 버 불합격"이 1.4에 연결돼 있으니,
1.4가 흔들리면 쓸 수 있는 돈이 1.5억이라는 것이 바로 나온다.

**가장 큰 두 개(각 1.5억)가 FAT 불합격과 운송·체재 연장**이다.
**국내에서 끝나지 않고 현지로 가는 프로젝트의 돈 새는 구멍**이 어디인지 보여 준다.

## 2-4. 원가율 KPI

**1일차 헌장의 목표가 "원가율 85% 이하"였다.**

| 상황 | 원가율 | 판정 |
| --- | --- | --- |
| 예비비 **미사용** | **83.1%** | 목표 달성 |
| 예비비 **전액 사용** | **86.9%** | **목표 초과** |

```plain text
예비비를 3.0억 넘게 쓰면 원가율 85%를 넘는다
→ 예비비 집행 자체를 관리 지표로 본다
```

**이 계산이 예산표에서 가장 좋은 부분이다.**
목표를 적어 놓고 끝내지 않고, **"어디까지 쓰면 목표를 넘는지"를 역산**했다.
그러면 예비비 집행이 **사후 보고가 아니라 사전 경고**가 된다.

## 2-5. 체크리스트 — 게이트마다 무엇을 보나

**55개 항목을 8개 구간으로 나눴다.**

| 구간 | 내용 | 연결 WBS | 항목 | 점검 시점 |
| --- | --- | --- | --- | --- |
| A | **G1 설계 확정** | 1.1 · 1.4.1 | 7 | 13주 |
| B | 구매·입고 검사 | 1.2 | 7 | 2~22주, **입고 시마다** |
| C | 조립·내부 Pre-FAT | 1.3 | 8 | 26~30주 |
| D | **FAT (G2)** | 1.4 | **9** | 31~33주 |
| E | 출하·운송 | 1.5 | 5 | 30~44주 |
| F | **설치·SAT (G4)** | 1.6 | 7 | 44~52주 |
| G | **인수·보증 (G5)** | 1.7 · 1.8 | 5 | 51~57주 |
| **H** | **안전 공통** | 위험성 평가 | **7** | **전 단계 상시** |

**H(안전)만 게이트에 묶이지 않고 전 단계 상시다.**

```plain text
H1 나이프 취급      교체 시 전용 지그·보호장갑, 날 보호 커버 비치
H2 회전체·닙 포인트  롤 닙·권취축 접근 가드와 인터록
H3 비상정지        작업 위치마다 접근 가능, 해제 후 리셋해야 재기동
```

**"해제 후 리셋해야 재기동"이 중요한 조건이다.** 비상정지를 풀자마자 다시 돌면 안 된다.

### 사용 방법이 문서에 적혀 있다

```plain text
게이트 전에 해당 구간 항목을 점검하고 확인란에 적합/부적합을 표시한다
부적합 항목은 비고에 조치 내용을 기재한다
```

**항목마다 `적합 / 부적합` 두 칸이 인쇄돼 있다.** 애매하게 넘어갈 수 없게 만든 것이다.

### 두 가지 표시

| 표시 | 뜻 |
| --- | --- |
| **확인 필요** | 고객·공급사 확인 전의 **가정**이다. 확인 후 기준을 확정한다 |
| **신규** | **WBS에 아직 없는 항목**이다. WBS를 보완해야 한다 |

**`신규` 표시가 특히 좋다.** 체크리스트를 만들다 보면 WBS에서 빠뜨린 게 드러나는데,
그걸 체크리스트에만 몰래 넣지 않고 **"WBS 보완 필요"로 역방향 표시**를 남겼다.

**예시 (A 구간)**

| No. | 항목 | 기준 | 비고 |
| --- | --- | --- | --- |
| A1 | 사양서 동결 | 버 10μm 이하, 폭 ±0.1mm, 사행 ±0.2mm, 100 m/min, 조수 기재 **및 고객 서명** | 1.1.1 |
| A2 | 양극/음극 나이프 사양 구분 | 소재·각도·간격·버 기준이 **극별로 명시** | 1.1.2 · **고객 확인 필요** |

## 이 장 정리

### 한 줄 요약

**예산표와 체크리스트는 WBS에 "얼마"와 "무엇을 보고 통과시킬지"를 붙인 것이다.**
예비비를 리스크별로 미리 나누고, **원가율 85% 목표를 "예비비 3억"이라는 집행 한도로 역산**한 것이 핵심이다.

### 숫자 한눈에

| 항목 | 값 |
| --- | --- |
| 계약 / 실행예산 / 이익 | **160억 / 139억 / 21억 (13.1%)** |
| 예비비 | **6억** (리스크 5종 배분) |
| 원가율 | 예비비 미사용 **83.1%** · 전액 사용 **86.9%** (목표 85%) |
| **예비비 임계점** | **3.0억** — 넘으면 목표 초과 |
| 최대 비용 항목 | **자재 82억 (59%)**, 그중 장납기 10종 **34억** |
| 비용 성격 | 재료 59.0 · 노무 18.8 · 경비 9.4 · 외주 8.5 · 예비 4.3 % |
| 체크리스트 | **55개 / 8구간** (안전 7개는 상시) |
| 인코텀즈 | **DAP** — 관세는 매수인 부담 |

### 자주 틀리는 것

- 예비비를 예산에 안 넣는다 → 문제 생기면 **이익을 깎아 쓴다**
- 예비비를 통으로 둔다 → 어느 리스크에 얼마 쓸 수 있는지 모른다
- 목표 원가율만 적는다 → **"얼마까지 쓰면 넘는지"를 역산**해야 관리가 된다
- 가정으로 채운 금액을 확정값처럼 쓴다 → **"견적 확인 필요"**를 남긴다
- 인코텀즈를 안 보고 관세를 계상한다 → DAP면 매수인 부담이다
- 체크리스트를 WBS와 따로 만든다 → 빠진 항목이 보이지 않는다
- 체크리스트에서 발견한 누락을 **체크리스트에만 넣는다** → `신규` 표시로 WBS를 보완한다
- 안전 항목을 게이트에만 넣는다 → **전 단계 상시**여야 한다
