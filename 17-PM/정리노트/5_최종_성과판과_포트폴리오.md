## 5-3. EVM — 숫자로 "늦었다"를 말하는 법

8장 8쪽. **12주차 말(2027-01-24) 가상값**이다.

| 항목 | 값 | 뜻 |
| --- | --- | --- |
| **BAC** | **139억원** | 실행예산 총액 (계약 매출 160억과 **다르다**) |
| **PV** | **40억원** | 이때까지 **하기로 한** 일의 예산가치 |
| **EV** | **32억원** | 실제로 **끝낸** 일의 예산가치 |
| **AC** | **36억원** | 실제로 **쓴** 돈 |

| 지수 | 식 | 값 | 판정 |
| --- | --- | --- | --- |
| **SPI** | EV / PV = 32 / 40 | **0.80** | 일정 **적색** |
| **CPI** | EV / AC = 32 / 36 | **0.889** | 원가 **황색** |
| **EAC** | BAC / CPI = 139 / 0.889 | **156.375억원** | 이대로면 17.4억 초과 |

**계산 확인**: 32/40 = 0.8 정확. 32/36 = 0.8889. 139/0.8889 = 156.37억 — 문서값과 일치한다.

> **매출 160억과 실행예산 139억을 구분한 것이 이 쪽의 핵심이다.**
> EVM은 **쓸 돈** 기준으로 돌린다. 매출로 돌리면 이익이 사라진 것을 못 본다.

**조치까지 적혀 있다**: "설계·조달 회복과 기존 가용 인력 2명·2주 재배치 검토 요청."
숫자만 내고 끝내지 않는다.

> 문서가 **"실제 집행 실적 아님"**이라고 바로 밑에 적어 뒀다.

## 5-4. 변경요청 CR-SLT-02

8장 4쪽·8쪽. **고객이 FAT 중에 추가 요청**을 한 상황이다.

| 요청 | 내용 |
| --- | --- |
| 기능 | 4기 **알림·이력 기능** 추가 |
| 예비품 | 예비 나이프 **총 4세트** (계약에 1세트 포함 → **추가 3세트**) |

| 비용 항목 | 금액 |
| --- | --- |
| 예비품 | 0.12억 |
| 기능 | 0.12억 |
| 추가 검증 | 0.08억 |
| 재조정 | 0.12억 |
| **합계** | **0.44억원** (VAT 별도) |

**일정 영향**: FAT·선적 **각 14일** 조정안 → FAT 6/28 · 선적 7/12 (추정).
**SAT·인수 영향은 재계산 후 협의.**

세 가지를 분명히 적었다.

1. **미승인이다** → 기존 BAC·일정에 **반영하지 않았다**
2. **기존 버 불량 수정비는 제외** → 우리 책임인 것과 고객 요청을 섞지 않는다
3. **FAT 단축(4일차)과 FAT 연기(이 변경)가 동시에 걸려 있다** → 반대 방향의 변경 두 개

> **2번이 PM의 문장이다.** 변경요청이 들어오면 **원래 하기로 한 일의 비용까지 같이 청구하고 싶어진다.**
> 그걸 미리 잘라 둔다.

## 5-5. 지급 비율이 드디어 통일됐다

**4일차 노트 4-5절에서 "어느 쪽이 맞다는 문서가 없다"고 적었던 문제가 5일차에 해결됐다.**

| | 2일차 예산배분표 | 4일차 계약서 4조 (1식) | **5일차 8장 최종** |
| --- | --- | --- | --- |
| 계약·착수 | 30% | 30% | **30% · 48억** |
| FAT 합격·출하 | 40% | 50% | **40% · 64억** |
| SAT 합격 | 20% | 20% | **20% · 32억** |
| 최종 인수 | 10% | — | **10% · 16억** |

8장 1쪽에 그 문장이 있다 — **"대금은 사진의 1식 예시 대신 우리 4기 WBS 30·40·20·10%로 통일함."**

**중간 단계도 남아 있다.** A3 전체흐름판(8장보다 먼저 만들어진 판)에는 아직 30·50·20이 표시돼 있고
**"4기 WBS의 지급·보증 가정과 달라 실제 적용 전 계약 기준 통일 필요"**라고 적혀 있다.
→ **불일치를 발견 → 문서에 남김 → 다음 판에서 통일**의 순서가 파일에 그대로 찍혀 있다.

**48 + 64 + 32 + 16 = 160억.** 합이 맞는다.

> 8장 2쪽에 덧붙은 문장: **"SAT 20%와 최종 인수 10%는 서로 다른 조건이다."**
> SAT 합격과 최종 인수를 같은 사건으로 보면 지급 시점을 놓친다.

## 5-6. 직무 포트폴리오 1쪽 양식

5일차 강의 **53쪽**이 제시한 양식이다.

| 항목 | 적는 내용 |
| --- | --- |
| 프로젝트 개요 | 해외 셀 제조사향 코팅 라인 턴키 (2줄) |
| **나의 역할** | PM·기록·QA·AI 담당을 맡은 **날과 한 일** |
| 주요 산출물 3개 | 기획서 · 간트 · A3 보고서 (사진) |
| **STAR 2개** | **문제해결 1 + 협업·소통 1** |
| AI 활용·검증 | **AI 결과를 고친 사례 1개** |
| 배운 점 · 지원 직무 | 왜 이 직무에 맞는가 |

**54쪽은 이것을 3종 세트로 넓힌다.**

| | 무엇 | 요점 |
| --- | --- | --- |
| ① | **1쪽 PDF** | 지원서 첨부용. 양식 그대로 + **STAR 2개 + 숫자 1개** + 하단 QR → ②로 연결 |
| ② | **포트폴리오 페이지** | 블로그·노션·구글 사이트. **프로젝트 1건 = 문제 → 내 역할 → 산출물 사진 → 결과 → 배운 점**. 갤러리에 간트·A3·위험성평가표·관리도 |
| ③ | **링크드인 프로필** | 영문 검색에 걸리게. 헤드라인 `이차전지 장비 셋업·PM 지망 ǀ FAT·SAT·EVM` + 영문 요약 3줄 |

**강의가 못 박은 원칙 두 개.**

> **"세 곳의 내용이 같아야 합니다. 가상 프로젝트는 '교육 과정 실습'이라고 분명히 적습니다."**
> **"면접관은 링크를 열어 3초 안에 '무슨 일을 했는지'를 봅니다 → 첫 화면에 역할과 숫자."**

**"AI 결과를 고친 사례"를 한 칸 따로 둔 것**이 이 양식에서 제일 눈에 띈다.
AI를 썼다는 것보다 **AI가 틀린 것을 잡아냈다**가 평가 대상이다.

## 5-7. 확인 필요 / 주의

| 항목 | 내용 |
| --- | --- |
| **FAT 단축과 FAT 연기가 동시에 있다** | 4일차는 고객이 **1주 당겨** 달라 했고, CR-SLT-02는 **14일 미뤄**진다. 두 변경의 선후·상쇄 관계가 문서에 정리돼 있지 않다 |

| 팀원 실명 | 모든 PDF 파일 이름과 본문에 들어 있다. 저장소에는 **정리노트만** 올리고 원본 PDF·docx는 제외했다 |
