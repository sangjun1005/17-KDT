## 3-1. 체크시트 → 파레토도

**슬리팅기 불량·정지 원인 10가지, 가상 발생 100건.**

| 순위 | 원인 | 건수 | 누적 |
| --- | --- | --- | --- |
| **1** | **나이프 마모·날끝 깨짐** | **28** | **28%** |
| 2 | 나이프 간극·겹침량 불량 | 20 | 48% |
| 3 | 권출·권취 장력 설정 불량 | 12 | **60%** |
| 4 | 나이프·스페이서 조립 위치 오류 | 9 | 69% |
| 5 | EPC 센서 오염·위치 설정 불량 | 8 | 77% |
| 6 | 롤러·샤프트 정렬 불량 | 7 | **84%** |
| 7 | 권취 토크·테이퍼 장력 설정 불량 | 6 | 90% |
| 8 | 베어링 마모·축 흔들림 | 4 | 94% |
| 9 | 집진·스크랩 배출 불량 | 3 | 97% |
| 10 | 투입 전극 두께·코팅 상태 편차 | 3 | 100% |

```plain text
상위 3개 = 60%     상위 6개 = 84%
```

**읽는 법** — 막대는 건수(큰 순서), 꺾은선은 왼쪽부터 더한 누적 비율.

> **80:20은 고정 비율이 아니다.** 문서에 명시돼 있다 —
> *"80:20은 모든 데이터에 맞는 고정 비율은 아님."*
> 이 데이터는 **상위 3개가 60%**다. 비율을 외우는 게 아니라 **그래프에서 읽는 것**이다.

**유래**: 파레토가 **부·토지 소유가 소수에게 집중**되는 현상을 관찰했고,
**주란(Juran)이 1950년대 초 품질관리에 적용**해 "중요한 소수(vital few)"에 집중하도록 설명했다.

**집계 규칙도 적혀 있다** — *"동일 기간, 사건 1건당 주원인 1개 배정."*
한 사건에 원인을 두 개 매기면 합이 100건을 넘어 누적 비율이 깨진다.

**결론: 1순위 `나이프 마모·날끝 깨짐` 28건을 문제 정의 대상으로 선정.**

## 3-2. 특성요인도 — 6M

**"왜 그럴까"를 여섯 갈래로 나눈다.** 생선뼈(fishbone) 모양이라 피시본 다이어그램이라고도 한다.

| 6M | 무엇을 보나 | 이 사례의 원인 후보 |
| --- | --- | --- |
| **Man** (사람) | 작업자·숙련도·교육 | 오버랩 깊이·측압 세팅이 작업자마다 다름 / 교체 중 날끝 치핑 |
| **Machine** (설비) | 장비 상태·정밀도 | 샤프트 런아웃·평행도 불량 → **한쪽만 마모** / 상·하 나이프 속도비 부적정 |
| **Material** (자재) | 투입물·부품 | 전극 연마성 증가(고니켈 NCM, 캘린더링 밀도 상승) / 나이프 재질·경도 로트 문제 |
| **Method** (방법) | 절차·기준 | 교체 주기가 **주행 거리가 아닌 감각**에 의존 / 재연마 품질 불량 |
| **Measurement** (측정) | 재는 방법 | 측정 위치·배율·장비가 다름 / **측정기 교정 이탈로 정상품을 초과로 오판** |
| **Mother nature** (환경) | 온습도·분진 | 분진 퇴적으로 연마 마모 가속(집진 부족) / 열팽창으로 간격 변화 |

**모든 후보에 `추정 · 미확인` 이 붙어 있다.**

> *"아래 12개 원인 후보는 모두 확인되지 않은 추정임.
> 현장 측정·점검으로 확인하기 전까지 원인으로 단정하지 않음."*

**그리고 후보마다 "현장 확인 방법"이 짝으로 적혀 있다.**

| 원인 후보 | 확인 방법 |
| --- | --- |
| 샤프트 런아웃 불량 | **다이얼 게이지**로 런아웃·평행도 측정. 마모가 원주 방향으로 고른지 |
| 상·하 나이프 속도비 | **엔코더·회전수계**로 측정 후 설정값과 비교. 슬립 흔적(광택 띠) 확인 |
| 측정 방법 불일치 | 같은 시료를 여러 사람이 반복 측정 — **게이지 R&R** |
| 측정기 교정 이탈 | **표준 시편**으로 확인. 교정 유효기간·성적서 확인 |

**확인 방법이 없는 원인 후보는 추측이다.** 이 표의 형식이 그걸 강제한다.

> **팀 프로젝트 2장의 "플래그는 오류 건수가 아니라 의심 후보일 뿐이다"와 같은 태도다.**
> 거기서는 플래그 116,635건 중 사람이 판정한 BAD가 0건이었다.
> **의심을 확정으로 바꾸려면 확인 절차가 따로 있어야 한다.**

## 3-3. 5Why로 원인 사슬 확장

**별도 산출물에서 6M의 각 갈래를 "왜?"로 다섯 단계까지 밀었다.**
대상은 **절단면 버 기준 초과** (샘플 30개 중 8개 = 26.7%, 기준 10μm 이하, 초과 샘플 14~22μm).

**설비(Machine) 갈래 예시**

```plain text
1. 나이프 마모·날끝 손상
   왜? → 2. 교체 시점이 지나도 계속 사용
         왜? → 3. 누적 사용량·손상 추세 기록이 없음
               왜? → 4. 예방보전 점검표에 해당 항목 누락
                     왜? → 5. 보전 기준 개정 담당·주기가 없음
```

**사람(Man) 갈래**

```plain text
1. 간극 설정 오류 → 2. 설정·확인 방법이 작업자마다 다름
   → 3. 실습·숙련도 확인이 빠짐 → 4. 변경 작업의 교육 절차가 없음
   → 5. 교육 갱신 책임·완료 기준이 없음
```

**여섯 갈래가 전부 같은 곳에 도착한다.**

| 갈래 | 5단계(마지막) |
| --- | --- |
| 사람 | 교육 갱신 **책임·완료 기준**이 없음 |
| 설비 | 보전 기준 개정 **담당·주기**가 없음 |
| 재료 | 소재 변경 **승인·정보 전달 절차**가 없음 |
| 방법 | 변경 시 **절차서 개정 책임**이 미정 |
| 측정 | 측정 방법 변경 시 **개정·검증 절차**가 없음 |
| 환경 | 점검표 **개정 담당·확인 주기**가 미정 |

**전부 "변경을 관리하는 절차가 없다"로 수렴한다.**
현상은 나이프가 닳은 것이지만, 뿌리는 **변경 관리(change control)의 부재**다.

> **문서 하단의 단서가 중요하다** —
> *"모든 원인 사슬은 검증 전 가설임. 자료로 확인한 단계까지만 채택함."*
> 5Why는 밀면 계속 밀 수 있어서, **어디까지가 확인된 것인지**를 끊어 줘야 한다.

## 3-4. 확인 순서 — 측정부터 의심한다

**원인 후보 12개를 어떤 순서로 확인할지도 정해 뒀다.**

| 순서 | 대상 | 이유 |
| --- | --- | --- |
| **1** | **측정 (9, 10)** | **측정이 틀렸다면 "기준 초과" 자체가 거짓일 수 있음.** 가장 빠르고 비용이 거의 안 든다 |
| 2 | 세팅·설비 (1, 3, 4) | 다이얼 게이지와 세팅 기록만으로 **당일 확인** 가능. 편마모 패턴이 보이면 범위가 크게 좁혀진다 |
| 3 | 자재·방법 (5~8) | 로트 이력·주행 거리 데이터를 모아야 해서 시간이 걸린다. **재발 방지 기준이 여기서 나온다** |
| 4 | 환경 (11, 12) | 장시간 운전 기록 필요. 집진 풍량은 1·2단계와 함께 측정해도 됨 |

**1순위가 "측정을 의심한다"인 것이 이 표의 핵심이다.**

```plain text
문제가 있다  ←  측정값이 기준을 넘었다
                    ↑
              이게 맞는 측정인가?
```

**측정기가 교정을 벗어났으면 "문제"가 애초에 없다.** 그리고 확인 비용이 거의 0이다.
**비용 대비 정보량이 큰 것부터** 확인한다 — 이게 순서를 정하는 기준이다.

> 팀 프로젝트 2장에서 **오류의 36%가 모델 성능이 아니라 NFKC 인코딩 문제**였던 것과 같다.
> "성능이 낮다"고 결론 내리기 전에 **재는 방법**을 봤어야 했다.

## 3-5. 관리도

**"불량이 났나"가 아니라 "공정이 변했나"를 본다.**

```plain text
버 높이 (μm) — 로트 1~25

USL 10.0  ─────────────────────────────── 규격 상한 (FAT 합격 기준, 고객이 정한 선)
UCL  8.2  ─────────────────────────────── 관리 상한 (±3σ, 공정이 정한 선)
CL   6.0  ─────────────────────────────── 중심선 (1~14번 평균)
LCL  3.8  ───────────────────────────────

1~14번   5.2 ~ 6.7 사이에서 오르내림        ← 안정
15번     재연마 나이프 투입
15~22번  6.6 → 7.9 로 계단식 상승
21번     8점 연속 CL 위  → 이상 신호
23번     8.3 > UCL      → 이상 확정
25번     8.9            → 그래도 규격 10은 안 넘음
```

| 선 | 누가 정하나 | 뜻 |
| --- | --- | --- |
| **USL** 규격 상한 | **고객** | 넘으면 불량 (FAT 기준 10μm) |
| **UCL/LCL** 관리 한계 | **공정** | 넘으면 "평소와 다르다" (±3σ) |
| **CL** 중심선 | 공정 | 안정 구간의 평균 |

**σ = 0.74, CL = 6.00 — 1~14번 로트만 써서 계산했다.**
**기준 구간을 안정된 구간으로 한정한 것**이 맞다. 15번 이후를 포함하면 CL이 올라가 이상이 안 보인다.

### 적용한 판정 규칙 2가지 (Western Electric 규칙)

| 규칙 | 걸린 지점 |
| --- | --- |
| ① 한 점이라도 UCL·LCL 밖 | **23 · 24 · 25번** |
| ② **8점 연속 CL 한쪽** | 14~21번 연속 → **21번에서 감지** |

**규칙 ②가 더 빨리 잡았다.** 23번에 한계를 넘기 2로트 전에 이미 신호가 떴다.

### PM 관점 해석

> *"규격(10μm)만 보면 25번까지 모두 합격이라 문제가 없어 보임.
> 관리도로 보면 21번에 이미 이상 신호가 나왔고 23번에 UCL을 넘음.
> 이 추세가 이어지면 몇 로트 뒤 규격을 넘어 **SAT·양산 불량**으로 이어질 수 있으므로,
> **불량이 나기 전에** 재연마 나이프를 점검하고 교체 주기를 조정함."*

**불량은 아직 0건인데 조치한다.** 이게 관리도를 쓰는 이유 전부다.

**유래**: **W. A. Shewhart**, Bell Telephone Laboratories, **1924-05-16**.
한 쪽짜리 내부 메모에서 시작됐다.

## 3-6. WBS로 되돌리기

**원인 후보마다 팀 문서의 어느 항목으로 가는지 적어 뒀다.**

| 원인 후보 | 연결 문서 | 활용 |
| --- | --- | --- |
| 7 교체 주기 | **WBS 1.7.2** 나이프 교체 주기표 | **주행 거리 기준** 교체 주기의 근거 |
| 9·10 측정 | 체크리스트 **C8** 계측기 교정 · **A5** FAT 절차서 | 측정 위치·횟수·방법과 교정 유효기간을 **사전 고정** |
| 3 샤프트 | 체크리스트 **B3·C1** 진원도·평행도 | **입고·조립 단계에서 미리 차단** |
| 6 나이프 로트 | 체크리스트 **B2** 나이프 입고 검사 | 경도·날끝 성적서와 실측 대조 |
| 11 분진 | WBS 1.3.1.1.8 기내 집진 · 체크리스트 **H5** | 집진 풍량을 정기 점검 항목에 포함 |

**원인 분석의 산출물이 "보고서"가 아니라 "WBS 항목과 체크리스트 수정"이다.**

```plain text
관리도 21번 신호
   → 6M 후보 8(재연마 품질) · 7(교체 주기) 먼저 확인
   → 나이프 교체 주기표 (WBS 1.7.2)에 반영
   → 다음 프로젝트의 체크리스트 B2·C8에 미리 들어간다
```

**2일차에 만든 WBS·체크리스트가 3일차 분석의 도착지가 된다.** 두 날이 한 덩어리다.

## 이 장 정리

### 한 줄 요약

**체크시트로 세고, 파레토로 고르고, 6M+5Why로 가설을 펼치고, 관리도로 시점을 찾고,
결론을 WBS와 체크리스트에 되돌려 넣는다.** 모든 원인은 확인 전까지 **추정**이다.

### 숫자 한눈에

| 항목 | 값 |
| --- | --- |
| 파레토 — 상위 3 / 상위 6 | **60% / 84%** (80:20 아님) |
| 1순위 원인 | 나이프 마모·날끝 깨짐 **28/100건** |
| 6M 원인 후보 | **12개** (전부 `추정·미확인`) |
| 5Why 사슬 | 6갈래 × 5단계 = **30개** |
| 버 초과 샘플 | **30개 중 8개 (26.7%)**, 초과값 14~22μm |
| 관리도 CL / UCL / LCL | **6.00 / 8.20 / 3.80 μm** (σ=0.74) |
| 규격 상한 USL | **10.0 μm** |
| 이상 감지 | **21번(8점 연속)** → 23번(UCL 초과) |
| 변곡점 | **15번 로트 — 재연마 나이프 투입** |

### 외워 둘 것

```plain text
6M   Man · Machine · Material · Method · Measurement · Mother nature
     (사람 · 설비 · 자재 · 방법 · 측정 · 환경)

확인 순서   측정 → 세팅·설비 → 자재·방법 → 환경
            (비용이 적고 정보량이 큰 것부터)

관리도      USL/LSL = 고객이 정한 규격      UCL/LCL = 공정이 정한 ±3σ
            판정 ① UCL·LCL 밖   ② 8점 연속 CL 한쪽
            기준 구간은 "안정된 구간"만 써서 CL을 계산한다
```

### 자주 틀리는 것

- 파레토를 **80:20으로 외운다** → 그래프에서 읽는다. 이 데이터는 60%/84%였다
- 한 사건에 **주원인을 두 개** 매긴다 → 누적 비율이 깨진다
- 원인 후보를 **원인으로 확정**한다 → 확인 전까지 **`추정·미확인`**
- 원인만 적고 **확인 방법을 안 적는다** → 추측으로 끝난다
- **측정을 안 의심하고** 설비부터 뜯는다 → 가장 싸고 빠른 확인을 건너뛴 것
- 관리 한계와 규격을 같은 선으로 본다 → **UCL과 USL은 다르다**
- **이상 구간까지 포함해 CL을 계산**한다 → 중심선이 올라가 이상이 안 보인다
- 규격 안이니 문제없다고 본다 → 관리도는 **불량 전에** 신호를 준다
- 분석을 보고서로 끝낸다 → **WBS 항목·체크리스트로 되돌린다**
