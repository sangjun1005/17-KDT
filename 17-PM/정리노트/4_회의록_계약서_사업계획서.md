## 4-1. 하루의 구조 — 세 묶음

```plain text
[A] 회의록      고객이 FAT를 1주 앞당겨 달라고 했다
                 -> 부서별로 묻고, PM이 조건부 결론을 낸다
                 -> 한국어 2판 + 영문 + 중문
                       |
[B] 계약서      회의록은 계약을 바꾸지 못한다
                 -> 공시 사례로 조건을 확인하고 (5곳)
                 -> 공급 계약서 본문을 쓰고
                 -> FAT 변경합의서로 "서명해야 바뀐다"를 못 박는다
                       |
[C] 사업계획서  같은 기술로 창업을 한다면
                 -> 슬리팅기 품질 관리 모듈 (주제 연장)
                 -> 오픈트레이 (전혀 다른 분야, 같은 양식)
                 -> 상세 평가표로 스스로 채점한다 (75점)
```

**A에서 B로 넘어가는 지점이 핵심이다.** 회의에서 "하겠다"고 말한 것과
계약이 바뀌는 것은 다른 일이다. 4-4의 변경합의서 7항이 그 문장이다.

## 4-2. FAT 1주 단축 검토 회의록

**상황**: 고객이 FAT(공장 출하 검사)를 기존 일정보다 **1주 앞당겨** 달라고 요청.

문서는 **2판**이다.

| 파일 | 크기 | 성격 |
| --- | --- | --- |
| `FAT_1주단축_부서별검토_PM결론_1쪽.docx` | 38,877 B | **1쪽 압축판** — 표 하나로 끝낸다 |
| `Team<팀>_FAT_1주단축_검토회의록_서식개선.docx` | 41,097 B | **정식 회의록** — 5개 절, 후속 조치 포함 |

### 부서별로 묻는 구조

6개 부서(영업 · 설계 · 구매 · 제작·조립 · 셋업·품질 · 고객 협의)에
**같은 3가지를 묻는다.**

```plain text
① 무엇이 걱정인가 (우려)
② 무엇은 양보할 수 없나 (지켜야 할 기준)
③ PM이 무엇을 해 주면 되나 (지원·조정)
      -> 그래서 부서 결론은?
```

| 부서 | 양보할 수 없는 것 | 부서 결론 |
| --- | --- | --- |
| 영업 | 일정 약속 · 계약 조건 | 가능성 확인 후 **조건부** 수용 |
| 설계 | 설계 정확성 · 사양 충족 | **사양 동결**·필수 검토 완료가 전제 |
| 구매 | 필수 부품 납기 · 승인된 품질 | 확정 입고일이 조립 일정에 맞아야 가능 |
| 제작·조립 | 조립 정확성 · 작업 안전 | **정렬·체결 확인은 생략 불가** |
| 셋업·품질 | 안전·성능 기준 · 검사 신뢰성 | **Pre-FAT·필수 검사 통과 후** FAT |
| 고객사 | 요구 성능 · 실제 인도 일정 | 소재·사양·참관 일정 확정 및 변경 조건 합의 |

### PM의 결론 — 거절도 승낙도 아니다

> "고객 요청은 최대한 반영하되, 품질과 안전을 충족할 수 있는지 **검증한 후 확정**하겠습니다.
> 필수 시험 시간을 확보하지 못하면 **기존 FAT 일정을 유지**하겠습니다."

**수용 조건 5개를 전부 확인해야 성립한다.**

1. 필수 부품 입고
2. 조립·셋업 완료
3. Pre-FAT 통과
4. 추가 인력·예산 확보
5. 고객의 일정·비용 변경 **서면 합의**

**대안까지 미리 적어 둔다.** 조건 미충족 시 기존 FAT를 유지하고,
고객 희망일에는 **진도 확인·사전 검수만** 한다 — "최종 FAT 합격으로 처리하지 않는다."

### 후속 조치표가 회의록의 진짜 결과물

| 담당 | 제출물 | 기한안 |
| --- | --- | --- |
| 영업 | 고객 요청 사유 · 기존/희망 FAT 날짜 · 시험 범위 · 시료 확인서 | D+1 영업일 |
| 설계 | 미결 사양·도면 목록, 조립 공정별 완료일, 타 프로젝트 영향 | D+1 영업일 |
| 구매 | 핵심 부품 확정 입고일, 긴급 조달 견적, 지급 일정 | D+1 영업일 |
| 셋업·품질 | 셋업·Pre-FAT·재시험 계획, 시험 소재·장비 현황 | D+1 영업일 |
| PM | 통합 일정·위험·추가 비용 검토 후 **진행/보류안** | D+2 영업일 |
| 영업·PM | 내부 승인 후 **고객 변경 합의서 확보** 및 최종 일정 회신 | 고객 회신 기한 내 |

**`D`는 실제 회의일을 뜻한다.** 날짜를 비워 두고 상대 기한으로 쓴 것은
문서가 아직 초안이기 때문이다. 문서 머리말에 **"검토용 초안 / 실제 발언·합의 여부는 회의 후 확인"**
이라고 못 박혀 있다.

```plain text

  "设计<이름> | 未定规格及图纸变更可能造成返工。需冻结关键规格、优先出图…"
```

빈칸을 번역 과정에서 메우지 않은 것이 중요하다.

## 4-5. 지급 비율이 2일차와 다르다

| | 2일차 예산배분표 (게이트) | 4일차 공급계약서 4조 | 공시 사례 ① 텐파워 |
| --- | --- | --- | --- |
| 선급·계약금 | **30%** | **30%** | **30%** |
| 출하·선적 전 | **40%** | **50%** | **50%** |
| SAT 합격 | **20%** | **20%** | — |
| 잔금 | **10%** | — | **20%** (10+10 분할) |
| 단계 수 | 4 | 3 | 3 |

**어느 쪽이 맞다는 문서가 없다.** 2일차는 G0~G5 게이트 6단계에 맞춰 4분할했고,
4일차는 공시 사례 ①을 따라 3분할했다. **확인 필요 항목이다.**

> 2일차 예산배분표를 다시 볼 때 **금액(160억)과 비율을 같이 확인해야 한다.**
> 선급 48억(30%) · 출하 64억(40%) · SAT 32억(20%) · 잔금 16억(10%) = 160억 — 2일차 기준.
> 계약서 비율(30/50/20)을 적용하면 48 / 80 / 32억이 된다.

### 성능 목표를 "검증 방법"과 묶어서 쓴다

슬릿인사이트의 5개 목표는 **전부 측정 절차가 붙어 있다.**

| 성능 목표 | 검증 방법 |
| --- | --- |
| 버 검출 **재현율 95% 이상** | 기준 확인 불량 100개 이상, `TP/(TP+FN)`. **학습·평가 표본 분리** |
| 정상 **오검출률 5% 이하** | 정상 100개 이상, `FP/(FP+TN)`. 전극·속도별 기록 |
| 폭 측정 오차 **±0.02mm 이내** | 30개 이상 측정점, 기준 측정기 비교. 교정·장력·온도·위치 통일 |
| 나이프 판정 **일치율 90% 이상** | 등급 시료 30개 이상, 현미경 판정과 비교 |
| 데이터 기록 **완전성 99% 이상** | 8시간 예정 기록 대비 저장 비율. 통신 중단·복구 시 누락 확인 |

**재현율·오검출률·표본 분리 — 딥러닝 과목에서 쓴 그 지표다.**
사업계획서에서 `TP/(TP+FN)`을 그대로 쓰는 게 이 과정의 성격을 보여준다.

**문서가 스스로 경계를 긋는다**: "아래 수치는 **상용 보증이 아닌 개발 목표**다."
"버 발생을 마모의 확정 증거로 단정하지 않는다." "측정기 교정 상태와 반복 측정 편차를 **먼저** 확인한다."

### 오픈트레이 — 일부러 다른 분야를 골랐다

| 개발 목표 | 값 |
| --- | --- |
| 하중 범위 | 100~2,000g 정지 하중 |
| 오차 | **±10g 이내** |
| 갱신 | 안정화 후 **5초 이내** |
| 기록 완전성 | 8시간 **99% 이상** |

**개선 목표**: 재고 확인 시간 **30% 감소**, 음료 100잔당 대상 식재료 폐기량 **15% 감소**.
"판매량·메뉴·행사 차이를 함께 기록해 효과를 평가한다" — **교란 변수를 미리 적어 둔다.**

**제외를 분명히 한다**: 받침대는 **부패를 판정하지 않는다**.
개봉은 직원이 앱에서 등록하며 **무게만으로 자동 추정하지 않는다**.
식품 안전을 보증하지 않는다.

## 4-7. 사업계획서 상세 평가 — 75점

`슬리팅기_사업계획서_상세평가표_1쪽.pdf` (103,766 B)
**자기 계획서를 심사 관점으로 다시 채점한 문서다.** 5개 항목 × 20점.

| 평가 항목 | 점수 | 감점 사유 |
| --- | --- | --- |
| 문제·필요성 | **17** / 20 | −3: 불량 빈도·교체 판단 시간·손실 비용의 **현장 자료가 없음** |
| **차별성** | **12** / 20 | **−8: 기존 비전검사·설비 관리 시스템과의 기능·가격 비교가 없음** |
| 기술 실현성 | **15** / 20 | −5: 전극 사양·운전 속도·최소 검출 버 크기·광학계 사양이 미정 |
| 사업성 | **13** / 20 | −7: 견적·구매 의향·도입비 회수 근거가 없음 |
| 실행 계획 | **18** / 20 | −2: 실증 설비·협력사·외부 자금 7,000만원이 미확보 |
| **종합** | **75** / 100 | |

**가장 크게 깎인 것이 차별성(−8)이다.** 기술이 아니라 **"왜 우리 것을 사야 하나"**가 비어 있었다.

### 우선 보완 3가지

1. **고객 문제 입증** — 불량 건수·폐기비·정지시간·교체 작업시간의 **기준값부터** 확보
2. **핵심 성능 실증** — 합의한 전극·속도에서 버 검출·폭 측정을 우선 검증, 시험 성적 첨부
3. **구매 타당성** — 비교표 + 실제 견적 + 고객 절감액을 연결해 **"왜 4,000만원을 내는가"**에 답한다

### 심사 관점의 마지막 문장

> "목표 수치를 **달성 실적으로 표현하지 말고**, 검증 결과에 따라 사양과 가격을 조정해야 한다."

**이 과정에서 반복된 규칙과 같다.** 3일차에서 "원인 후보는 전부 추정·미확인",
이번엔 "목표를 실적으로 쓰지 말라".

| 비목 | 슬릿인사이트 | 오픈트레이 |
| --- | --- | --- |
| 재료비 | 12,000,000 (카메라·광학계) | 12,000,000 (센서·제어부) |
| 재료비 | 13,000,000 (센서·제어 600 + 기구·지그 700) | 13,000,000 (기구·전원·시제품) |

| **개발 인건비** | **35,000,000** (2명×7개월×250만) | **35,000,000** (2명×7개월×250만) |
| **시험·분석비** | **10,000,000** | **10,000,000** |
| 지식재산비 | 3,000,000 | — |
| 현장 출장비 | 4,000,000 | — |
| 사업화 준비비 | 5,000,000 | 10,000,000 (출장 400 + 권리화 300 + 소개자료 300) |

## 4-9. 이 날의 문장 규칙

이 날 만든 10개 문서에 **같은 장치가 반복된다.** 외부로 나가는 문서의 작성법이다.

| 장치 | 실제 문장 |
| --- | --- |
| **빈칸을 메우지 않는다** | `[확인 필요]` `[ ]mm` `미설정` `미정` — 모르는 것은 비워 둔다 |
| **문서 성격을 머리에 쓴다** | "검토용 초안" · "미서명 초안" · "교육용 비공식 서면평가" |
| **목표와 실적을 구분한다** | "모두 시험 전 목표다" · "확정 수익으로 반영하지 않는다" |
| **실적 없음을 적는다** | "시제품·매출·투자·고용·특허·실증 실적은 없다" |
| **제외를 명시한다** | 계약서 1조 제외 목록 · "부패를 판정하지 않는다" |
| **연습값을 끌고 오지 않는다** | "과거 모의 버 기준 10μm는 자동 적용하지 않는다" |
| **상대 기한을 쓴다** | `D+1 영업일` — 날짜가 안 정해졌으니 |
| **출처를 구분한다** | "①은 공시 본문, ②는 계약 보도, ③~⑤는 공시 보도·증권사 자료" |
| **AI 사용을 기록한다** | 3일차 문서들의 "AI 사용 기록" 줄과 동일 |

**가장 자주 나오는 말이 "확인 필요"다.**
모르는 것을 모른다고 쓴 문서가, 다 채워 넣은 문서보다 신뢰도가 높다 — 이 날의 결론.
