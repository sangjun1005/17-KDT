```
같은 원본에서 나온 사진 A(원본), A'(15도 회전), A''(좌우 반전)
  → 무작위로 8:2 분할하면 A는 학습, A'는 검증에 들어갈 수 있다

```

**이게 데이터 누수(data leakage)다.** 5장에서 `test_set`이 훈련 폴더를 가리켰던 것과
결과는 같지만 **훨씬 알아채기 어렵다.** 파일 이름이 다르니까.

### 이 프로젝트의 답

```
원본 한 장 = 한 번의 촬영
  → 원본을 나누는 순간 형제가 생길 수 없다
  → 데이터는 354장으로 줄지만 점수를 믿을 수 있다
```

**"데이터를 늘릴 것인가, 점수를 믿을 것인가"를 후자로 택했다.**

그리고 §20 부록에서 **그 선택의 근거를 숫자로 보인다.**

**둘 다 "다수 클래스로 찍기"를 걸러낸다는 점은 같다.**
macro-F1은 재현율뿐 아니라 정밀도도 보므로, "단핵구를 다 맞히려고 아무거나 단핵구라 찍는" 전략까지 벌한다.
5장 5-6의 균형정확도에서 한 걸음 더 나간 지표다.

**정확도는 함께 보고하되 주지표가 아니다.** 이 한 문장이 보고서의 신뢰도를 결정한다.

### 층화 3분할 + 누수 점검

```python
def make_split(seed=SPLIT_SEED, test_size=0.2, val_size=0.2):
    x_tv, x_te, y_tv, y_te = train_test_split(
        paths, labels, test_size=test_size, stratify=labels, random_state=seed)
    x_tr, x_va, y_tr, y_va = train_test_split(
        x_tv, y_tv, test_size=val_size, stratify=y_tv, random_state=seed)

    s_tr, s_va, s_te = set(x_tr), set(x_va), set(x_te)
    assert not (s_tr & s_va) and not (s_tr & s_te) and not (s_va & s_te), '분할이 겹친다'
    return (x_tr, y_tr), (x_va, y_va), (x_te, y_te)
```

**`train_test_split`을 두 번 불러 3분할을 만든다.** sklearn에 3분할 함수가 없어서다.

**`stratify=labels`가 20장짜리 단핵구 때문에 반드시 필요하다.**
안 쓰면 검증셋에 단핵구가 0장인 분할이 나올 수 있다.

**집합 연산으로 겹침을 확인하는 게 좋은 습관이다.** 한 줄이면 된다.

## P-4. 반복 홀드아웃 — K-Fold 없이 같은 목적 달성하기

### 문제

```
test 71장, 그중 단핵구 4장
```

**단핵구를 한 장 더 맞히고 덜 맞히고에 균형정확도가 크게 흔들린다.**
`1/4 = 0.25`씩 움직인다. 한 번의 결과는 대부분 운이다.

### 해법

```python
for seed in SEEDS:                        # 시드 5개
    (tr, va, te) = make_split(seed)       # 분할을 새로 만든다
    model = train(tr, va, FINAL_CFG)      # 그 시드의 train/val 로만
    scores.append(evaluate(model, te))    # test 는 마지막에 한 번

summary = rep[['test_accuracy','test_balanced','test_auc']].agg(['mean','std'])
```

**수업에 K-Fold가 없으니 `random_state`를 바꾼 층화분할을 반복한다.**
목적은 같다 — **한 번의 운을 평균으로 걷어내는 것.**

</table>

**결과는 반드시 "평균 ± 표준편차"로 쓴다.** 최고 시드의 점수만 쓰면 그건 체리피킹이다.

### 지켜야 할 규칙 네 가지

```
1. 설정을 확정한 뒤에는 한 글자도 바꾸지 않는다
2. 시드마다 분할을 새로 만들고, 그 시드의 train 으로만 학습한다
3. 조기종료·체크포인트는 그 시드의 val 로만 판단한다
4. test 는 학습이 끝난 뒤 한 번 채점하고, 그 결과를 보고 아무것도 바꾸지 않는다
```

**4번이 가장 지키기 어렵다.** test 점수를 보고 "학습률을 조금만 바꿔 볼까" 하는 순간
test는 검증셋이 되고, 보고하는 점수는 부풀려진다.

5장 5-7에서 "임계값은 검증셋에서 고른다"고 한 것과 같은 원칙이다.

## P-5. 가설검정을 numpy로 직접 구현하기

### 상황

**과제에서 가설검정을 요구했는데 수업에는 통계 검정이 한 번도 안 나온다.**
(`가설`·`유의수준`·`p값`·`scipy` 등장 0회)

그래서 **numpy와 `math.comb`만으로 직접 구현**했다.
원리가 코드에 그대로 보이므로 "모르고 갖다 쓴 것"이 아니라는 게 같이 보인다.

### 원리는 딱 두 가지다

**① 섞어서 세기 (순열검정)**

> "차이가 진짜 없다면, 정답표를 뒤섞어도 지금만큼의 차이가 자주 나와야 한다."

```python
def paired_permutation(a_ok, b_ok, n_perm=20000, seed=0):
    d = a_ok.astype(int) - b_ok.astype(int)   # 문제마다 +1 / 0 / -1
    obs = d.mean()

    rs = np.random.RandomState(seed)
    null = np.empty(n_perm)
    for i in range(n_perm):
        flip = rs.choice([-1, 1], size=len(d))   # 문제마다 A·B를 바꿔치기
        null[i] = (d * flip).mean()

    p = float((np.abs(null) >= abs(obs) - 1e-12).mean())
    return dict(obs=float(obs), p=p, null=null)
```

```
p값 = (뒤섞었을 때 지금만큼 큰 차이가 나온 횟수) ÷ (뒤섞은 총 횟수)
```

**분포표도 공식도 필요 없다. 세기만 하면 된다.**
`t분포`나 `정규근사` 같은 가정도 없다.

**`d * flip`이 핵심이다.** 두 모델이 똑같다면 문제마다 A와 B의 결과를 바꿔치기해도
전체 차이는 지금과 비슷해야 한다. 그래서 부호를 무작위로 뒤집는다.

**② 경우의 수 전부 세기 (정확검정)**

```python
def exact_sign_permutation(d):
    """d : 짝지은 점수 차이 (예: 시드 5개의 A점수 - B점수)"""
    n = len(d); obs = d.mean(); cnt = 0
    for mask in range(2 ** n):                 # 2^5 = 32가지 전부
        signs = np.array([1 if (mask >> i) & 1 else -1 for i in range(n)])
        if abs((d * signs).mean()) >= abs(obs) - 1e-12:
            cnt += 1
    return dict(obs=float(obs), p=cnt / 2 ** n, n_cases=2 ** n)
```

**표본이 작으면 뒤섞는 대신 모든 경우를 나열한다. 근사가 없다.**
시드 5개면 `2⁵ = 32`가지뿐이다.

**p값의 최솟값이 `1/32 = 0.031`이라는 점에 주의한다.**
시드가 5개면 아무리 차이가 커도 `p < 0.031`은 나올 수 없다.

```python
def binom_test_greater(k, n, p0):
    """'관측된 k 이상이 우연히 나올 확률' — k부터 n까지 전부 더한다"""
    return float(sum(comb(n, i) * p0**i * (1-p0)**(n-i) for i in range(k, n + 1)))
```

`math.comb`로 이항분포 확률을 직접 더한다. 이것도 근사가 없다.

### P-8-8. 가설검정 4종 — 실측 p값

**검정 1 — McNemar** (C+ 미세조정+가중치 vs A 밑바닥 CNN, 같은 71장)

<table fit-page-width="true" header-row="true">
<tr><td></td><td>A 맞음</td><td>A 틀림</td></tr>
<tr><td>C+ 맞음</td><td>49</td><td><strong>10</strong></td></tr>

```
불일치 15건 (b=10, c=5) → 정확 이항검정  통계량 5.0000  p = 0.3018
정확도 0.8310 vs 0.7606   차이 +0.0704
판정: H0 기각 못함 — 차이를 입증하지 못했다
```

**정확도가 7%p나 높은데 유의하지 않다.** test가 71장이라 **검정력이 낮기 때문**이다.
"기각 못 함"은 "같다"가 아니다. 이 구분을 흐리면 검정을 한 의미가 없다.

**대각선 49와 7은 검정에 쓰이지 않는다.** 둘 다 맞히거나 둘 다 틀린 문제는
두 모델을 구분하는 정보가 없다. **불일치 칸만 본다** — 이것이 McNemar의 전부다.

**검정 2 — 대응표본** (증강 `flip_rot` vs `none`, 같은 시드 5개)

```
95% 신뢰구간 [+0.0211, +0.0770]

윌콕슨     : W = 1.0,    p = 0.1250        (정규성 가정이 약한 대안)
효과크기 Cohen's d = 1.54 (큼)
```

**t검정은 유의하고 윌콕슨은 아니다.** 모순이 아니라 **표본이 5개라 그렇다.**
윌콕슨의 p값 최솟값이 `1/16 = 0.0625`라서 5쌍으로는 어떤 결과가 나와도 `p < 0.05`가 불가능하다.
**둘 다 보고하고, 왜 갈리는지 적는 것**이 정직한 처리다.

**시드 42에서만 증강이 손해(-0.0021)였다.** 짝지어 보지 않으면 이런 게 안 보인다.

**검정 3 — 이항검정(단측)**: "다수 클래스 찍기보다 나은가"

```
H0: 정확도 = 0.5932 (전부 호중구)      H1: > 0.5932
관측 59/71 = 0.8310
p = 1.52e-05   95% 신뢰구간 (0.7406, 1.0)
판정: H0 기각 → 모델이 다수 클래스 찍기보다 유의하게 낫다
```

**검정 1은 기각 못 했는데 검정 3은 기각했다.** 같은 71장, 같은 모델이다.
차이는 **비교 대상과의 간격**이다. 0.0704(모델 대 모델)는 못 잡고 0.2378(모델 대 기준선)은 잡는다.
**71장의 검정력이 그 사이 어딘가에 있다**는 뜻이다.

**검정 4 — 두 비율 z검정**: 누수가 점수를 부풀리는가 ⭐

```
① 무작위 검증 (증강본을 무작위 분할) : 1988/1992 = 0.9980
③ 공식 TEST  (제작자가 따로 만든 폴더): 2073/2487 = 0.8335
차이 +0.1645   95% 신뢰구간 [+0.1497, +0.1792]
z = 18.803   p = 7.16e-79
```

**P-2에서 "누수다"라고 말로 했던 것이 여기서 숫자가 됐다.**
같은 모델, 같은 학습인데 **시험지를 어떻게 만드느냐에 따라 정확도가 16.5%p 차이 난다.**

`p = 7e-79`는 사실상 0이다. 우연일 가능성이 없다.

**서로 다른 표본이라 McNemar가 아니라 두 비율 검정을 쓴 것**도 맞다.
①과 ③은 사진 자체가 다르므로 짝을 지을 수 없다.

**다중비교 보정**: 검정 4개를 했으므로 Holm-Bonferroni를 적용했다.
p값을 오름차순으로 정렬해 k번째에 `(m-k+1)`을 곱한다. 검정 4개면 우연히 하나가 유의할 확률이 **18.5%**다.

## 이 프로젝트 정리

### 흐름

```
데이터 감사      354장 확정, 뺀 이유를 세어 둔다
   ↓
누수 차단        원본만 쓴다. 이유는 §20에서 숫자로
   ↓
기준선 0         전부 호중구 = 정확도 0.5932 / macro-F1 0.1862
   ↓
베이스라인 3단    A 밑바닥 → B 백본고정 → C+ 미세조정+가중치
   ↓
실험 1~4         에폭 · 증강 · 하이퍼파라미터 · 백본 (검증셋으로만)
   ↓
설정 확정        여기서 한 글자도 더 안 바꾼다
   ↓
반복 홀드아웃 5회  test 를 처음 연다 → 0.8507 ± 0.0514 (정확도) / 0.8010 ± 0.0803 (macro-F1)
   ↓
해석             Grad-CAM · 보류 임계값 · 가설검정 · 다중비교 보정
```

### 실험을 설계할 때의 원칙

```
1. 기준선을 먼저 만든다 (찍기, 규칙 기반, 밑바닥 모델)
2. 계단을 한 칸씩 올려 무엇이 기여했는지 분리한다
3. 선택은 전부 검증셋으로 한다
4. test 는 마지막에 한 번만 연다
5. 한 번의 결과를 믿지 않는다 — 반복하고 평균 ± 표준편차
6. 차이가 우연이 아닌지 검정한다
7. 모델이 무엇을 보고 판단했는지 확인한다
```

### 자주 틀리는 것

- **증강본을 무작위로 분할한다** (형제 사진이 양쪽에 들어간다)
- 불균형 데이터에서 **정확도를 주지표로** 쓴다
- `stratify=`를 빼먹어 소수 클래스가 한쪽 분할에 0장이 된다
- test 점수를 보고 설정을 바꾼다
- **한 번의 홀드아웃 결과**를 성능으로 보고한다
- 같은 시험지를 본 두 모델을 **독립 표본으로** 검정한다
- 검정을 여러 번 하고 **다중비교 보정을 안 한다**
- **실행하지 않은 노트북의 계획 수치**를 결과로 인용한다 (이 장의 이전 판이 그랬다 — P-8-11)
- 소수 클래스 재현율을 **분모 없이** 쓴다 ("단핵구 50%"는 4장 중 2장이다)
