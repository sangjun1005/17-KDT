```python
def make_split(seed=SPLIT_SEED, test_size=0.2, val_size=0.2):
    x_tv, x_te, y_tv, y_te = train_test_split(
        paths, labels, test_size=test_size, stratify=labels, random_state=seed)
    x_tr, x_va, y_tr, y_va = train_test_split(
        x_tv, y_tv, test_size=val_size, stratify=y_tv, random_state=seed)

    s_tr, s_va, s_te = set(x_tr), set(x_va), set(x_te)
    assert not (s_tr & s_va) and not (s_tr & s_te) and not (s_va & s_te), '분할이 겹친다'
    return (x_tr, y_tr), (x_va, y_va), (x_te, y_te)
```

**`train_test_split`을 두 번 불러 3분할을 만든다.** sklearn에 3분할 함수가 없어서다.

**`stratify=labels`가 21장짜리 단핵구 때문에 반드시 필요하다.**
안 쓰면 검증셋에 단핵구가 0장인 분할이 나올 수 있다.

**집합 연산으로 겹침을 확인하는 게 좋은 습관이다.** 한 줄이면 된다.

### 지켜야 할 규칙 네 가지

```
1. 설정을 확정한 뒤에는 한 글자도 바꾸지 않는다
2. 시드마다 분할을 새로 만들고, 그 시드의 train 으로만 학습한다
3. 조기종료·체크포인트는 그 시드의 val 로만 판단한다
4. test 는 학습이 끝난 뒤 한 번 채점하고, 그 결과를 보고 아무것도 바꾸지 않는다
```

**4번이 가장 지키기 어렵다.** test 점수를 보고 "학습률을 조금만 바꿔 볼까" 하는 순간

5장 5-7에서 "임계값은 검증셋에서 고른다"고 한 것과 같은 원칙이다.

## P-5. 가설검정을 numpy로 직접 구현하기

### 상황

**과제에서 가설검정을 요구했는데 수업에는 통계 검정이 한 번도 안 나온다.**
(`가설`·`유의수준`·`p값`·`scipy` 등장 0회)

그래서 **numpy와 `math.comb`만으로 직접 구현**했다.
원리가 코드에 그대로 보이므로 "모르고 갖다 쓴 것"이 아니라는 게 같이 보인다.

### 원리는 딱 두 가지다

**① 섞어서 세기 (순열검정)**

> "차이가 진짜 없다면, 정답표를 뒤섞어도 지금만큼의 차이가 자주 나와야 한다."

```python
def paired_permutation(a_ok, b_ok, n_perm=20000, seed=0):
    d = a_ok.astype(int) - b_ok.astype(int)   # 문제마다 +1 / 0 / -1
    obs = d.mean()

    rs = np.random.RandomState(seed)
    null = np.empty(n_perm)
    for i in range(n_perm):
        flip = rs.choice([-1, 1], size=len(d))   # 문제마다 A·B를 바꿔치기
        null[i] = (d * flip).mean()

    p = float((np.abs(null) >= abs(obs) - 1e-12).mean())
    return dict(obs=float(obs), p=p, null=null)
```

```
p값 = (뒤섞었을 때 지금만큼 큰 차이가 나온 횟수) ÷ (뒤섞은 총 횟수)
```

**분포표도 공식도 필요 없다. 세기만 하면 된다.**
`t분포`나 `정규근사` 같은 가정도 없다.

**`d * flip`이 핵심이다.** 두 모델이 똑같다면 문제마다 A와 B의 결과를 바꿔치기해도
전체 차이는 지금과 비슷해야 한다. 그래서 부호를 무작위로 뒤집는다.

**② 경우의 수 전부 세기 (정확검정)**

```python
def exact_sign_permutation(d):
    """d : 짝지은 점수 차이 (예: 시드 5개의 A점수 - B점수)"""
    n = len(d); obs = d.mean(); cnt = 0
    for mask in range(2 ** n):                 # 2^5 = 32가지 전부
        signs = np.array([1 if (mask >> i) & 1 else -1 for i in range(n)])
        if abs((d * signs).mean()) >= abs(obs) - 1e-12:
            cnt += 1
    return dict(obs=float(obs), p=cnt / 2 ** n, n_cases=2 ** n)
```

**표본이 작으면 뒤섞는 대신 모든 경우를 나열한다. 근사가 없다.**
시드 5개면 `2⁵ = 32`가지뿐이다.

**p값의 최솟값이 `1/32 = 0.031`이라는 점에 주의한다.**
시드가 5개면 아무리 차이가 커도 `p < 0.031`은 나올 수 없다.

```python
def binom_test_greater(k, n, p0):
    """'관측된 k 이상이 우연히 나올 확률' — k부터 n까지 전부 더한다"""
    return float(sum(comb(n, i) * p0**i * (1-p0)**(n-i) for i in range(k, n + 1)))
```

`math.comb`로 이항분포 확률을 직접 더한다. 이것도 근사가 없다.

## 이 프로젝트 정리

### 흐름

```
데이터 감사      354장 확정, 뺀 이유를 세어 둔다
   ↓
누수 차단        원본만 쓴다. 이유는 §20에서 숫자로
   ↓
기준선 0         전부 호중구 = 정확도 0.59 / 균형정확도 0.25
   ↓
베이스라인 3단    A 밑바닥 → B 백본고정 → C+ 미세조정+가중치
   ↓
실험 1~4         에폭 · 증강 · 하이퍼파라미터 · 백본 (검증셋으로만)
   ↓
설정 확정        여기서 한 글자도 더 안 바꾼다
   ↓
반복 홀드아웃 5회  test 를 처음 연다. 평균 ± 표준편차
   ↓
해석             Grad-CAM · 보류 임계값 · 가설검정 · 다중비교 보정
```

### 실험을 설계할 때의 원칙

```
1. 기준선을 먼저 만든다 (찍기, 규칙 기반, 밑바닥 모델)
2. 계단을 한 칸씩 올려 무엇이 기여했는지 분리한다
3. 선택은 전부 검증셋으로 한다
4. test 는 마지막에 한 번만 연다
5. 한 번의 결과를 믿지 않는다 — 반복하고 평균 ± 표준편차
6. 차이가 우연이 아닌지 검정한다
7. 모델이 무엇을 보고 판단했는지 확인한다
```

### 자주 틀리는 것

- **증강본을 무작위로 분할한다** (형제 사진이 양쪽에 들어간다)
- 불균형 데이터에서 **정확도를 주지표로** 쓴다
- `stratify=`를 빼먹어 소수 클래스가 한쪽 분할에 0장이 된다
- test 점수를 보고 설정을 바꾼다
- **한 번의 홀드아웃 결과**를 성능으로 보고한다
- 같은 시험지를 본 두 모델을 **독립 표본으로** 검정한다
- 검정을 여러 번 하고 **다중비교 보정을 안 한다**
- **실행하지 않은 노트북의 계획 수치**를 결과로 인용한다
