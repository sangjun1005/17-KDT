# 1. 파이토치 시작하기

**실습 파일**: `1.ipynb`

환경이 제대로 잡혔는지 확인하는 장이다. 셀이 네 개뿐이지만
**GPU를 왜 쓰는지, 시간을 어떻게 재는지**가 들어 있다.

---

## 1-1. 장치 확인

### 개념

파이토치는 텐서가 **CPU에 있는지 GPU에 있는지**를 구분한다.
케라스는 GPU가 있으면 알아서 썼지만, 파이토치는 **직접 옮겨야 한다.**

### 핵심 코드

```python
import torch

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print(device)      # cuda
```

`torch.cuda.is_available()`이 `False`면 GPU를 못 쓰는 상태다.
이 경우 원인은 셋 중 하나다.

| 원인 | 확인 |
|---|---|
| GPU가 없다 | 노트북 사양 |
| CPU 전용 파이토치를 깔았다 | `print(torch.__version__)`에 `+cu`가 붙어 있는지 |
| CUDA 드라이버 문제 | `nvidia-smi` |

```python
print(torch.__version__)      # 2.13.0+cu130
```

`+cu130`이 **CUDA 13.0용 빌드**라는 뜻이다. 이게 없으면 CPU 전용이다.

### 이 한 줄을 쓰는 이유

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
```

`"cuda"`라고 못 박지 않고 이렇게 쓰면, **GPU가 없는 컴퓨터에서도 같은 코드가 돈다.**
GPU가 있으면 GPU로, 없으면 CPU로 알아서 간다. 노트북을 다른 사람과 주고받을 때 필수다.

이 뒤로는 모든 모델과 데이터에 `.to(device)`를 붙인다.

## 1-2. 텐서 만들어 보기

```python
import torch

def main():
    x = torch.tensor([1.0, 2.0, 3.0])
    print('Hello, PyTorch!')
    print(f'Tensor x: {x}')

main()
```

```
Hello, PyTorch!
Tensor x: tensor([1., 2., 3.])
```

`torch.tensor`는 넘파이 배열과 거의 같다. 다른 점은 두 가지다.

| | 넘파이 | 파이토치 텐서 |
|---|---|---|
| 장치 | CPU만 | **CPU / GPU** |
| 미분 | 안 됨 | **자동 미분 지원** |

출력에 `tensor([1., 2., 3.])`처럼 점이 찍힌 건 실수형(`float32`)이라는 뜻이다.
`torch.tensor([1, 2, 3])`처럼 정수를 넣으면 `int64`가 된다.
**신경망 입력은 실수여야** 하므로 `1.0`처럼 점을 찍거나 `dtype=torch.float32`를 준다.

## 1-3. GPU가 얼마나 빠른가

### 핵심 코드

```python
import time

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

a_cpu = torch.randn(10000, 10000)
b_cpu = torch.randn(10000, 10000)

start_time = time.time()
c_cpu = torch.matmul(a_cpu, b_cpu)
cpu_time = time.time() - start_time
print(f'CPU 연산 시간: {cpu_time:.4f}초')

if torch.cuda.is_available():
    a_gpu = a_cpu.to(device)
    b_gpu = b_cpu.to(device)

    start_time = time.time()
    c_gpu = torch.matmul(a_gpu, b_gpu)
    torch.cuda.synchronize()   # GPU 연산 완료 대기
    gpu_time = time.time() - start_time
    print(f'속도 향상: {cpu_time/gpu_time:.1f}배 빨라짐!')
```

실행 결과

```
CPU 연산 시간: 2.2154초
속도 향상: 7.1배 빨라짐!
```

10000×10000 행렬 두 개를 곱한다. 곱셈만 **1조 번**이다.

### `torch.cuda.synchronize()` — 이 절의 핵심

**GPU 연산은 비동기다.**

```python
c_gpu = torch.matmul(a_gpu, b_gpu)   # 여기서 CPU는 기다리지 않는다
```

이 줄은 "GPU야 이거 계산해" 하고 **바로 다음 줄로 넘어간다.**
GPU가 아직 계산 중인데 CPU는 이미 `time.time()`을 찍는 것이다.

`synchronize()`를 빼면 어떻게 되나

```
실제 GPU 연산 시간 : 0.31초
잘못 측정된 시간   : 0.0003초   ← 명령을 보낸 시간만 잼
계산된 배수        : 7000배     ← 말이 안 되는 숫자
```

`torch.cuda.synchronize()`는 **GPU가 다 끝날 때까지 CPU를 붙잡아 둔다.**
그래야 제대로 된 시간이 나온다.

**GPU 시간을 잴 때는 항상 붙인다.** 이걸 모르면 벤치마크 결과가 전부 엉터리가 된다.

### `.to(device)`가 하는 일

```python
a_gpu = a_cpu.to(device)
```

CPU 메모리(RAM)에 있던 데이터를 **GPU 메모리(VRAM)로 복사**한다.

주의할 점이 두 가지다.

| 주의 | 설명 |
|---|---|
| **새 텐서를 돌려준다** | `a_cpu.to(device)`만 쓰면 원본은 그대로다. 반드시 대입해서 받는다 |
| **전송에도 시간이 든다** | 그래서 `start_time`을 전송 뒤에 찍었다 |

작은 연산은 **옮기는 시간이 더 오래 걸려** GPU가 오히려 느리다.
GPU가 이기는 건 데이터가 크고 연산이 무거울 때다.

### 7.1배를 어떻게 볼 것인가

실제 GPU는 이런 행렬곱에서 수십 배까지 나온다. 7.1배가 낮게 나온 이유가 있다.

- **첫 CUDA 연산에는 초기화 부담**이 붙는다. 두 번 재서 두 번째 값을 쓰면 더 정확하다
- CPU 쪽도 여러 코어를 쓰는 최적화된 구현이라 생각보다 빠르다

참고: 이 코드는 `gpu_time`을 계산해 놓고 **출력하지 않는다.**
배수만 보여 주므로 실제로 몇 초 걸렸는지는 알 수 없다. 한 줄 추가하면 좋다.

```python
print(f'GPU 연산 시간: {gpu_time:.4f}초')
```

## 1-4. 한글 폰트 설정

### 핵심 코드

```python
import matplotlib.pyplot as plt

plt.rc('font', family='Malgun Gothic')
plt.rcParams['axes.unicode_minus'] = False

plt.figure()
plt.title("한글 제목: 테스트 성공!")
plt.plot([1, 2, 3], [1, 4, 9])
plt.xlabel("가로축")
plt.ylabel("세로축")
plt.show()
```

matplotlib은 기본 폰트에 한글이 없어서 **네모(□□□)로 나온다.**
그래프에 한글을 쓸 거면 이 두 줄을 먼저 실행한다.

| 줄 | 하는 일 |
|---|---|
| `plt.rc('font', family=...)` | 한글이 있는 폰트로 바꾼다 |
| `axes.unicode_minus = False` | **음수 부호가 깨지는 것**을 막는다 |

두 번째 줄이 필요한 이유는 matplotlib이 기본으로 유니코드 마이너스(−, U+2212)를 쓰는데
한글 폰트에 그 글자가 없는 경우가 많기 때문이다. `False`로 두면 일반 하이픈(-)을 쓴다.

### 운영체제별 폰트

| OS | 폰트 이름 |
|---|---|
| 윈도우 | `Malgun Gothic` |
| macOS | `AppleGothic` |
| 리눅스 | `NanumGothic` (별도 설치) |

이 노트북은 **윈도우 기준**이다. 다른 환경에서 열면 폰트를 못 찾는다는 경고가 뜬다.

## 이 장 정리

| 항목 | 코드 | 기억할 것 |
|---|---|---|
| 장치 지정 | `torch.device("cuda" if ... else "cpu")` | GPU 없는 곳에서도 돌게 |
| 버전 확인 | `torch.__version__` | `+cu`가 있어야 GPU 빌드 |
| GPU로 이동 | `x = x.to(device)` | **대입해서 받는다** |
| GPU 시간 측정 | `torch.cuda.synchronize()` | **빼면 엉터리 값** |
| 한글 그래프 | `plt.rc('font', ...)` + `unicode_minus=False` | 둘 다 필요 |

### 첫 셀에 넣어 둘 것

```python
import torch
import matplotlib.pyplot as plt

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print(device, torch.__version__)

plt.rc('font', family='Malgun Gothic')
plt.rcParams['axes.unicode_minus'] = False
```

### 자주 틀리는 것

- `x.to(device)`만 쓰고 대입을 안 한다 → 원본은 CPU에 그대로
- GPU 시간 측정에서 `synchronize()`를 빠뜨린다 → 비현실적으로 빠른 값이 나온다
- 작은 데이터를 GPU로 옮긴다 → 전송 시간 때문에 오히려 느려진다
- `unicode_minus`를 안 끈다 → 음수 축 라벨만 네모로 나온다
