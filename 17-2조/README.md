# 2조 — 백혈구(WBC) 이미지 4클래스 분류

## 파일

| 파일 | 내용 |
|---|---|
| **`백혈구분류_전체과정.ipynb`** | **메인. 이 파일 하나로 전 과정이 돌아간다** (외부 모듈 불필요) |
| `프로젝트_가이드.md` | 발표·보고서용 설명 (모델 선정 근거, 가설검정 설계, 예상 질문) |

## 폴더 구조 (이대로 두어야 경로가 맞는다)

```
2조/
 ├─ dataset2-master/images/{TRAIN,TEST}/{EOSINOPHIL,LYMPHOCYTE,MONOCYTE,NEUTROPHIL}/
 ├─ dataset-master/{JPEGImages, labels.csv}
 ├─ 백혈구분류_전체과정.ipynb
 ├─ external/    ← 자동 생성 (증강 전 원본 = 외부 검증셋)
 └─ results/     ← 자동 생성 (runs.csv, ckpt/, preds/)
```

## 실행

```powershell
pip install timm scipy scikit-learn pandas matplotlib pillow
jupyter lab
```

노트북 맨 위 `RUN_LEVEL` 하나로 규모를 정한다.

| 값 | 용도 | 대략 시간(GPU) |
|---|---|---|
| `'test'` | 코드가 끝까지 도는지 확인 | 10~20분 |
| `'quick'` | 발표 준비용 축소 실험 | 1~2시간 |
| `'full'` | 최종 제출용 | 4~7시간 |

**중간에 멈춰도 된다.** 모든 실험이 `results/runs.csv` 에 누적되고,
이미 돌린 `run_id` 는 다음 실행 때 자동으로 건너뛴다. 이게 "무한 반복"을 감당하는 장치다.

## 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| `DataLoader worker` 오류 / 커널 멈춤 (윈도우) | 상단에서 `NUM_WORKERS = 0` |
| CUDA out of memory | `BATCH_SIZE = 32`, 또는 `RUN_LEVEL` 의 `image_size` 를 160 으로 |
| 그래프 한글이 □ | §1 폰트 셀 확인 (맑은 고딕) |
| 에폭이 3분 초과 (`⚠3분초과`) | §8 아래의 "대응 순서" |
| 같은 실험 다시 돌리기 | `run_experiment(..., force=True)` 또는 `run_id` 변경 |
| 처음부터 다시 | `results/` 폴더 삭제 |
