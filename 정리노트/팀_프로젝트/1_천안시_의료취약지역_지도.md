### 시도 2 — 출처를 바꿔서 해결

```python
df = pd.read_excel("02_의료기관.xlsx", header=1)   # 통계연보 표, 35행
```

**병원 하나하나의 목록이 아니라 읍면동별로 이미 집계된 통계표를 쓴다.**
이 표는 인구 통계와 **같은 기관이 같은 행정동 기준으로 만든 것**이라 키가 맞는다.

```python
df2 = df.rename(columns={"읍면동별(2)": "지역", "합계": "의료기관수"})
df2 = df2[["지역","의료기관수","보건소","보건지소","보건진료소"]].copy()
df2 = df2.drop(index=0).reset_index(drop=True)     # 2단 헤더의 두 번째 줄 제거

for col in ["의료기관수","보건소","보건지소","보건진료소"]:
    df2[col] = df2[col].replace("-", 0).astype(int)
```

**`"-"`를 0으로 바꾸는 처리가 핵심이다.** 통계표는 "없음"을 하이픈으로 쓴다.
안 바꾸면 컬럼 전체가 `object`로 남아 산술 연산이 안 된다.

> **`drop(index=0)`**은 헤더가 2단이라 첫 데이터 행이 실제로는 `병원수 / 병상수` 같은 부제목이기 때문이다.
> `header=1`로 읽어도 한 줄이 더 남는다.

**교훈: 키가 안 맞으면 매핑 테이블을 만드는 것보다 같은 기준의 다른 출처를 찾는 편이 빠를 때가 있다.**
행정동↔법정동 대응표를 만들려면 쌍용동 → 쌍용1·2·3동에 병원을 **어떻게 나눌지**부터 정해야 하는데, 근거가 없다.

**평균 7.55인데 중앙값은 4.56이다.** 평균이 중앙값의 1.7배 — **오른쪽으로 심하게 치우쳤다.**

```python
iqr = (7.40 - 1.99) * 1.5      # 8.115
print(1.99 - iqr)              # -6.125  (하한, 음수라 의미 없음)
print(7.40 + iqr)              # 15.515  (상한)
# 이상치: 59.55
```

**59.55는 상한 15.515의 네 배다.** 확실한 이상치다.

**이런 분포에서는 평균을 기준선으로 쓰면 안 된다.** 이상치 하나가 평균을 끌어올려
"평균 이하"인 지역이 지나치게 많아진다. 그래서 **중앙값 4.56을 기준으로 삼았다.**

> 박스플롯을 `plt.boxplot(data)`가 아니라 `ax.bxp(stats)`로 그린 것이 눈에 띈다.
> 통계량(`med`, `q1`, `q3`, `whislo`, `whishi`, `fliers`)을 **직접 넣어서** 그린다.
> 원시 데이터 없이 요약값만으로 박스플롯을 그려야 할 때 쓰는 방법이다.

### 자주 틀리는 것

- 공공 엑셀을 `read_excel(path)`만으로 읽는다 → `Unnamed` 컬럼
- 병합 셀을 `ffill` 없이 쓴다 → 절반이 NaN
- 키에 공백·이름 체계 차이가 있는데 `how="inner"`로 합친다 → **조용히 행이 사라진다**
- 합계 행을 빼지 않고 평균을 낸다 → 기준선이 망가진다
- 치우친 분포에서 평균을 기준으로 쓴다 → 중앙값을 쓴다
- 개수로 지역을 비교한다 → 인구 대비 밀도로
- 새 지표를 상관 확인 없이 추가한다 → 0.98이면 안 넣는 게 낫다
