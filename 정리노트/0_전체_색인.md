## 과목이 이어지는 흐름

```plain text
파이썬 기초
   |
   +-- 판다스·시각화 -- 머신러닝 ------------+
   |                                        |
   +-- 딥러닝(파이토치) --+-- 컴퓨터 비전     |
                          +-- 비전 트랜스포머 |
                          +-- 파이토치 NLP --+-- 코드 생성 LM
                                             |      |
                                             |      +-- RAG·생성형
                                             |
   +-- 웹 백엔드 -----------------------------+ (모델을 서비스로)
   |
   +-- 팀 프로젝트 (위의 것들을 합쳐서 쓴다)
   |
   +-- AutoCAD  (도구가 다름 — 도면)
   +-- PM 실무  (코드가 없음 — 일정·돈·문서)
```

**12·13번은 앞의 11과목과 성격이 다르다.** AutoCAD는 코드가 아닌 도면이고,
PM은 코드가 한 줄도 없다. 그래도 겹치는 곳이 있다 —
PM의 관리도 ±3σ는 머신러닝 3장의 이상치 판정이고,
사업계획서의 재현율·오검출률·표본 분리는 딥러닝 7장의 평가 지표다.

## 노트를 쓸 때 지키는 규칙

과목이 13개로 늘어나도 **같은 규칙으로 쓴다.**

| 규칙 | 이유 |
| --- | --- |
| **숫자는 실제 출력에서 가져온다** | 추정값을 쓰면 복습할 때 틀린 걸 외운다 |
| **실측과 계산값을 구분해 적는다** | 출력이 없으면 파일에서 직접 재거나 계산하고, 어느 쪽인지 표시 |
| **출력이 없는 노트북은 "결과"로 적지 않는다** | 안 돌린 셀의 숫자는 없는 숫자다 |
| **그림으로만 있는 값은 인용하지 않는다** | 렌더링된 그래프에서 눈대중으로 읽지 않는다 |
| **지난 라운드의 "미실행" 판정은 다시 확인한다** | 사이에 실행했을 수 있다 (실제로 두 번 틀렸다) |
| **교재 오류는 해당 장 노트에 적는다** | 별도 오류 문서를 만들지 않는다 |
| **절대 경로의 실명은 `<사용자>`로 바꾼다** | 저장소가 공개다 |
