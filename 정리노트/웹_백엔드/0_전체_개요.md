# 웹 백엔드 — 전체 개요

`17-KDT`의 웹 백엔드 실습 폴더 5개를 **한 과목**으로 묶어 정리한 것이다.
다른 과목과 달리 노트북(`.ipynb`)이 아니라 **실행 가능한 `.py` 프로젝트**라서, 장 번호를 파일명이 아니라 **배우는 순서**로 매겼다.

## 폴더 → 장 매핑

| 장 | 폴더 | 무엇을 배우나 |
| --- | --- | --- |
| 1. FastAPI 기초 | `17-fast-api` (10개 모듈) | 타입 힌트 · Pydantic · 라우팅 · HTTP 메서드 · 응답 클래스 · 예외 · Jinja2 |
| 2. 메모 앱 단계별 구축 | `17-todos/01_temp` ~ `05_foreign` | 템플릿 → DB → 로그인 → 프런트 → 소유권 |
| 3. MVC 리팩터링 | `17-todos/06_mvc` | 한 파일 앱을 6개 모듈로 분리 |
| 4. Flask로 만든 데이터 웹앱 | `17-apartment`, `17-assignment` | 공공 API · 크롤링 · 스케줄러 · CSV 다운로드 |
| 5. Docker와 배포 | `17-aws-docker` | Dockerfile · docker compose · nginx 리버스 프록시 |

## 이 과목의 성격

> **실행 결과가 파일로 남지 않는다.**
> 노트북 과목들은 셀 출력이 저장돼 있어 숫자를 그대로 확인할 수 있었지만, 웹 프로젝트는 서버를 띄워야 결과가 보인다.
> 그래서 이 정리는 **코드에 실제로 쓰여 있는 것**만 기술하고, "이렇게 하면 이런 응답이 온다"는 부분은 코드에서 확실히 읽히는 것만 적었다.

## 전체를 관통하는 흐름

```
17-fast-api          FastAPI 문법을 조각조각
      ↓
17-todos 01~05       그 조각들을 하나의 앱으로 (기능 추가 순서대로)
      ↓
17-todos 06_mvc      커진 앱을 구조로 정리
      ↓
17-apartment/assignment   Flask로도 같은 일을 (다른 프레임워크 비교)
      ↓
17-aws-docker        만든 것을 컨테이너에 담아 배포
```

## 프레임워크 두 개를 쓰는 이유

| | FastAPI | Flask |
| --- | --- | --- |
| 쓰인 곳 | `17-fast-api`, `17-todos`, `17-aws-docker` | `17-apartment`, `17-assignment` |
| 라우팅 | `@app.get('/path')` (메서드별 데코레이터) | `@app.route('/path')` (기본 GET) |
| 요청 검증 | Pydantic 모델로 **자동** | 직접 `request.args.get(...)` |
| 자동 문서 | `/docs` **있음** | 없음 |
| 비동기 | `async def` 네이티브 | 기본은 동기 |
| 템플릿 | `Jinja2Templates(directory=...)` 직접 등록 | `render_template` 기본 내장 |

**둘 다 Jinja2를 쓴다.** 템플릿 문법(`{{ }}`, `{% %}`)은 완전히 같다.

## 자주 쓰는 실행 명령

```bash
# FastAPI
uvicorn main:app --reload

# Flask
python app.py          # app.run(debug=True)

# Docker
docker compose up --build
```

## 이 과목에서 발견한 문제들

| 어디 | 무엇 |
| --- | --- |
| `17-fast-api/pydantic/main.py` | 경로가 `'items/'` — 슬래시(`/`)로 시작하지 않는다 |
| `17-fast-api/quiz/main.py` | `return {"..."}`는 딕셔너리가 아니라 **집합(set)** |
| `17-fast-api/routing/main.py` | 매개변수에 타입 힌트가 없어 전부 문자열로 들어온다 |
| `17-todos/03_login` | 로그인 실패 시 `return` 없이 함수가 끝나 `null`이 응답된다 |
| `17-todos/*` | `SessionMiddleware(secret_key="secret-key")` — 하드코딩된 고정 키 |
| `17-aws-docker/backend` | `Dockerfile`은 `python:3.13`, `pyproject.toml`은 `requires-python >=3.14` |
| `17-apartment/templates/index.html` | 따옴표가 깨진 `class` 속성 3곳 |

각 장의 **주의** 항목에서 자세히 다룬다. **원본 파일은 수정하지 않았다.**
