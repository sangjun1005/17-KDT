# AutoCAD 교육 — 전체 개요

`17-KDT/17-CAD` — **4일짜리 AutoCAD 과정.** 교재 PDF 4권(244쪽)과 과제 도면 3개, 템플릿 1개, LISP 3개.

> **2026-10-15 기준 — 1일차 때 지적한 것이 2일차에 거의 다 해결됐다**
> 1일차 도면은 레이어가 `0` 하나였고, 소수점이 쉼표로 찍혔고, 도면 한계가 A3였다.
> 2일차에 **A2 템플릿(`A2.dwt`)을 직접 만들면서 셋 다 고쳐졌다** — 레이어 8개, 마침표, A2.
> 3일차에는 그 레이어 작업을 **LISP으로 자동화**했다.
>
> 이 노트의 숫자는 전부 **도면 파일에서 직접 읽은 실측값**이다.
> `.dwg` 는 바이너리라 LibreDWG로 변환해 객체·치수·설정을 뽑았다.

## A2.dwt — 2일차에 만든 템플릿

**1일차 교재 CH01에서 "템플릿 파일(.dwt)에 저장해야 하는 설정"을 배웠고, 2일차에 실제로 만들었다.**

| 항목 | 값 (실측) |
| --- | --- |
| 도면 한계 | **594 × 420 (A2)** |
| 단위 / 정밀도 | 밀리미터 · 십진 · **소수 4자리** |
| 레이어 | **8개** — `0`(7) · 외형선(3) · 숨은선(2) · 중심선(1) · 가상선(6) · 보조선(1) · 윤곽선(4) · 구성선(8) |
| 선종류 | `Continuous` · `HIDDEN` · `HIDDEN2` · `CENTER2` · `PHANTOM2` |
| 문자 스타일 | `Standard`(`isocp.shx`) · `주석`(`arial.ttf`) · `굴림`(`Gulim.ttf`) |
| 치수 스타일 | **`ISO-25`** (문자 3.5 · 화살촉 3.5 · `DIMSCALE` 1.0 · 구분자 `.`) · `주석`(주석 축척) · `Standard` |
| 들어 있는 객체 | 선 **64** · 문자 **22** · 폴리선 2 = 윤곽선 + 표제란 + 부품란 |
| 누적 편집 시간 | 1시간 34분 |

**교재 CH09가 요구한 것이 그대로 들어 있다** — 윤곽선, 표제란, 부품란, 도면 한계, 단위, 도면층, 치수 스타일, 문자 스타일.

## 핵심 정리

- **AutoCAD는 무한 평면이므로 무조건 1:1(실제 치수)로 그린다.** 축척은 **출력할 때** 적용한다.
- **선 굵기는 작도할 때 넣지 않는다.** 색상으로 구분해 그리고, **출력 시 CTB가 색상→굵기로 바꾼다.**
- **그래서 레이어가 전부다.** 용도별 레이어 + 색 + 선종류를 정해 두면 나머지는 따라온다.
- **템플릿(.dwt)에 그 설정을 담아 두면 매번 다시 안 해도 된다.** 2일차의 `A2.dwt` 가 그것이다.
- **치수는 복합 객체다.** 분해(`X`)하면 연관성이 깨지고 스타일 제어가 안 된다. 분해하지 않는다.
- **치수 문자를 손으로 덮어쓰면 도형을 고쳐도 숫자가 안 바뀐다.**
- **반복 작업은 LISP으로 줄인다.** 레이어 전환을 숫자키 하나로 바꾼 것이 가장 체감이 크다.
