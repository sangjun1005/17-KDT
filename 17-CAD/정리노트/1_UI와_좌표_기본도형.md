## 1-1. 화면 구성과 기능키

**교재가 꼽은 화면 5요소.**

```plain text
① 풀다운(Drop Down) 메뉴
② 리본(Ribbon) 메뉴          - 탭 + 패널 + 패널 확장기 + 대화상자 실행기
③ 그래픽 창 (도면 영역)
④ 명령 윈도우 및 명령행 (Command Line)
⑤ 상태 막대 (Status Line)
```

**Enter 키의 두 가지 역할이 중요하다.**

| 동작 | 결과 |
| --- | --- |
| 명령 입력 완료 / 옵션 선택 완료 | **Space Bar 와 같다** |
| 아무것도 없는 상태에서 Enter | **직전에 쓴 명령을 다시 실행** |

**이것 하나로 속도가 달라진다.** 같은 명령을 반복할 때 다시 칠 필요가 없다.

### 기능키

| 키 | 기능 |
| --- | --- |
| **F3** | 객체 스냅 (`OSNAP`) |
| **F7** | 그리드 |
| **F8** | 직교 모드 |
| **F9** | 스냅 |
| F2 | 명령 이력 창 |

## 1-2. 새 도면과 템플릿(.dwt)

**AutoCAD는 다른 프로그램과 달리 "빈 파일"에서 시작하지 않는다.**
반드시 **템플릿 도면(원형 도면, `.dwt`)을 참조해서** 새 도면을 시작한다.

```plain text
템플릿(.dwt)  --참조-->  스크래치 도면(새 .dwg)
                         템플릿의 설정과 속성을 그대로 물려받는다
```

**교재가 꼽은 "템플릿에 저장해야 하는 설정" 10가지.**

| 항목 |
| --- |
| 도면 용지 시트 크기 — 도면 한계(`LIMITS`) |
| 단위 및 단위 형식, 정밀도 |
| **윤곽선 · 표제란 · 부품란 · 중심마크** |
| 선종류(`LINETYPE`)와 선가중치 |
| 치수 스타일 |
| 배치 뷰포트 및 축척 |
| **도면층(Layer) 작성 및 설정** |
| 문자 스타일 |
| 품번 · 다듬질 등 각종 기호 |
| 플롯 및 게시 설정 |

**이 목록이 2일차에 만든 `A2.dwt` 의 설계도가 된다.** 1일차에는 글로만 배우고, 2일차에 실제로 만든다.

| 명령 | 단축키 |
| --- | --- |
| 새 도면 | **`NEW`** |
| 열기 | `OPEN` |
| 옵션(기본 세팅) | `OPTION` — 십자선 크기, 배경색 |
| 특성 팔레트 | **`Ctrl` + `1`** |

**미터법 기본 도면 경계는 420 × 297 (A3) 이고 단위는 mm 다.**

## 1-3. 좌표 네 가지

**이 네 개가 1일차의 핵심이다.**

| 방식 | 입력 | 뜻 |
| --- | --- | --- |
| **절대좌표** | `100,50` | 원점(0,0)에서 X100 Y50 |
| **상대좌표** | `@200,0` | **직전 점**에서 X로 200 |
| **극좌표** | `100<45` | 원점에서 45° 방향으로 100 |
| **상대극좌표** | `@30<90` | **직전 점**에서 90° 방향으로 30 |

```plain text
@  = 상대좌표 구분자 — "직전 점(상대 원점)에서부터"
<  = 각도 구분자
```

**교재의 사각형 예제가 이것을 보여 준다.**

```plain text
절대좌표        상대좌표          상대극좌표
A (0,   0)      A (10, 10)        A (10, 10)   <- A만 절대좌표
B (200, 0)      B @200,0          B @30<0
C (200, 100)    C @0,100          C @30<90
D (0,   100)    D @-200,0         D @30<180
```

**원점에서 거리를 재는 것보다 직전 점에서 재는 쪽이 쉽고 빠르다** — 그래서 실무는 상대좌표를 쓴다.

## 1-4. LINE · ERASE · UNDO

| 명령 | 단축키 | 메모 |
| --- | --- | --- |
| `LINE` | **`L`** | 시작점 → 다음 점 반복. **`C`(닫기)** 로 시작점에 연결 |
| `ERASE` | **`E`** | 객체 선택 후 Enter. `Del` 키도 된다 |
| `UNDO` | **`U`** / `Ctrl`+`Z` | |
| `REDO` | `REDO` / `MREDO` | **명령 취소를 쓰지 않았으면 아이콘이 비활성** |

**교재의 정의가 정확하다** — 선(Line)은 **공간상 두 지점을 최단거리로 연결하는 형상**이고,
AutoCAD에서 **가장 중요한 기본 구성요소(Entity)** 다.

## 1-5. 도형 그리기 #1

| 명령 | 단축키 | 핵심 옵션 |
| --- | --- | --- |
| `RECTANG` | **`REC`** | 모따기(C) / 고도(E) / **모깎기(F)** / 두께(T) / 폭(W) · 영역(A) / 치수(D) / 회전(R) |
| `POLYGON` | **`POL`** | 면의 수 → 중심 → **원에 내접(I) / 원에 외접(C)** |
| `CIRCLE` | **`C`** | 중심-반지름(기본) · **`D`로 지름** · 2P · 3P · **Ttr(접선·접선·반지름)** · Ttt |
| `COPY` | **`CO`** | 변위(D) / 모드(O) — **단일(S) / 다중(M)** · **배열(A)** |
| `TRIM` | **`TR`** | 울타리(F) / 걸치기(C) / 프로젝트(P) / 모서리(E) / **지우기(R)** |

**`RECTANG` 은 닫힌 폴리선을 만든다** — 선 4개가 아니라 **객체 1개**다.

**`CIRCLE` 의 Ttr 이 실무에서 자주 쓰인다.** 두 객체에 접하면서 지정한 반지름을 갖는 원을 그린다.
1일차 과제의 마지막 예제가 바로 이것이다 — *"원의 접선 옵션을 이용하여, 반지름이 500인 원을 큰 사각형 안에 접하게 그리시오."*

**`TRIM` 의 `지우기(R)` 옵션을 기억해 둘 것.** 자르다가 필요 없는 객체가 보이면
**명령을 끝내지 않고 그 자리에서 지울 수 있다.**

## 1-6. 보조 도구 — GRID · SNAP · OSNAP

| 명령 | 단축키 | 기능 |
| --- | --- | --- |
| `GRID` | `GRID` | 모눈 표시. **도면 한계(`LIMITS`) 영역 위에만 표시되고 플롯되지 않는다** |
| `SNAP` | **`SN`** | 커서 이동을 지정 간격/각도로 **제한** |
| `OSNAP` | **`OS`** / **`F3`** | 기존 객체의 **정확한 점**(끝점·중간점·교차점·접점…)을 잡는다 |

**교재가 "그리드는 반드시 스냅과 병행해서 써야 한다"고 못 박는다.**
그리드만 켜면 눈금만 보일 뿐, 커서가 그 눈금에 붙지 않는다.

### 1일차 OSNAP 실습

교재의 SNAP 예제가 구체적이다.

```plain text
1. 모든 선은 LINE 명령으로만 그린다
2. 절대좌표로 가로세로 200 사각형을 그린다
3. 매번 필요한 스냅을 켜서 확인한다  ('OSNAP' 입력 -> 객체 스냅 설정창)
4. 가상 교차점 스냅으로 교차점에 선 긋기
5. 근처점 스냅으로 선 긋기
```

**"매번 필요한 스냅만 켠다"가 요령이다.** 전부 켜 두면 엉뚱한 점이 잡힌다.

## 1-7. 도형 그리기 #2

| 명령 | 단축키 | 메모 |
| --- | --- | --- |
| `ELLIPSE` | **`EL`** | 축 끝점 / **호(A)** / **중심(C)** |
| `ARC` | **`A`** | **작도법 8가지** |
| `PLINE` | **`PL`** | 선과 호 세그먼트를 **단일 객체**로 |

### 호(ARC) 8가지

| 방법 |
| --- |
| ① 시작점 - 두번째 점 - 끝점 (기본, 3점) |
| ② 시작점 - 중심점 - 끝점 |
| ③ 시작점 - 중심점 - 각도 |
| ④ 시작점 - 중심점 - 현의 길이 |
| ⑤ 시작점 - 끝점 - 각도 |
| ⑥ 시작점 - 끝점 - 방향 |
| ⑦ 시작점 - 끝점 - 반지름 |
| ⑧ 연속 — 직전 호/선의 끝점에 접하게 |

**호는 항상 시작점으로부터 반시계 방향으로 작성된다.** 방향이 반대로 나오면 **두 점의 지정 순서**를 바꾼다.

### PLINE 이 LINE 과 다른 점

```plain text
LINE  으로 사각형 -> 선 4개      (하나만 지워진다, 면적 조회 불가)
PLINE 으로 사각형 -> 객체 1개    (통째로 지워진다, 면적·길이 조회 가능)
```

교재가 꼽은 폴리선 용도 — **등압선·윤곽선, 배선 다이어그램, 공정/배관 다이어그램, 3D 돌출 경로, 절단선(Cutting Line).**

## 이 장 정리

### 한 줄 요약

**1일차는 "AutoCAD로 선을 정확히 긋는 법"이다.** 좌표 4종으로 위치를 정하고,
객체 스냅으로 기존 점을 잡고, 기본 도형 7개와 편집 2개(COPY·TRIM)를 익혔다.

### 외워 둘 단축키

```plain text
그리기   L 선   C 원   A 호   REC 사각형   POL 다각형   EL 타원   PL 폴리선
편집     E 지우기   CO 복사   TR 자르기   U 취소
보조     OS 객체스냅(F3)   SN 스냅(F9)   GRID 모눈(F7)   F8 직교
시작     NEW 새도면   OPTION 환경설정   Ctrl+1 특성팔레트
```

### 자주 틀리는 것

- 좌표 앞에 `@` 를 빠뜨린다 → 절대좌표로 들어가 엉뚱한 곳에 그려진다
- 객체 스냅을 다 켜 둔다 → 원하지 않는 점이 잡힌다. **필요한 것만 켠다**
- 그리드만 켜고 스냅을 안 켠다 → 눈금에 안 붙는다. **둘은 같이 쓴다**
- `LINE` 으로 그려 놓고 면적을 재려 한다 → `PLINE` 이어야 면적이 나온다
- 호가 반대 방향으로 나온다 → **반시계가 기본이다.** 점 지정 순서를 바꾼다
- 같은 명령을 다시 치려고 전부 입력한다 → **빈 상태에서 Enter** 면 직전 명령이 재실행된다
- 레이어를 안 나누고 `0` 에 다 그린다 → 2일차에서 바로 이것을 고친다
