## 5-1. `notepadd++.lsp` — 레이어를 숫자키로

**이 파일이 셋 중 제일 쓸모 있다.** 2일차에 손으로 만든 레이어 7개를 명령 하나로 만들고,
**숫자키 하나로 레이어를 바꾼다.**

### `LM` — 레이어 7개를 한 번에 만든다

```lisp
(defun c:lm ()
  (command "layer" "m" "중심선" "c" "1" "" "l" "center" ""
                   "m" "윤곽선" "c" "4" "" "l" "continuous" ""
                   "m" "외형선" "c" "3" "" "l" "continuous" ""
                   "m" "숨은선" "c" "2" "" "l" "hidden" ""
                   "m" "가상선" "c" "6" "" "l" "phantom" ""
                   "m" "구성선" "c" "8" "" "l" "continuous" ""
                   "m" "보조선" "c" "1" "" "l" "continuous" "" ""))
```

**`(command ...)` 는 명령행에 그대로 타이핑하는 것과 같다.**

```plain text
"layer"  LAYER 명령 실행
"m"      만들기(Make) - 레이어를 만들고 "현재 레이어로" 설정까지 한다
"중심선"  이름
"c" "1" ""   색상 1(빨강) 지정, 빈 문자열("")은 Enter
"l" "center" ""   선종류 center 지정
...
"" ""    마지막 두 개는 LAYER 명령 종료
```

**`""` 가 Enter 다.** LISP에서 명령 옵션을 넘길 때 Enter를 빈 문자열로 보낸다.
이게 LISP `command` 함수의 기본 문법이다.

### 레이어 체계 (2일차 템플릿과 일치)

| 숫자키 | 레이어 | 색 | 선종류 | 용도 |
| --- | --- | --- | --- | --- |
| **`1`** | **중심선** | 1 빨강 | `center` | 원·대칭의 중심 |
| **`2`** | **숨은선** | 2 노랑 | `hidden` | 안 보이는 모서리 |
| **`3`** | **외형선** | 3 초록 | continuous | 보이는 모서리 |
| **`4`** | **윤곽선** | 4 하늘 | continuous | 도면 테두리 |
| **`5`** | **보조선** | 1 빨강 | continuous | 작도 보조 |
| **`6`** | **가상선** | 6 자홍 | `phantom` | 가공 전 모양 등 |
| **`7`** | **`0`** | — | — | 기본 레이어 |
| **`8`** | **구성선** | 8 회색 | continuous | `XLINE`·`RAY` 보조선 |

**숫자키와 색 번호가 거의 일치하도록 맞춰 놨다** — `1`→색1, `2`→색2, `3`→색3, `4`→색4, `6`→색6, `8`→색8.
**예외는 `5`(보조선, 색 1)와 `7`(`0` 레이어)뿐이다.** 외우기 쉽게 설계한 것이다.

### `1`~`8` — 선택 객체를 옮기고 현재 레이어도 바꾼다

```lisp
(defun c:3 (/ ss)
  (setq ss (ssget))                              ; 객체 선택
  (if ss (command "chprop" ss "" "la" "외형선" ""))  ; 선택한 것을 외형선으로
  (setvar "clayer" "외형선")                       ; 현재 레이어도 외형선으로
  (princ))
```

**한 명령이 두 가지를 한다.**

```plain text
객체를 선택하고 3 -> 그 객체들이 외형선 레이어로 옮겨지고, 이후 그리는 것도 외형선
그냥 3 (선택 없이 Enter) -> 현재 레이어만 외형선으로 바뀐다
```

**이것이 2일차에 손으로 하던 작업을 키 하나로 줄인 것이다.**
`LA` 를 열어 레이어를 고르거나, 객체를 선택하고 리본 드롭다운에서 바꾸는 과정이 사라진다.

| 함수 | 하는 일 |
| --- | --- |
| `(ssget)` | **선택 세트**를 만든다 (사용자가 객체를 고른다) |
| `(command "chprop" ss "" "la" "외형선" "")` | `CHPROP` 으로 **도면층(LA) 변경** |
| `(setvar "clayer" "외형선")` | **현재 도면층** 시스템 변수를 바꾼다 |
| `(princ)` | **반환값을 안 찍고 조용히 끝낸다** |

**`(princ)` 로 끝내는 것이 관례다.** 안 쓰면 명령행에 `nil` 이 찍힌다.

### `C5` — 동심원 5개

```lisp
(defun c:C5 (/ a b c i)
  (setq a (getpoint "\n 중심점을 찍어주세요. : "))
  (setq b (getreal "\n 원의 지름을 입력하세요. : "))
  (setq c (/ b 2))          ; 반지름
  (setq i 1)
  (repeat 5
    (command "circle" a (* c i))
    (setq i (+ i 1)))
  (princ "원 5개가 생성되었습니다.")
  (princ))
```

**지름을 받아 반지름으로 바꾸고, 그 배수로 원 5개를 그린다.**

```plain text
지름 20 입력 -> 반지름 10
반지름 10, 20, 30, 40, 50 인 동심원 5개
```

| 함수 | 하는 일 |
| --- | --- |
| `(getpoint "...")` | 점을 **클릭**받는다 |
| `(getreal "...")` | **실수**를 입력받는다 |
| `(repeat 5 ...)` | 5번 반복 |

**주의 — 이름이 `C5` 라 `CIRCLE` 의 별칭 `C` 와 헷갈리기 쉽다.**
그리고 **개수 5가 코드에 박혀 있다.** `(getint)` 로 개수도 받으면 더 쓸모 있다.

## 5-2. `TLEN.lsp` — 선택한 객체의 길이 합계

```lisp
(defun c:TLEN (/ ss i ent lengthResult total count message)
  (prompt "\n전체 길이를 계산할 객체를 선택하세요: ")
  (setq ss (ssget '((0 . "LINE,ARC,LWPOLYLINE,POLYLINE,SPLINE,CIRCLE,ELLIPSE"))))
  ...)
```

**`(ssget '((0 . "LINE,ARC,...")))` 가 핵심이다** — **필터**를 걸어 그 타입만 선택되게 한다.
`0` 은 DXF 그룹 코드로 **객체 타입**을 뜻한다. 문자나 치수를 같이 긁어도 무시된다.

### 길이를 구하는 방법

```lisp
(vlax-curve-getDistAtParam obj (vlax-curve-getEndParam obj))
```

**"곡선의 끝 매개변수에서의 거리" = 전체 길이.**
선이든 호든 스플라인이든 **같은 함수 하나로** 길이가 나온다 — 이게 `vlax-curve-*` 계열의 장점이다.

| 함수 | 하는 일 |
| --- | --- |
| `(vl-load-com)` | **ActiveX 함수를 쓰기 전에 반드시 호출** |
| `vlax-curve-getEndParam` | 곡선의 끝 매개변수 |
| `vlax-curve-getDistAtParam` | 그 지점까지의 거리 |
| `(vl-catch-all-apply ...)` | **오류가 나도 죽지 않게** 감싼다 |
| `(vl-catch-all-error-p ...)` | 오류였는지 판정 |

**`vl-catch-all-apply` 로 감싼 것이 좋은 습관이다.**
길이를 못 구하는 객체가 하나 섞여도 **전체가 중단되지 않고** 그것만 건너뛴다.

```lisp
(rtos total 2 2)   ; 실수를 문자열로. 2=십진, 2=소수점 2자리
```

**결과는 `alert` 대화상자와 명령행에 둘 다 출력한다** — 좋은 설계다.
대화상자는 눈에 띄고, 명령행 기록은 `F2` 로 다시 볼 수 있다.

## 5-3. `MS.lsp` — 질량 계산 (DCL 대화상자)

**셋 중 가장 복잡하다. 대화상자(DCL)를 런타임에 만들어 띄운다.**

### 구조

```plain text
① mass2d-create-dcl : DCL 파일을 임시 폴더에 "써서" 만든다
② c:MS : 객체 선택 -> 대화상자 띄움 -> 두께/밀도 입력 -> 면적 합계 -> 질량 계산
```

```lisp
(setq dclFile (vl-filename-mktemp "mass2d" nil ".dcl"))
(setq fp (open dclFile "w"))
(foreach line '("mass2d : dialog {" ...) (write-line line fp))
(close fp)
```

**DCL 파일을 따로 배포하지 않아도 되게 만든 것이 영리하다.**
`.lsp` 하나만 있으면 돌아간다. 쓰고 나면 `(vl-file-delete dclFile)` 로 지운다.

### 계산식

```plain text
부피 = 전체 면적(mm²) × 두께(mm)              -> mm³
질량 = 부피(mm³) / 1000 × 밀도(g/cm³)         -> g
```

**`/ 1000` 이 단위 변환이다** — `1 cm³ = 1000 mm³` 이므로 mm³를 cm³로 바꾼다.

| 기본값 | 값 | 의미 |
| --- | --- | --- |
| 두께 | **1.0 mm** | |
| 밀도 | **7.85 g/cm³** | **강철(steel)** |

**7.85는 일반 탄소강의 밀도다.** 기계 도면 기본값으로 적절하다.
(알루미늄 2.7 · 황동 8.5 · 스테인리스 7.9 정도)

### 닫힌 객체만 계산한다

```lisp
(setq closedOk
  (or (not (vlax-property-available-p obj 'Closed))
      (= (vla-get-Closed obj) :vlax-true)))
```

**열린 폴리선은 면적이 의미가 없으므로 건너뛴다.**
`Closed` 속성이 아예 없는 객체(원 등)는 통과시킨다 — **논리가 정확하다.**

**건너뛴 개수(`skipped`)를 따로 세어 알려 주는 것도 좋다.**
"계산 객체 수 / 전체 면적 / 두께 / 밀도 / 질량"을 한 번에 보여 준다.

### 입력 검증

```lisp
(if (and (> (atof (get_tile "thickness")) 0.0)
         (> (atof (get_tile "density")) 0.0))
    (progn ... (done_dialog 1))
    (set_tile "error" "0보다 큰 숫자를 입력하세요."))
```

**0 이하를 막고 대화상자 안에 오류 메시지를 띄운다** — 대화상자를 닫지 않고 다시 입력받는다.

### 교재와의 연결

**3일차 CH07의 `MASSPROP` 명령이 이것의 원형이다.**
교재는 *"`PLINE` 으로 모형을 그리고 `REGION` 으로 Region 객체로 만든 뒤 질량 특성을 계산"* 하라고 한다.
`MS.lsp` 는 **`REGION` 변환 없이 닫힌 2D 객체의 면적만으로** 질량을 내므로 더 간편하지만,
**두께가 일정한 판재에만 맞는다.**

## 5-4. 불러오는 법과 주의점

### 불러오기

| 방법 | 설명 |
| --- | --- |
| `APPLOAD` | 대화상자에서 `.lsp` 선택 |
| **시작 세트(Startup Suite)** | `APPLOAD` 안에서 등록하면 **AutoCAD 켤 때 자동 로드** |
| `(load "경로/파일.lsp")` | 명령행에서 직접 |

**매번 불러오기 귀찮으면 시작 세트에 넣는다.**

### 주의할 점

| 항목 | 내용 |
| --- | --- |
| **인코딩** | 세 파일 모두 **CP949**. UTF-8로 열면 한글이 깨진다 |
| **명령 이름 충돌** | `c:1`~`c:8` 은 **숫자만 입력해도 실행된다.** 좌표 입력과 헷갈릴 수 있다 |
| `C5` vs `C` | `C` 는 `CIRCLE` 별칭. **한 글자 차이** |
| **레이어 이름 의존** | `LM` 으로 만든 레이어 **이름이 정확히 일치**해야 `1`~`8` 이 동작한다. 다른 템플릿에서는 실패 |
| 선종류 로드 | `LM` 은 `center`·`hidden`·`phantom` 을 지정하는데, **템플릿에는 `CENTER2`·`HIDDEN2`·`PHANTOM2`** (반 간격판)가 들어 있다 — 어느 쪽이 적용되는지 **확인 필요** |
| 파일 이름 | **`notepadd++.lsp`** 는 `d` 가 하나 많다(Notepad++). 기능과도 무관한 이름 |

## 이 장 정리

### 한 줄 요약

**반복되는 조작은 `(command ...)` 로 묶어 한 글자 명령으로 만든다.**
레이어 전환을 숫자키 하나로 줄인 것이 가장 체감이 크고,
길이 합계·질량 계산은 AutoCAD가 기본 제공하지 않는 "합계"를 만들어 쓴 것이다.

### 외워 둘 LISP 기본

```lisp
(defun c:이름 (/ 지역변수)  ... (princ))   ; c: 를 붙이면 명령이 된다
(command "명령" 인자 "" ...)               ; "" 가 Enter
(setq a (getpoint "메시지"))               ; 점 입력
(setq b (getreal "메시지"))                ; 실수 입력
(setq ss (ssget))                          ; 객체 선택
(setq ss (ssget '((0 . "LINE,ARC"))))      ; 타입 필터
(setvar "clayer" "외형선")                  ; 시스템 변수 설정
(repeat N ...)                             ; N번 반복
(vl-load-com)                              ; ActiveX 쓰기 전 필수
(vl-catch-all-apply '함수 (list 인자))      ; 오류 방어
(rtos 값 2 2)                              ; 실수 -> 문자열 (십진, 소수 2자리)
(alert "메시지")                            ; 대화상자
(princ)                                    ; nil 안 찍고 종료
```

### 자주 틀리는 것

- `(princ)` 없이 끝낸다 → 명령행에 `nil` 이 찍힌다
- `(command ...)` 에서 Enter를 빠뜨린다 → **옵션이 밀려서 엉뚱하게 동작한다**
- `vl-load-com` 없이 `vlax-*` 를 쓴다 → 함수가 없다는 오류
- 오류 방어 없이 전체를 돌린다 → **객체 하나 때문에 전부 중단**된다
- 레이어 이름을 하드코딩하고 다른 템플릿에서 쓴다 → **조용히 실패**한다
- 기존 명령과 같은 이름을 쓴다 → 원래 명령을 덮어쓴다
- UTF-8로 저장한다 → **한글 프롬프트가 깨진다** (이 파일들은 CP949)
