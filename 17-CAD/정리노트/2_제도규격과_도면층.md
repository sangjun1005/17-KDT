## 2-1. 도면 양식 — 윤곽선·표제란·부품란

**기계제도는 `KS B 0001`, 도면 크기와 양식은 `KS A 0106` 을 따른다.**

| 요소 | 규격 | 역할 |
| --- | --- | --- |
| **윤곽선**(Borderline) | **0.5mm 실선** | 기재 영역을 명확히 하고, 가장자리 손상으로부터 내용을 보호 |
| **중심마크**(Center mark) | **0.5mm 실선** | 도면 복사·마이크로필름 제작 시 기준선 |
| **표제란**(Title block) | 규정 없음 | **오른쪽 하단 윤곽선 안쪽.** 도면번호·도명·척도·각법·설계자·작성일 |
| **부품란**(BOM) | 규정 없음 | 품번·품명·재질·수량. 표제란 위 또는 오른쪽 상단 |

**표제란·부품란은 형식 규정이 없지만** "도면을 보는 사람이 모든 제도 정보를 파악할 수 있어야" 한다.

## 2-2. 용지 크기와 척도

**`KS A 0206` / `KS A 5201` — A0~A4.**

| 용지 | 크기 (mm) |
| --- | --- |
| **A0** | **1189 × 841** (면적 약 1m²) |
| A1 | 841 × 594 |
| **A2** | **594 × 420** |
| A3 | 420 × 297 |
| A4 | 297 × 210 |

**가로:세로 = 1 : 1.4 (√2).** 반으로 접으면 다음 크기가 된다.

### 척도 (`KS A 0110`)

| 종류 | 의미 | 기준 배율 |
| --- | --- | --- |
| **축척** | 실물보다 작게 | 1:2 · 1:5 · 1:10 · 1:20 · 1:50 · 1:100 · 1:200 |
| **현척** | 실물과 같게 | **1:1 (원칙)** |
| **배척** | 실물보다 크게 | 2:1 · 5:1 · 10:1 · 20:1 · 50:1 |

**"되도록 1:1을 사용하는 것을 원칙"으로 하고, 정해진 배율만 쓴다.**
작도 후 **표제란의 척도란에 기입**하고, 같은 도면 안에서 다른 척도를 쓰면 그 옆에 따로 적는다.

## 2-3. 투상법 — 제3각법

**광원·물체·평면을 놓고 그림자로 입체를 평면에 옮기는 것이 투상법이다.**

```plain text
광원 --투상선--> 물체 --> 투상면 --> 투상도
```

| 종류 | 특징 | 쓰는 곳 |
| --- | --- | --- |
| **투시투상법** | 멀수록 짧게 그려진다. **원근감** | 건축 투시도. **제작 도면에는 단점** |
| **정투상법** | 좌표면이 투상면에 평행인 **직각 투상** | **기계제도 (KS B 0001)** |
| 사투상법 | — | 카탈로그 설명도 |

### 제1각법 vs 제3각법

```plain text
유리 상자에 물체를 넣고 6면(A~F)에 투상한 뒤 전개한다.

제1각법 : 상자를 "밀어서" 펼친다  -> 평면도가 정면도 아래, 좌측면도가 오른쪽
제3각법 : 상자를 "당겨서" 펼친다  -> 완전히 반대. 물체를 전개한 상태로 배치
```

**`KS B 0001` 은 원칙적으로 제3각법을 쓰도록 규정한다.**
제1각법은 물건이 길면 정면도와 측면도를 대조하기 불편하지만, **제3각법은 대조에 편리**하다.

| 투상면 | 투상도 |
| --- | --- |
| 입화면(앞) | 정면도 |
| 평화면(위) | 평면도 |
| 측화면(오른쪽) | 우측면도 |
| 입화면(뒤) | 배면도 |
| 평화면(아래) | 저면도 |
| 측화면(왼쪽) | 좌측면도 |

**실용상은 정면도 · 평면도 · 좌(우)측면도 세 개를 많이 쓴다.**

## 2-4. 선 9종과 우선순위

**선 굵기 비율은 가는선 : 굵은선 : 아주굵은선 = 1 : 2 : 4.**

`KS B 0001` 이 정한 9개 기준값에서 도면 크기에 맞게 고른다.

```plain text
0.13 · 0.18 · 0.25 · 0.35 · 0.5 · 0.7 · 1.0 · 1.4 · 2.0 (mm)
```

선 종류는 **실선 · 파선 · 1점쇄선 · 2점쇄선**.

### 선의 우선순위

**두 종류 이상의 선이 같은 자리에 겹치면 우선순위가 높은 선으로 긋는다.**
이 규칙이 있어야 도면이 사람마다 달라지지 않는다.

## 2-5. AutoCAD 작도 2원칙

**교재가 따로 한 절을 할애한 부분이고, 이 과정 전체에서 가장 중요한 두 줄이다.**

> ① **AutoCAD는 무한 평면이므로 축척에 상관없이 무조건 1:1(실제 치수)로 작도한다.**
>
> ② **모든 선종류는 작도 시에 적용하지만, 선 굵기(선가중치)는 적용하지 않는다.**
>    기본값(0.25mm)으로 그리고, **최종 출력에서 색상으로 구분해 굵기를 적용한다. → 도면층 이용**

```plain text
작도할 때        출력할 때
형상  1:1        축척 적용 (PLOT)
선종류 지정      그대로
굵기  기본값 --> 색상 -> CTB가 굵기로 변환 (4일차)
```

**"왜 레이어를 나누는가"의 답이 여기 있다.** 색이 보기 좋으라고 나누는 게 아니라
**출력에서 선 굵기를 결정하기 때문**이다.

## 2-6. 도면 설정 — UNITS · LIMITS · MVSETUP

| 명령 | 단축키 | 하는 일 |
| --- | --- | --- |
| `UNITS` | **`UNITS`** | 길이·각도 단위 유형과 **정밀도** |
| `LIMITS` | **`LIMITS`** | 도면 한계 |
| `MVSETUP` | `MVSETUP` | 단위·축척·용지 크기를 묻고 **도면 한계에 경계(Border)를 그려 준다** |

**기계 도면 시트는 단위 mm, 정밀도(유효 소수 자리)를 반드시 설정한다.**

### 도면 한계 = 용지 크기 × 축척의 역수

```plain text
1:1 로 A2 출력  ->  594, 420
1:2 로 A2 출력  ->  594 x 2, 420 x 2 = 1188, 840
```

**역수를 곱하는 이유** — 1:2로 줄여 출력할 거면 실물은 두 배 크게 그려 둬야 용지에 맞는다.

| 용지 | LIMITS 입력값 (1:1) |
| --- | --- |
| A4 | `297, 210` |
| A3 | `420, 297` |
| **A2** | **`594, 420`** |
| A1 | `841, 594` |

`LIMITS` 의 켜기(ON)/끄기(OFF) — **켜면 도면 한계 밖에 객체를 만들 수 없다** (`LIMCHECK` 변수).

도면 한계가 하는 일 네 가지: **모눈 표시 범위 · 작도 가능 영역 제한 · Zoom All 표시 영역 · 플롯 영역 옵션.**

## 2-7. 도면층(Layer)

**교재의 비유가 좋다** — 여러 장의 투명 필름에 각각 그리고 겹쳐 보면 한 장처럼 보인다.
그 **낱장 필름**이 도면층이다. 3번 필름을 빼면(OFF) 1·2번 내용만 보인다.

| 명령 | 단축키 |
| --- | --- |
| 도면층 특성 관리자 | **`LA`** |

### 도면층 상태 네 가지

| 상태 | 보이나 | 선택되나 | 재생성 |
| --- | --- | --- | --- |
| **켜기(ON)** | O | O | O |
| **끄기(OFF)** | **X** | — | **O (계속 재생성한다)** |
| **동결(Freeze)** | **X** | — | **X (재생성에서 제외)** |
| **잠금(Lock)** | O | **X** | O |

**끄기와 동결의 차이가 시험에 나온다.**
끄기는 안 보이지만 **계속 재생성**되고, 동결은 **재생성에서 빠져 속도가 빨라진다.**
복잡한 도면에서는 동결을 쓴다.

**잠금은 "보이되 못 건드리게"** 하는 것이다 — 배경 도면을 깔아 놓고 그 위에 그릴 때 쓴다.

### 도면층을 쓰면 좋은 점 (교재)

- 도면과 객체 관리가 쉽다
- 복잡한 도면에서 **일시적으로 숨겼다 다시 표시**할 수 있다
- **잠금**으로 선택 불가하게 하면 편집이 빠르고 안전하다
- **객체의 선가중치와 색상에 따라 최종 인쇄**할 수 있다 ← 2-5의 그 이유
- 외부 참조한 도면의 잠긴 도면층은 수정 불가라 **동시 공동 작업**이 가능하다

### 만드는 순서

```plain text
LA -> 새 도면층 아이콘 -> 이름 입력
   -> 색상 열 클릭 -> 색상 선택 (255색)
   -> 선종류 열 클릭 -> [로드] -> 선종류 선택
   -> 더블클릭 또는 [현재로 설정]
```

**이름은 한글도 되지만 교재는 영문을 권장한다.** 이름을 안 바꾸면 `도면층1`·`도면층2`로 자동 지정된다.

**삭제되지 않는 도면층이 있다** — `0`, `Defpoints`, 현재 도면층, 객체가 들어 있는 도면층, 외부 참조 도면층.

## 2-8. 엔티티 특성 — ByLayer · ByBlock

| 설정 | 뜻 |
| --- | --- |
| **ByLayer** | **도면층에 지정된 속성을 따른다.** `Layer0`에 빨강이 지정되고 선이 ByLayer면 선은 빨강 |
| **ByBlock** | 블록 생성 시 객체를 ByBlock으로 정의해 두면, **삽입한 뒤에도 속성을 바꿀 수 있다** |
| 직접 지정 | **도면층 설정을 재지정한다.** `Layer0`이 빨강이어도 선에 파랑을 주면 파랑 |

**원칙은 "전부 ByLayer"다.** 그래야 레이어 하나만 고치면 전부 따라온다.
객체에 색을 직접 주기 시작하면 **레이어가 무력해진다.**

| 명령 | 단축키 | 하는 일 |
| --- | --- | --- |
| `PROPERTIES` | **`Ctrl`+`1`** | 특성 팔레트 |
| `MATCHPROP` | **`MA`** | **특성 일치** — 한 객체의 특성을 다른 객체에 복사 (스포이드) |
| `CHANGE` / `CHPROP` | — | 색상(C)/도면층(LA)/선종류(LT)/선종류축척(S)/선가중치(LW) 변경 |
| `SETBYLAYER` | — | 지정 특성을 **ByLayer로 되돌린다** |

**`MA`(특성 일치)가 실무에서 제일 많이 쓰인다.** 레이어를 잘못 지정한 객체를
올바른 객체 하나 찍고 쓸어 주면 끝난다.

## 2-9. 문자와 해치

### 문자 — 먼저 스타일을 정의한다

| 명령 | 단축키 | 메모 |
| --- | --- | --- |
| `STYLE` | **`ST`** | **문자 스타일 정의. 이것부터 한다** |
| `TEXT` (단일행) | **`DT`** | 각 행이 **독립 객체**. 레이블에 편리 |
| `MTEXT` (여러줄) | **`MT`** | 단락 전체가 **단일 객체**. 밑줄·글꼴·색을 부분 적용 가능 |
| 편집 | `DDEDIT` / `MTEDIT` | 단일행 / 여러줄 |

**도면 문자는 `KS A 0107` 을 기준으로 한다.**

**트루타입 글꼴을 많이 쓰면 도면 파일이 커지고 느려진다** — 그래서 AutoCAD는
`*.shx` 벡터 폰트를 쓴다. (이 과정의 템플릿도 `Standard` 는 `isocp.shx` 다.)

### 해치 — 단면 표시

| 명령 | 단축키 |
| --- | --- |
| `HATCH` / `BHATCH` | **`H`** |

**단면에 해치할 때의 규칙 (교재).**

- 해칭선은 **가는 실선**
- 각도는 **45°를 원칙**으로
- **같은 간격**으로, 단면 크기에 따라 간격 조절
- **같은 부품의 단면은 같은 방법**으로
- **서로 다른 부품이 인접하면 각도를 반대로 하거나 간격을 다르게**
- 해치 부분에 문자·기호를 넣을 때는 **그 부분의 해칭선을 자른다**

**해치 축척과 출력 축척의 관계.**

```plain text
2:1 -> 0.5        1:1 -> 1.0        1:2 -> 2.0
```

**`연관(Associative)` 옵션을 켜 두면 경계를 고칠 때 해치가 따라온다.**

### 외워 둘 것

```plain text
LA    도면층 특성 관리자      <- 2일차의 주인공
MA    특성 일치 (스포이드)
ST    문자 스타일   DT 단일행   MT 여러줄
H     해치
UNITS 단위        LIMITS 도면 한계      MVSETUP 경계 그리기

도면 한계 = 용지 크기 x 축척의 역수
작도는 1:1, 굵기는 색으로, 축척은 출력에서
```

### 자주 틀리는 것

- 축척을 적용해서 그린다 → **무조건 1:1로 그린다.** 축척은 출력에서
- 선 굵기를 작도하면서 준다 → **색으로 구분**하고 CTB가 굵기로 바꾼다
- 객체에 색을 직접 지정한다 → **ByLayer가 무력해진다**
- 끄기와 동결을 같은 것으로 안다 → **끄기는 재생성되고 동결은 안 된다**
- `Defpoints` 를 지우려 한다 → 치수가 만든 레이어다. **출력 안 되니 그냥 둔다**
- 문자 스타일을 정의하지 않고 문자부터 넣는다 → 나중에 전부 다시 잡아야 한다
- 해치 각도를 부품마다 같게 준다 → **인접 부품은 각도를 반대로**
- 도면 한계를 안 잡고 그린다 → 출력할 때 배치가 안 맞는다
