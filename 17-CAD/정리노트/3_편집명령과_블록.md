## 3-1. 곡선·선형 객체

| 명령 | 단축키 | 메모 |
| --- | --- | --- |
| `SPLINE` | **`SPL`** | 맞춤점(F) 또는 조정정점(CV). 비행기 날개·터빈 블레이드 단면 같은 형상 |
| `DONUT` | **`DO`** | 내부지름 + 외부지름. **내부지름 0 = 꽉 찬 원** |
| `FILL` | `FILL` | 채워진 객체(해치·2D솔리드·굵은 폴리선) 표시 On/Off |
| **`XLINE`** (구성선) | **`XL`** | **무한 길이 보조선** |
| **`RAY`** (광선) | `RAY` | **한쪽만 무한.** 시작점 + 통과점 |
| `MLSTYLE` / `MLINE` | `MLINE` | 여러 줄(평행선). **아파트 평면도 벽체**에 편리 |
| `MLEDIT` | `MLEDIT` | 여러 줄의 교차점·중단점·정점 편집 |

### XLINE 이 핵심이다

**구성선은 삼각법(제3각법)으로 여러 뷰를 배치할 때 기준선이 된다.**

| 옵션 | 기능 |
| --- | --- |
| **수평(H)** | X축에 평행한 무한선 |
| **수직(V)** | Y축에 평행한 무한선 |
| 각도(A) | 지정 각도 |
| **이등분(B)** | 두 선 사이의 각을 **이등분** |
| 간격띄우기(O) | 참조 객체에 평행 |

**정면도에서 수평 구성선을 뽑아 우측면도의 높이를 맞추는 식**으로 쓴다.
2일차 과제에 이미 `XLINE` 14개, `RAY` 24개가 들어 있다 — 뷰 정렬에 썼다.

**다 그리고 나면 구성선 레이어를 꺼 버린다.** 그래서 `구성선` 레이어가 따로 있는 것이다.

## 3-2. 객체 선택 — 선택 세트

**교재가 선택 옵션을 전부 나열한다. 실제로 쓰는 것은 다섯 개 정도다.**

| 옵션 | 입력 | 동작 |
| --- | --- | --- |
| **윈도우(W)** | 왼쪽 → 오른쪽 | **완전히 들어온 것만** 선택 |
| **걸치기(C)** | 오른쪽 → 왼쪽 | **걸치기만 해도** 선택 (점선 표시) |
| 상자(BOX) | — | 방향에 따라 W 또는 C 로 동작 |
| **모두(ALL)** | `ALL` | 동결·잠긴 도면층 **제외** 전부 |
| **울타리(F)** | `F` | 선을 그어 **교차하는 것 전부** |
| 윈도우다각형(WP) | `WP` | 다각형 안에 완전히 들어온 것 |
| 걸침다각형(CP) | `CP` | 다각형에 걸친 것 |
| 이전(P) | `P` | 직전 선택 세트 |
| 최종(L) | `L` | 가장 최근에 만든 객체 |

```plain text
왼쪽 -> 오른쪽  (실선 사각형)  = 윈도우. 완전히 포함
오른쪽 -> 왼쪽  (점선 사각형)  = 걸치기. 스치기만 해도
```

**선택 해제는 `Shift` + 클릭이다.** 다만 **키보드 입력을 요구하는 옵션들은 Shift로 해제가 안 된다.**

**`ALL` 은 끄기(OFF)된 도면층의 객체도 선택한다** — 동결·잠금만 제외된다. 이게 함정이다.
안 보이는 객체가 같이 지워질 수 있다. **안 건드릴 레이어는 끄기가 아니라 동결·잠금으로.**

## 3-3. 그립 편집

**명령을 실행하지 않은 상태에서 객체를 선택하면 파란 사각점(그립)이 나타난다.**
그립을 클릭하면 활성화되고, **신축·이동·회전·축척·대칭**을 명령 없이 할 수 있다.

```plain text
객체 선택 -> 기준 그립 클릭 -> Space Bar 로 모드 순환 -> 드래그
```

| 설정 (`DDGRIPS` / 옵션-선택 탭) | 메모 |
| --- | --- |
| 그립 표시 | **도면에 그립을 많이 표시하면 성능이 현저히 떨어진다** |
| 그립 표시할 객체 선택 한계 | 기본 **100개**. 이보다 많이 선택하면 그립을 안 띄운다 |

## 3-4. 간격띄우기·연장·끊기·모깎기·모따기

| 명령 | 단축키 | 메모 |
| --- | --- | --- |
| **`OFFSET`** | **`O`** | **가장 빈번하게 쓰는 명령**(교재 표현). 평행 사본 |
| `EXTEND` | **`EX`** | 경계까지 늘리기 |
| `BREAK` | **`BR`** | 두 점 사이를 끊는다 |
| `FILLET` | **`F`** | 모깎기(라운드) |
| `CHAMFER` | **`CHA`** | 모따기 |
| `TRIM` | **`TR`** | 자르기 |

### OFFSET 의 옵션 세 개를 기억할 것

| 옵션 | 기능 |
| --- | --- |
| **통과점(T)** | 거리 대신 **지나갈 점**을 찍는다 |
| **지우기(E)** | 간격띄우기 후 **원본을 지운다** |
| **도면층(L)** | 사본을 **현재 도면층**에 만들지, **원본 도면층**에 만들지 |

**`도면층(L)` 옵션이 중요하다.** 기본은 원본 도면층을 따라간다 —
중심선을 offset 하면 사본도 중심선 레이어가 된다. 외형선을 만들 생각이었다면 바꿔야 한다.

### FILLET 반지름 0

```plain text
FILLET 반지름 > 0  ->  둥근 모서리
FILLET 반지름 = 0  ->  두 선을 직각으로 맞물린다 (연장 + 자르기를 한 번에)
Shift 누르고 선택  ->  현재 반지름을 무시하고 0 으로 적용
```

**`Shift` 트릭이 실전에서 제일 많이 쓰인다.** 반지름을 바꾸지 않고 그때만 뾰족하게 만든다.

**FILLET 은 원을 자르지 않는다** — 호가 원에 부드럽게 일치한다.

### TRIM 의 두 모드 (최신 버전)

| 모드 | 동작 |
| --- | --- |
| **빠른 작업** | **모든 객체가 자동으로 절단 모서리.** 자를 것만 고르면 된다 |
| **표준** | 먼저 경계를 선택 → Enter → 자를 객체 선택 |

**빠른 작업 모드에서는 자를 수 없는 객체를 선택하면 그냥 삭제된다.** 주의.

**`TRIM` 중 `Shift` 를 누르면 `EXTEND` 가 된다.** 반대도 같다.

## 3-5. 이동·대칭·회전·축척

| 명령 | 단축키 | 핵심 옵션 |
| --- | --- | --- |
| `MOVE` | **`M`** | 변위(D) |
| `MIRROR` | **`MI`** | **예(Y)=원본 삭제 / 아니오(N)=원본 유지** |
| `ROTATE` | **`RO`** | **복사(C)** / 참조(R) |
| `SCALE` | **`SC`** | **복사(C)** / 참조(R) |

**`MIRROR` 가 기계 도면의 핵심이다.** 교재 표현대로 *"대부분 기계 부품들은 좌우상하 대칭 형상"*이므로
**절반만 그리고 대칭**한다. 작업량이 반으로 준다.

**`ROTATE`·`SCALE` 의 `복사(C)` 옵션** — 원본을 두고 회전/축척된 사본을 만든다.
이걸 모르면 복사하고 회전하는 두 단계를 밟게 된다.

**`SCALE` 의 `참조(R)`** — 축척 비율을 모를 때 쓴다. *"지금 이 길이를 저 길이로 맞춰라"*.

```plain text
축척 비율 > 1  -> 확대
0 < 비율 < 1   -> 축소
```

## 3-6. 배열 세 가지

| 명령 | 단축키 | 용도 |
| --- | --- | --- |
| 직사각형 배열 | **`ARRAY`** / `ARRAYRECT` | 행 × 열 |
| **원형 배열** | **`ARRAYPOLAR`** | 중심점 기준 원형 분산 |
| 경로 배열 | `ARRAYPATH` | 선·호·폴리선·스플라인 경로를 따라 |
| 배열 편집 | `ARRAYEDIT` | 연관 배열 수정 |

**원형 배열이 기계 도면에서 제일 많이 쓰인다** — 볼트 구멍, 플랜지 구멍.

| 원형 배열 옵션 | 기능 |
| --- | --- |
| **항목(I)** | 개수 |
| **사이의 각도(A)** | 항목 간 각도 |
| 채울 각도 | 첫 항목과 마지막 항목 사이 각도 |
| **항목 회전(ROT)** | 배열될 때 항목도 같이 회전할지 |

**`연관(AS)` 을 켜면 배열 전체가 하나의 객체**가 되어 나중에 `ARRAYEDIT` 로 개수를 바꿀 수 있다.
끄면 그냥 복사본들이 된다.

## 3-7. 결합·길이조정·신축·분해

| 명령 | 단축키 | 메모 |
| --- | --- | --- |
| `JOIN` | **`J`** | 두 객체를 하나로 |
| `LENGTHEN` | — | 증분(DE) / 퍼센트(P) / 합계(T) / **동적(DY)** |
| `STRETCH` | **`STR`** | **걸침 선택으로만** 동작 |
| `EXPLODE` | **`X`** | 블록·폴리선·영역 분해 |

### JOIN 의 조건

| 원본 | 결합 조건 |
| --- | --- |
| 선 | **동일 선상**(간격은 있어도 됨) |
| 호 | **반지름과 중심점이 같아야** 한다. 반시계 방향으로 결합 |
| 폴리선 | 선·폴리선·호. **연속 + 동일 평면** |

### STRETCH 의 규칙

```plain text
걸침 윈도우에 "부분적으로" 걸린 객체   -> 신축된다
완전히 둘러싸이거나 개별 선택된 객체    -> 신축 안 되고 "이동"된다
원, 타원, 블록                        -> 신축 불가
```

**이 세 줄이 STRETCH 의 전부다.** 늘리고 싶은 쪽만 걸치도록 **오른쪽에서 왼쪽으로** 선택한다.

**연관 치수(`DIMASSOC=2`)가 켜져 있으면 STRETCH 할 때 치수 숫자가 따라 바뀐다.**

## 3-8. 분할과 조회 명령

| 명령 | 단축키 | 하는 일 |
| --- | --- | --- |
| `DIVIDE` | **`DIV`** | **등분할** — 객체를 N등분한 자리에 점/블록 배치 |
| `MEASURE` | **`ME`** | **길이분할** — 지정 간격마다 점/블록 배치 |
| `POINT` / `DDPTYPE` | **`PO`** / `DDPTYPE` | 점 / **점 스타일** |
| `DIST` | **`DI`** | 두 점 사이 거리와 각도 |
| `AREA` | — | 면적과 둘레 |
| `MASSPROP` | `MASSPROP` | **영역/질량 특성** |
| `LIST` | **`LI`** | 선택 객체의 특성 데이터 |
| `ID` | `ID` | 위치의 절대 좌표 |

**`DIVIDE`·`MEASURE` 는 점을 찍는 것이지 객체를 자르는 게 아니다.**
점이 안 보이면 `DDPTYPE` 으로 **점 스타일을 바꿔야** 한다 (기본은 한 픽셀이라 안 보인다).

**`MASSPROP` 을 쓰려면 먼저 `REGION`(영역) 객체로 만들어야 한다** —
`PLINE` 으로 닫힌 모형을 그리고 `REGION` 으로 변환한 뒤에 질량 특성을 계산한다.
(3일차에 만든 `MS.lsp` 가 이것을 대화상자로 감싼 도구다. 5번 노트 참조)

## 3-9. 블록

**반복해서 쓰는 도형에 이름을 붙여 저장해 두고 불러 쓴다.**

| 구분 | 내부 블록 | 외부 블록 |
| --- | --- | --- |
| 정의 명령 | **`BLOCK`** (**`B`**) | **`WBLOCK`** |
| 참조 명령 | `INSERT` | `INSERT` |
| 저장 장소 | **블록 테이블**(그 도면 안) | **도면 파일(.dwg)** |
| 이용 범위 | **저장된 도면에서만** | **모든 도면** |

**블록 색상·선종류를 어떻게 다룰지가 핵심이다.**

| 원하는 동작 | 블록 만들 때 |
| --- | --- |
| **원래 특성 유지** | `0` 이외의 도면층에서 작성, `ByBlock`·`ByLayer` 아닌 **명시적 색상** |
| **삽입한 도면층 특성 상속** | **도면층 `0` 에서 작성 + `ByLayer`** |
| 삽입 시 현재 특성 상속 | 도면층 `0` 에서 작성 + **`ByBlock`** |

**실무 기본은 두 번째다** — **`0` 레이어에서 `ByLayer` 로 만든다.**
그러면 어느 레이어에 넣든 그 레이어 색과 선종류를 따라간다.

**블록 이름은 최대 255자**, 블록 정의는 현재 도면에 저장된다. 기준점(삽입점) 기본값은 `(0,0,0)`.

**`INSERT` 에서 `분해` 를 체크하면** 블록이 아니라 개별 객체로 들어온다 —
이때 **도면층 `0` 에 그려진 구성요소는 `0` 에 남고**, `BYBLOCK` 색은 흰색, `BYBLOCK` 선종류는 `CONTINUOUS` 가 된다.

**DesignCenter** 로 다른 도면의 블록·도면층·문자 스타일을 **복사해 올 수 있다.**

## 이 장 정리

### 한 줄 요약

**3일차는 편집 명령으로 작업량을 줄이는 날이다.**
대칭으로 절반만 그리고, 배열로 반복을 없애고, 구성선으로 뷰를 정렬하고,
블록으로 같은 도형을 재사용한다. 그리고 그날 저녁 **LISP으로 레이어 전환까지 자동화했다.**

### 외워 둘 단축키

### 자주 틀리는 것

- `STRETCH` 를 왼쪽→오른쪽으로 선택한다 → **걸침이 아니면 이동만 된다**
- `OFFSET` 사본이 엉뚱한 레이어에 생긴다 → **`도면층(L)` 옵션**을 확인
- `FILLET` 반지름을 매번 다시 설정한다 → 뾰족하게만 할 거면 **`Shift`+선택**
- `DIVIDE`·`MEASURE` 했는데 아무것도 안 보인다 → **`DDPTYPE` 으로 점 스타일을 바꾼다**
- `ALL` 로 선택하고 지운다 → **끄기(OFF)된 도면층 객체도 같이 선택된다**
- 블록을 아무 레이어에서나 만든다 → **`0` 레이어 + `ByLayer`** 가 기본
- 배열을 비연관으로 만든다 → 나중에 개수를 못 바꾼다
- 구성선을 지우지 않고 남긴다 → **구성선 레이어를 끄면 된다.** 지울 필요 없다
