## 4-1. 치수의 구조와 기입 원칙

**치수는 복합 객체다.**

```plain text
치수(Dimension) = 치수선 + 치수보조선 + 치수문자 (+ 화살촉)
                  전체가 하나로 움직이는 "연관성(Associativity)"을 가진다
```

> **치수 객체를 분해(`EXPLODE`)하면 안 된다.**
> 연관성이 깨지고 **스타일 제어가 더 이상 안 된다.** 꼭 필요한 경우가 아니면 분해하지 않는다.

**교재의 한 문장이 핵심이다.**

> *"치수 기입은 단순하게 부품의 크기를 숫자로 표시하는 것이 아니다.
> 치수 기입은 **부품이 제작되는 순서와 가공 방법을 결정**하기 때문이다."*

그래서 치수를 넣기 전에 **가공 방법·조립 순서·동작 상태를 고려해 기준선을 먼저 정한다.**
가공·조립의 기준이 있으면 **그곳을 기준으로** 치수를 기입한다.

### 치수 기입 원칙 — 숫자로 외울 것

| 항목 | 값 |
| --- | --- |
| 치수선·치수보조선 | **가는 실선** |
| 화살표 크기 | **1 × 3 mm** |
| 치수보조선은 치수선을 지나 | **2~3 mm** 더 긋는다 |
| 치수보조선과 외형선 사이 | **1.5 mm 띄운다** (단, **중심선에서 끌어낼 때는 띄우지 않는다**) |
| 치수 문자 크기 | 3.15 ~ 6.3 mm — **주로 3.15 mm** |
| 치수 문자와 치수선 간격 | **1 mm** |
| 치수선과 치수선 사이 | **8 ~ 10 mm, 일정하게** |

**치수는 중복해서 기입하지 않는다.**

### 치수 5종 + 지시선

| 분류 | 명령 |
| --- | --- |
| 선형(Linear) | `DIMLINEAR` · `DIMALIGNED` · `DIMCONTINUE` · `DIMBASELINE` |
| 원형(Radial) | `DIMDIAMETER` · `DIMRADIUS` · `DIMJOGGED` |
| 각도(Angular) | `DIMANGULAR` |
| 세로좌표(Ordinate) | `DIMORDINATE` |
| 호 길이(Arc length) | `DIMARC` |
| 지시선(Leader) | `MLEADER` · `LEADER` |

## 4-2. 치수 스타일(DIMSTYLE)

**새 도면에는 `Standard` · `ISO-25` · `주석` 세 스타일이 기본으로 있고, 지정하지 않으면 `ISO-25` 가 적용된다.**

| 버튼 | 기능 |
| --- | --- |
| 현재로 설정 | 선택 스타일을 현재로 |
| 새로 만들기 | 새 스타일. **하위 스타일**도 여기서 |
| 수정 | **이 스타일을 쓰는 도면의 모든 치수가 자동 업데이트된다** |
| **재지정** | **임시 재지정.** 스타일 아래에 "저장되지 않은 변경"으로 표시 |
| 비교 | 두 스타일의 차이를 나열 |

**"수정"과 "재지정"의 차이가 중요하다.**

```plain text
수정   -> 스타일 자체를 바꾼다. 그 스타일 치수 전부가 바뀐다
재지정 -> 임시. 이후 새로 만드는 치수에만 적용. 원래 스타일은 그대로
```

**하위 스타일**은 "선형 치수만 다르게" 같은 경우에 쓴다 — 부모 스타일을 선택하고
`새로 만들기` → `사용` 리스트에서 **치수 유형**을 고른다.

| 명령 | 하는 일 |
| --- | --- |
| `DIMOVERRIDE` | 선택한 치수에 **시스템 변수 재지정**. 또는 재지정 지우기 |
| `DIM` / `UPDATE` | **현재 스타일을 기존 치수에 강제 적용** |

> **문자 스타일과 달리 치수 스타일은 바꿔도 자동 업데이트되지 않는 경우가 있다.**
> 그때 `UPDATE` 로 강제한다.

**주요 치수 변수**

| 변수 | 뜻 |
| --- | --- |
| `DIMTOFL` | 문자가 밖에 있어도 **치수보조선 사이에 치수선을 그릴지** |
| `DIMTOH` / `DIMTIX` | 문자를 **수평으로** / 치수보조선 **안쪽에** |
| `DIMCEN` | **중심 표식** 크기 |
| `DIMSCALE` | **전체 축척** (3일차까지 쓴 템플릿은 1.0) |
| `DIMDSEP` | **소수점 구분자** (1일차 쉼표 → 2일차 마침표) |

## 4-3. 선형 치수 계열

| 명령 | 단축키 | 용도 |
| --- | --- | --- |
| `DIMLINEAR` | `DIMLINEAR` | **수평·수직·회전** 치수 |
| `DIMALIGNED` | **`DIMALIGNED`** | **경사면**에 나란한 치수 |
| `DIMJOGLINE` | — | **꺾어진 선형** 치수 (긴 치수를 꺾어 표시) |
| `DIMORDINATE` | `DIMORDINATE` | **세로좌표** 치수 |
| `DIMCONTINUE` | `DIMCONTINUE` | **연속(체인)** 치수 |
| `DIMBASELINE` | `DIMBASELINE` | **기준선** 치수 |

### 공통 옵션

| 옵션 | 기능 |
| --- | --- |
| **여러줄 문자(M)** | 내부 문자 편집기. **머리말/꼬리말**을 측정값 앞뒤에 붙인다 |
| **문자(T)** | 측정값 대신 **새 문자를 직접 입력** |
| 각도(A) | 치수 문자의 각도 |
| 수평(H)/수직(V)/회전(R) | `DIMLINEAR` 전용 |

> **`문자(T)` 로 측정값을 덮어쓰면 연관이 깨진다.**
> 도형을 고쳐도 숫자가 안 바뀐다. **머리말/꼬리말이 필요하면 `여러줄 문자(M)` 를 쓰고
> 측정값은 `<>` 로 그대로 두는 쪽**이 안전하다.
> (1~3일차 도면에 `∅25.00` 같은 수동 입력이 보이는 것이 이 경우다.)

### 연속 치수와 기준선 치수

```plain text
연속(체인)   |--20--|--30--|--25--|      앞 치수의 끝에서 이어진다
기준선       |--20--|
             |-----50-----|              한 기준에서 전부 측정
             |--------75--------|
```

**기준선 치수가 가공 오차 누적에 유리하다** — 모두 같은 기준에서 재므로.
`DIMBASELINE` 의 간격은 `치수 스타일 > 선 탭 > 기준선 간격` 에서 바꾼다.

**세로좌표 치수(`DIMORDINATE`)는 데이텀(원점)에서의 거리만 표시한다** —
*"데이텀에서 피처까지 정확한 간격을 유지함으로써 **오류가 단계적으로 확대되는 것을 방지**"* 한다.
**`UCS` 로 원점을 먼저 재정의한 뒤** 기입한다.

## 4-4. 원호 치수 계열

| 명령 | 단축키 | 용도 |
| --- | --- | --- |
| 지름 | **`DIMDIA`** | ∅ 기호와 함께 |
| 반지름 | **`DIMRADIUS`** | R 기호와 함께 |

**`DIMJOGGED` 가 쓰이는 상황** — 반지름이 너무 커서 중심점이 도면 밖에 있을 때.
(3일차 도면의 `R140`, `R100` 같은 경우)

## 4-5. 신속 치수·중심표식·공차

| 명령 | 단축키 | 하는 일 |
| --- | --- | --- |
| `QDIM` | **`QDIM`** | **여러 치수를 한 번에** 작성/편집 |
| `DIMCENTER` | `DIMCENTER` | 중심 표식 / 중심선 |
| `TOLERANCE` | `TOLERANCE` | **기하공차** 피처 조정 프레임 |

**`QDIM` 이 시간을 가장 많이 줄여 준다** — 여러 객체를 한꺼번에 선택하고
**연속(C) / 다중(S) / 기준선(B) / 세로좌표(O) / 반지름(R) / 지름(D)** 중 하나를 고르면 일괄 기입된다.

**중심 표식은 치수선이 원/호 바깥에 있을 때만 자동 생성된다.** 크기는 `DIMCEN` 변수.

### 기하공차 14종

| 유형 | 기호 |
| --- | --- |
| **양식(형상)** | 평면도 · 진원도 · 직진도 · 원통도 |
| **방향** | 평행도 · 직각도 · 경사도 |
| **위치** | 위치도 · 동축도 · 대칭도 |
| **프로파일** | 면의 윤곽도 · 선의 윤곽도 |
| **런아웃** | 원주 흔들림 · 온 흔들림 |

피처 조정 프레임 구성: **기호 · 공차1 · 공차2 · 데이텀1 · 데이텀2 · 데이텀3 · 높이 · 투영된 공차영역 · 데이텀 식별자.**

## 4-6. 치수 편집

| 명령 | 단축키 | 하는 일 |
| --- | --- | --- |
| `DIMEDIT` | `DIMEDIT` | **홈(H)** / 새로만들기(N) / **회전(R)** / **기울기(O)** |
| `DIMTEDIT` | — | 치수 **문자 위치** — 왼쪽(L)/오른쪽(R)/중심(C)/홈(H)/각도(A) |
| `DIMSPACE` | `DIMSPACE` | 평행 치수선 **간격 균일화** |
| `DIMBREAK` | `DIMBREAK` | 치수선이 외형선과 **교차하는 곳을 끊는다** |
| 화살표 반전 | — | 그립 클릭 → 커서 메뉴 → **화살표 반전** |

**`DIMEDIT` 의 `기울기(O)` 는 등각투영 도면에서 필수다** — 치수보조선의 기울기 각도를 조정한다.
보통 **30 · 330 · 90도**로 설정한다.

**`DIMSPACE` 에 간격 `0` 을 주면 치수선들이 한 줄로 정렬된다.**
`자동(A)` 을 쓰면 **치수 문자 높이의 2배**로 자동 계산한다.

**`DIMBREAK` 는 치수가 설계의 일부처럼 보이는 것을 막는다** — 자동(A)으로 두면
교차 객체를 고칠 때 끊기도 같이 업데이트된다. **수동(M)은 업데이트되지 않는다.**

## 4-7. 지시선(MLEADER)

```plain text
지시선 = 화살촉 + 수평 연결선 + 지시선(직선/스플라인) + 여러줄 문자 또는 블록
```

| 명령 | 단축키 | 하는 일 |
| --- | --- | --- |
| **`MLEADERSTYLE`** | `MLEADERSTYLE` | **스타일부터 정의한다** |
| `MLEADER` | `MLEADER` | 다중 지시선 작성 |
| `MLEADEREDIT` | `MLEADEREDIT` | 지시선 추가/제거 |
| `MLEADERALIGN` | `MLEADERALIGN` | 여러 지시선 **정렬** |
| `MLEADERCOLLECT` | `MLEADERCOLLECT` | 블록 지시선들을 **하나로 수집** |
| `LEADER` | — | 구형 명령. **가급적 `MLEADER` 를 쓸 것** |

**스타일 탭 세 개** — 지시선 형식(유형·색상·화살촉) / 지시선 구조(구속조건·연결선·축척) / 내용(문자 또는 블록).

**화살촉 크기와 끊기 크기는 "치수 스타일에서 지정한 것과 같은 크기"로 맞추는 것이 좋다** (교재 권장).

**연관 치수 기입이 켜져 있고 객체 스냅을 쓰면** 화살촉이 객체에 연관된다 —
객체를 옮기면 **화살촉은 따라가고 지시선은 늘어나되 문자는 제자리에** 있다.

## 4-8. 도면 출력 — PLOT 과 CTB

### 프린터 vs 플로터

| | 프린터 | 플로터 |
| --- | --- | --- |
| 장점 | 간편·빠름 | **축척을 적용한 정밀 출력** |
| 용도 | **중간 검도용 체크 도면** | **최종 출도(Production Drawing)** |

**최종 출도는 플로터로, 흑백으로 출력한다** (교재).

| 명령 | 단축키 |
| --- | --- |
| 플로터 관리 | **`PLOTTERMANAGER`** |
| 출력 | **`PLOT`** |

**AutoCAD 기본 플로터는 전부 소프트웨어 출력이다** — 종이가 아니라 파일로 나간다.

| 플로터 | 결과 |
| --- | --- |
| `DWG To PDF.pc3` | **PDF** |
| `DWF6 ePlot.pc3` / `DWFx ePlot` | DWF / DWFx |
| `PublishToWeb JPG` / `PNG` | JPG / PNG |
| Default Windows System Printer | 윈도우 기본 |

### 플롯 영역 네 가지

| 옵션 | 범위 |
| --- | --- |
| **범위** | 객체가 있는 부분 전체 |
| **윈도우** | 두 점으로 지정한 영역 |
| **한계** | **`LIMITS` 로 설정한 영역** ← 2일차에 한계를 잡아 둔 이유 |
| 화면 표시 | 지금 화면에 보이는 것 |

**플롯 축척** — `용지에 맞춤` 또는 정확한 축척 지정. **`선가중치 축척`** 은 플롯 축척에 비례해 선 굵기도 줄일지.

### CTB — 색상 종속 플롯 스타일

**이것이 2일차 "선 굵기는 색으로 구분한다"의 마무리다.**

```plain text
CTB = Color-Dependent Plot Style Table
      색상 1~255 각각에 대해 "출력 색 / 스크리닝 / 선가중치"를 지정
```

| 기본 CTB | 효과 |
| --- | --- |
| `acad.ctb` | 기본 |
| **`monochrome.ctb`** | **모든 색을 검은색으로** |
| `grayscale.ctb` | 모든 색을 회색조로 |
| `screening 100/75/50/25%.ctb` | 잉크를 100/75/50/25% 사용 |

**편집기에서 조정할 세 가지 — `색상` · `스크리닝` · `선가중치`.**

```plain text
예) 빨강(1번)  -> 출력 색 검정, 선가중치 0.25mm  = 가는 선
    초록(3번)  -> 출력 색 검정, 선가중치 0.5mm   = 굵은 선
```

**2일차 템플릿의 레이어 색이 여기서 의미를 갖는다.**

| 레이어 | 색 | 출력에서 |
| --- | --- | --- |
| 외형선 | 3 (초록) | **굵은 선** |
| 중심선 | 1 (빨강) | 가는 선 |
| 숨은선 | 2 (노랑) | 가는 선 |
| 구성선 | 8 (회색) | 보통 **출력 안 함** |

**스크리닝은 색의 농도(100~0)다.** `색상1` 을 스크리닝 100으로 하면 빨간색,
1로 하면 흰색으로 출력된다 — 즉 **용지에 올리는 잉크 양**이다.

## 이 장 정리

### 한 줄 요약

**4일차는 "치수를 넣고 종이로 빼는" 날이다.**
치수는 분해하면 안 되는 복합 객체이고, 스타일로 통제하며, 측정값을 손으로 덮어쓰면 연관이 깨진다.
출력은 **CTB가 색상을 선 굵기로 바꿔 주는 구조** — 2일차의 레이어 색이 여기서 쓰인다.

### 숫자 한눈에 (KS 기입 원칙)

| 항목 | 값 |
| --- | --- |
| 화살표 | **1 × 3 mm** |
| 치수보조선 연장 | **2~3 mm** |
| 외형선과 띄우기 | **1.5 mm** (중심선에서는 안 띄움) |
| 치수 문자 | **3.15 mm** (범위 3.15~6.3) |
| 문자-치수선 간격 | **1 mm** |
| 치수선 간 간격 | **8~10 mm** |
| 기하공차 | **14종** |

### 외워 둘 명령

```plain text
선형    DIMLINEAR  DIMALIGNED(경사)  DIMCONTINUE(연속)  DIMBASELINE(기준선)
        DIMORDINATE(세로좌표)  DIMJOGLINE(꺾인 선형)
원호    DIMDIA  DIMRADIUS  DIMANG  DIMARC  DIMJOGGED
일괄    QDIM
편집    DIMEDIT  DIMTEDIT  DIMSPACE  DIMBREAK  DIMOVERRIDE  UPDATE
지시선  MLEADERSTYLE -> MLEADER -> MLEADEREDIT/ALIGN/COLLECT
출력    PLOT  PLOTTERMANAGER  + CTB(색상 -> 굵기)
```

### 자주 틀리는 것

- 치수를 `EXPLODE` 한다 → **연관성이 깨지고 스타일 제어가 안 된다**
- `문자(T)` 로 측정값을 덮어쓴다 → 도형을 고쳐도 **숫자가 안 바뀐다**
- 치수 스타일을 고쳤는데 기존 치수가 그대로다 → **`UPDATE`** 로 강제 적용
- `DIMORDINATE` 를 원점 설정 없이 쓴다 → **`UCS` 로 데이텀을 먼저** 잡는다
- 지시선을 `LEADER` 로 만든다 → **`MLEADER`** 를 쓴다
- 출력 색이 그대로 나온다 → **CTB** 를 `monochrome.ctb` 로 지정
- `LIMITS` 를 안 잡고 "한계" 플롯 영역을 고른다 → 출력할 영역이 없다
- 치수를 중복해서 기입한다 → **가공 기준이 흐려진다.** 한 치수는 한 번만
