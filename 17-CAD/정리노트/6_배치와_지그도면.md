# 6. 배치와 지그 도면 (5일차)

**과제**: `11_<이름>_5일차과제.dwg` (149,628 B) + 플롯 PDF
**템플릿**: `A2_3D.dwt` (93,776 B)
**교재**: 없음 (4일차까지만 배포됨)

> **5일차에 가장 큰 변화는 선가중치다**
> 1~4일차 도면은 레이어를 나눠 놓고도 **선가중치가 전부 기본값**이었다.
> 그걸 매번 "고칠 것"에 적었는데, **5일차 도면에서 실제로 지정됐다.**
>
> 그리고 도면이 "형상 + 치수"에서 **"형상 + 치수 + 공차 + 나사 규격"**으로 올라갔다.
> 과제명이 `<드릴지그59>`, 재질이 `SCM415` 다 — 실제 기계 부품 도면이다.
>
> 교재가 없어 이 노트는 **전부 도면 파일 실측**이다. 수업에서 다룬 범위와 다를 수 있다.

## 6-1. 선가중치가 들어왔다

**2일차 교재의 원칙은 "굵기는 색으로 구분하고 출력에서 CTB가 바꾼다"였다.**
그런데 레이어에 선가중치를 직접 주면 **화면에서도 굵기가 보인다**(`LWDISPLAY` 켤 때).
5일차 도면은 그쪽을 택했다.

| 레이어 | 선가중치 인덱스 | 환산 | 제도상 역할 |
| --- | --- | --- | --- |
| **윤곽선** | **14** | **0.70 mm** | 도면 테두리 — 가장 굵게 |
| **외형선** | **11** | **0.50 mm** | 보이는 모서리 — 굵은 선 |
| **숨은선** | 9 | 0.35 mm | 파선 |
| **보조선** | 7 | 0.25 mm | |
| **가는실선** | 6 | 0.20 mm | 치수선·해칭 |
| 중심선 · 가상선 · 구성선 · 0 | 31 | 기본값 | 아직 미지정 |

**가는실선 0.20 과 외형선 0.50 의 비가 1 : 2.5 다.**
2일차 교재의 `가는 : 굵은 : 아주굵은 = 1 : 2 : 4` 와 대체로 맞는다
(정확히 1:2 면 0.40, 1:4 면 0.80).

> **인덱스→mm 는 AutoCAD 선가중치 표 기준으로 환산한 값이다.**
> 파일에는 정수 인덱스만 들어 있다. 실제 출력 굵기는 플롯 설정도 함께 봐야 한다.

**아직 중심선·가상선은 기본값이다.** 중심선은 가는 실선과 같은 굵기여야 하므로 6을 주면 된다.

## 6-2. 공차 표기 — 스택 문자

**이번 도면에서 처음 나온 표기다.**

```plain text
15{\H0.7x;\S+0.02^ 0;}      →  15  +0.02
                                     0

15{\H0.7x;\S 0^-0.02;}      →  15   0
                                   -0.02
```

**MTEXT 서식 코드 두 개가 겹쳐 있다.**

| 코드 | 뜻 |
| --- | --- |
| `{\H0.7x; … }` | 이 구간의 **문자 높이를 0.7배**로 (공차는 치수보다 작게) |
| `\S 위^아래;` | **스택(분수형) 표기.** `^` 가 위/아래 구분자 |
| `{ }` | 서식 적용 범위 |

**`^` 를 쓰면 가로선 없이 위아래로만 쌓인다.** (`/` 를 쓰면 분수선이 그려지고, `#` 를 쓰면 사선이 된다.)
치수공차는 선이 없어야 하므로 `^` 가 맞다.

**이게 "치수 문자를 손으로 고친 것"과는 다르다.**
측정값 `15` 는 그대로 두고 **접미사로 공차만 붙인 형태**다 —
`DIMLINEAR` 의 `여러줄 문자(M)` 옵션에서 `<>` 뒤에 붙이면 연관이 유지된다.

> 다만 파일에는 `<>` 없이 `15{...}` 로 들어 있는 항목도 있어,
> **일부는 측정값까지 직접 타이핑했을 가능성이 있다.** 도면을 열어 확인할 것.

## 6-3. 나사와 개수 표기

| 표기 | 읽는 법 |
| --- | --- |
| **`M12x1(2줄나사)`** | 미터 나사 호칭 12, **피치 1mm**, **2줄(2-start) 나사** |
| **`2-M4`** | **M4 나사 2개** |
| **`2-%%C4.5`** | **∅4.5 구멍 2개** (`%%C` 가 ∅ 제어코드) |
| `%%C8` · `%%C17` | ∅8 · ∅17 |

**`개수-치수` 형식이 기계제도의 관례다.** 같은 구멍이 여러 개면 하나에만 치수를 적고 앞에 개수를 쓴다.
`2-∅4.5` 는 "∅4.5 짜리가 2개"라는 뜻이지 "2에서 4.5까지"가 아니다.

**`%%C` 는 AutoCAD 제어코드다.**

| 제어코드 | 결과 |
| --- | --- |
| `%%C` | ∅ (지름) |
| `%%D` | ° (도) |
| `%%P` | ± (플러스마이너스) |

**2줄나사(`2줄나사`)가 눈에 띈다.** 한 바퀴에 피치의 2배만큼 진행하는 나사로,
빨리 조이거나 이송용으로 쓴다. 지그에서 클램프 축에 쓰는 경우가 많다.

## 6-4. `A2_3D.dwt` — 이름과 달리 3D가 아니다

**파일 이름에 `3D` 가 붙어 있지만 3D 객체가 하나도 없다.**

| 확인 항목 | 결과 |
| --- | --- |
| `3DSOLID` · `MESH` · `REGION` · `SURFACE` | **0개** |
| Z좌표가 0이 아닌 선 | **0개 / 384개** |
| **`VIEWPORT`** | **5개** |
| 배치(Layout) | **6개** |

**들어 있는 것은 3D가 아니라 배치(도면공간) 뷰포트다.**

```plain text
모형 공간(Model)     1:1 로 그린 실제 형상
      ↓  뷰포트가 창처럼 들여다본다
도면 공간(Paper)     A2 용지 + 윤곽선 + 표제란 + 뷰포트 5개
```

**뷰포트를 쓰면 한 장에 여러 뷰를 서로 다른 축척으로 배치할 수 있다** —
정면도는 1:1, 상세도는 2:1 같은 식이다. 4일차 교재 CH16의 "배치 뷰포트 및 축척"이 이것이다.

| 항목 | `A2.dwt` (2일차) | `A2_3D.dwt` (5일차) |
| --- | --- | --- |
| 크기 | 37,037 B | **93,776 B** |
| 모델 공간 객체 | 90 | 91 |
| **블록 내부 객체** | 4 | **457** |
| **뷰포트** | 없음 | **5개** |
| 누적 편집 | 1시간 34분 | 21분 |

**모델 공간 내용은 거의 같고(90 → 91) 블록·배치 쪽이 통째로 늘었다.**
2일차 템플릿에 **배치를 얹은 판**이라고 보면 된다.

| 항목 | 내용 | 수정안 |

## 이 장 정리

### 한 줄 요약

**형상·치수를 넘어 "제작에 필요한 정보"가 들어온 날이다.**
공차(스택 표기), 나사 호칭, 개수-치수 표기, 그리고 **드디어 선가중치**.

### 외워 둘 표기

```plain text
%%C      ∅ 지름          %%D   ° 도          %%P   ± 플러스마이너스
2-∅4.5   ∅4.5 구멍 2개
M12x1    미터나사 M12, 피치 1
\S 위^아래;   스택(공차) — ^ 는 선 없음, / 는 분수선, # 는 사선
{\H0.7x; }   그 구간 문자 높이 0.7배
```

### 숫자 한눈에

| 항목 | 값 |
| --- | --- |
| 과제명 / 재질 | 드릴지그59 / **SCM415** |
| 직접 그린 객체 | **572개** |
| 치수 | **72개** (선형 66 · 지름 4 · 반지름 1 · 각도 1) |
| 다중지시선 | **10개** |
| 레이어 | 13개 — **선가중치 5개 지정** |
| 윤곽선 / 외형선 굵기 | **0.70 / 0.50 mm** |
| 누적 편집 시간 | **8시간 14분** |

### 자주 틀리는 것

- 공차를 `\S` 없이 두 줄로 타이핑한다 → **한 줄 문자 두 개**가 되어 정렬이 깨진다
- 스택에 `/` 를 쓴다 → 치수공차에 **분수선이 그려진다.** `^` 를 쓴다
- `2-∅4.5` 를 "2~4.5"로 읽는다 → **개수-치수**다
- 측정값까지 손으로 타이핑한다 → 도형을 고쳐도 안 바뀐다. `<>` 를 남긴다
- 레이어만 나누고 선가중치를 안 준다 → 화면에서 외형선과 치수선이 구분되지 않는다
- 배치 템플릿을 3D 템플릿으로 착각한다 → **뷰포트는 2D 배치 도구**다
