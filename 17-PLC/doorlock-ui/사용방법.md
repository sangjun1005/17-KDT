# 손가락 인식 현관문 UI

`실행.cmd`를 더블클릭하고 브라우저에서 http://127.0.0.1:8765 를 엽니다.
화면이 먼저 열려 연결되지 않으면 서버 준비 후 새로고침합니다.

- 카메라 켜기 → 손가락 **3개, 1개, 5개, 2개** 순서로 입력합니다.
- 숫자마다 **1초 유지**하고, 입력 후 손을 **0.5초 이상** 화면 밖으로 빼 주세요.
- 문이 완전히 열리면 **5초 대기 후** 자동으로 닫히고 잠깁니다.
- 잘못 입력한 4자리 번호는 인증에 실패하며, 문을 열지 않습니다.
- 입력 칸 아래 **한 자리 지우기**로 마지막 숫자를, **전체 지우기**로 입력한 숫자를 모두 지울 수 있습니다. 인증 실패 표시 중에도 수정할 수 있으며, 문이 열리거나 닫히는 동안에는 삭제 버튼을 사용할 수 없습니다.
- **비밀번호 변경** → 현재 번호(최초 `3152`) → 새 번호 → 새 번호 확인 → 변경 저장. 새 번호는 0~5 숫자 네 자리이며 키보드로 설정합니다. 변경 창에서는 손동작 입력을 받지 않습니다.
- 변경한 번호는 현재 브라우저의 로컬 저장소에만 저장됩니다. 다른 브라우저/주소에는 적용되지 않으며, 사이트 데이터를 지우면 기본 번호 `3152`로 돌아갑니다. 시크릿 모드는 브라우저 종료 시 보존되지 않을 수 있습니다. 실제 보안용 저장 방식이 아니므로 다른 서비스의 비밀번호를 사용하지 마세요.
- 카메라를 끄고 다시 켜면 입력 중인 번호가 초기화됩니다.
- **열림 모션 시연**은 카메라 없이 애니메이션을 보는 별도 버튼입니다.
- 카메라를 사용하려면 기존 `gesture_doorlock.py`, 화상회의 등 다른 카메라 앱은 종료해 주세요.
- 카메라 미연결/권한 오류는 카메라 카드에 표시됩니다. 서버는 로컬 PC에서만 접근할 수 있습니다.
- 서버 종료: 실행 창에서 Ctrl+C. 서버가 종료되면 카메라도 해제됩니다.

원본 `../gesture_doorlock.py`는 수정하지 않았습니다. 동일한 손가락 판정 규칙과 입력 유지 시간을 사용하며,
키보드 자동 입력이나 USB/PLC 제어 대신 HTML 화면의 도어락에 연결합니다.
카메라 영상은 외부 서비스로 전송하거나 파일에 저장하지 않습니다.

이 화면은 **교육·발표용 시연**입니다. 손가락 개수는 본인 확인 수단이 아니며 실제 문을 제어하지 않습니다.
현재 PC에 설치된 Python 3.12, OpenCV, MediaPipe(0.10.14)의 기존 환경을 사용합니다.

테스트: `node test_logic.mjs` / `python -m unittest test_server.py`
