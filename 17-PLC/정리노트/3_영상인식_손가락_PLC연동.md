# 3. 영상인식 · 손가락 개수 · PLC 연동 (3일차)

**파일**: `gesture_doorlock.py` (5,837 B) · `day3last/day3last.xgwx` (5,901 B)
**교재**: 122~126쪽

> **이 과목의 도착점이다.** 웹캠이 손가락을 세고 → 그 숫자를 보내고 → PLC가 받아서 램프를 켠다.
> 교재 126쪽 제목이 그대로 *"인공지능을 이용한 영상인식 손가락 개수 만큼 램프동작"*이다.

```plain text
웹캠 ──▶ MediaPipe 손 랜드마크 ──▶ 손가락 개수 0~5
                                        │
                      ┌─────────────────┴─────────────────┐
                      ▼                                   ▼
            TINKERCAD 모드                           SERIAL 모드
       pyautogui로 시리얼 모니터에 타이핑        USB 시리얼로 아두이노에 전송
                      │                                   │
                      └─────────────────┬─────────────────┘
                                        ▼
                                  램프 / 도어락 동작
```

교재는 여기에 **PLC 경로를 하나 더** 둔다 — 124쪽 **LS PLC**, 125쪽 **미쯔비시 PLC**.
`day3last.xgwx`가 그 LS PLC 쪽 래더다.

## `gesture_doorlock.py` — 손가락을 세는 방법

소스 전문을 읽고 정리했다. **실행 결과 로그는 없다.**

### 설정값 (파일 상단)

| 상수 | 값 | 뜻 |
| --- | --- | --- |
| `MODE` | `"TINKERCAD"` | 팅커캐드 시리얼 모니터에 타이핑 / `"SERIAL"`이면 아두이노로 직접 |
| `SERIAL_PORT` | `"COM3"` | SERIAL 모드일 때 포트 |
| `BAUD` | `9600` | 통신 속도 |
| `CAMERA_INDEX` | `0` | 웹캠 번호 |
| **`HOLD_SEC`** | **`1.0`** | 같은 손동작을 **1초 유지**해야 입력된다 |
| **`RELEASE_SEC`** | **`0.5`** | 입력 후 손을 **0.5초 빼야** 다음 입력이 가능 |

### 손가락 세는 규칙 (`count_fingers`)

```plain text
엄지   왼손/오른손 라벨을 보고 끝점(4)과 그 아래 마디(3)의 x 좌표를 비교
         Right 이면  lm[4].x < lm[3].x  → 펴짐
         Left  이면  lm[4].x > lm[3].x  → 펴짐

나머지 4개   끝점이 두 번째 마디보다 "위"에 있으면 펴짐  (y 가 작으면 위)
         (8,6) 검지 · (12,10) 중지 · (16,14) 약지 · (20,18) 새끼
```

**엄지만 규칙이 다르다.** 엄지는 접어도 아래로 내려가지 않고 **옆으로 움직이기 때문에**
y가 아니라 **x를 비교**한다. 그리고 화면을 `cv2.flip(frame, 1)`로 좌우 반전해 보여주므로
**MediaPipe가 주는 손 라벨(Right/Left)을 기준**으로 부등호 방향을 뒤집는다.

> 이 두 줄이 이 프로그램에서 제일 잘 만든 부분이다. **"손가락 5개를 똑같이 처리하면 틀린다"**는
> 것을 알고 엄지만 따로 뺐다.

### 오입력을 막는 장치 — `armed` 플래그

```plain text
손가락 개수가 바뀌면          current, since = n, now      (유지 시간 초기화)
1초 넘게 같은 개수면         send_digit() 하고 armed = False
                              → 손을 빼기 전까지 더 안 보낸다
손이 사라지고 0.5초 지나면    armed = True                  (다시 입력 가능)
```

**영상 인식은 매 프레임 결과가 나온다.** 아무 장치 없이 보내면 1초에 수십 번 같은 숫자가 간다.
`HOLD_SEC`으로 **떨림을 걸러내고**, `armed`로 **한 번만 보낸다.**

이건 1장 **5절 타이머 회로(한시 동작)**와 **2절 자기 유지 회로**를 코드로 쓴 것과 같다 —
`HOLD_SEC`은 한시 동작, `armed`는 상태를 기억하는 자기 유지다.

### 화면에 그리는 것

| 요소 | 내용 |
| --- | --- |
| 진행 바 | 유지 시간 비율 `min(held/HOLD_SEC, 1.0)` — 폭 200 px, 보낼 수 있으면 초록 / 아니면 회색 |
| `Fingers: n` | 현재 인식된 개수 |
| `Sent! Remove hand` | 보낸 뒤 손을 빼라는 안내 (빨강) |
| `Entered:` | **최근 4개**만 남겨 표시 (`entered[-4:]`) — 도어락 비밀번호 4자리 |

**최근 4개만 남기는 것**에서 이게 **도어락**이라는 게 드러난다.

### MediaPipe 설정

`max_num_hands=1` · `min_detection_confidence=0.7` · `min_tracking_confidence=0.6`
→ 손은 **하나만** 본다. 두 손이 들어오면 첫 번째만 쓴다.

## `day3last.xgwx` — LS PLC 쪽 래더

XG5000 프로젝트 파일을 풀어 본 결과다.

| 항목 | 값 |
| --- | --- |
| 프로젝트 이름 | `day3last` |
| XG5000 파일 버전 | `4.82.1.0` |
| 태스크 | **스캔 프로그램** 1개 |
| 프로그램 | `NewProgram` 1개 (LD, 즉 래더) |
| 래더 본체 | base64 + bzip2 → **1,822 바이트** |

### 래더에서 꺼낼 수 있었던 것

```plain text
F0009B    MOV    D00100    M00000    P00021    P00023    END
```

| 디바이스 | LS XGT에서의 뜻 |
| --- | --- |
| **P00021 · P00023** | **P 영역 = 입출력.** 실제 입력 접점 또는 출력 램프 |
| **M00000** | **M 영역 = 내부 릴레이.** 프로그램 안에서만 쓰는 보조 접점 |
| **D00100** | **D 영역 = 데이터 레지스터.** **숫자를 담는 곳 — 손가락 개수가 들어갈 자리** |
| **MOV** | 값 전송 명령 |
| **F0009B** | F 영역 = 시스템 플래그 |
| **END** | 프로그램 끝 |

> **`MOV`와 `D00100`이 핵심이다.** 접점 on/off만 하는 회로라면 D 레지스터가 필요 없다.
> **숫자를 받아서 저장하는 구조**라는 뜻이고, 이게 손가락 개수를 받는 자리로 보인다.
> 그 값을 비교해 `P00021`·`P00023` 같은 출력을 켜면 "손가락 개수만큼 램프"가 된다.

**다만 회로 모양은 복원하지 못했다.** 아래 확인 필요를 보라.

## 확인 필요 / 주의

| 항목 | 내용 |
| --- | --- |
| **래더 회로도를 복원하지 못했다** | `.xgwx`의 래더는 **XG5000 전용 바이너리**(base64 + bzip2, 1,822 B)다. **디바이스 이름만** 꺼냈고 접점·코일 배치와 비교 조건은 **XG5000으로 열어야** 보인다. 화면 캡처를 남기면 노트에 넣을 수 있다 |
| **파이썬과 PLC가 아직 안 이어져 있다** | `gesture_doorlock.py`는 **팅커캐드/아두이노**로만 보낸다. PLC로 보내는 코드(예: LS 전용 프로토콜·MODBUS)는 폴더에 없다. 교재 124쪽이 그 부분인데 **글자 없는 화면 캡처**다 |
| **실행 결과가 없다** | 인식률·지연 같은 측정값이 없다. 전부 **소스에 적힌 설정값**이다 |
| **`a.xgwx`는 빈 프로젝트** | 래더 영역이 8바이트. 1·2일차 결과물이 아니다 |
| 파일 이름의 날짜 | `.xgwx` 안의 `FileLastWriteTime`이 **2026-07-20**으로 찍혀 있다. XG5000 템플릿의 값으로 보이며 실제 작업일(10-27)과 다르다 |
