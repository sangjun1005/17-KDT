# 1. 시퀀스 제어 기본 회로 (교재 10~27쪽)

> 교재가 이 묶음을 여는 **핵심 질문**: *"밤에만 자동으로 켜지는 조명은 어떻게 만들까?"*
> 답을 한 번에 주지 않고 **회로를 10단계로 쌓아 올린다.** 마지막 무접점 회로에 가서야
> 센서로 자동 동작하는 조명이 된다.

> **이 장은 교재 내용 정리다.** 쪽마다 회로도 그림이 중심이라 본문 글자는 많지 않고,
> 아래는 교재의 **제목·소제목·설명 문장**을 그대로 옮긴 것이다. 실습 결과값이 아니다.

## 교재가 말하는 학습 목표 (10쪽)

- 전자계전기와 플리커 계전기를 활용하여 **자기 유지 회로, 인터록 회로, 우선 회로**를 구성하고 작동 과정을 설명할 수 있다
- **타이머, 카운터, 온도 계전기**를 활용하여 제어 회로를 구성하고 작동 과정을 설명할 수 있다
- **전자접촉기** 회로를 구성하고 설명할 수 있다
- **전자개폐기** 회로와 다이오드·트랜지스터·IC 등을 활용한 **무접점 시퀀스 회로**를 구성하고 설명할 수 있다

## 10개 회로의 순서

```plain text
1 기초 논리 회로      AND / OR / NOT / NAND / NOR        <- 판단을 만든다
      |
2 자기 유지 회로      정지 우선 / 기동 우선               <- 기억을 만든다
      |
3 인터록 회로         서로 반대 동작 금지                 <- 금지를 만든다
      |
4 연동 제어 회로      선행 우선 / 후행 우선               <- 순서를 만든다
      |
5 타이머 동작 회로    한시 동작 / 일정 시간 동작          <- 시간을 만든다
      |
6 계수 제어 회로      일정 횟수                           <- 개수를 만든다
      |
7 온도 제어 회로      온도 계전기                         <- 바깥 조건을 읽는다
      |
8 전자 접촉기         큰 전류를 작은 신호로 끊는다
9 전자 개폐기         접촉기 + 과부하 보호
      |
10 무접점 제어 회로   NAND IC로 접점 없이                 <- 반도체로 바꾼다
```

**순서가 그냥 순서가 아니다.** 1~4는 **논리**, 5~6은 **시간과 수**, 7은 **외부 입력**,
8~9는 **힘(전력)**, 10은 **구현 방식의 교체**다. 뒤로 갈수록 추상에서 현물로 내려간다.

## 1 기초 논리 회로 (11~15쪽)

| 게이트 | 교재 설명 |
| --- | --- |
| **AND** | 11쪽 |
| **OR** | 12쪽 |
| **NOT** | 13쪽 |
| **NAND** | "**AND 게이트와 NOT 게이트를 직렬로 연결한 것**" |
| **NOR** | "**OR 게이트와 NOT 게이트를 직렬로 연결한 것**" |

**NAND·NOR를 "직렬 연결"로 설명한다는 점이 중요하다.** 진리표를 외우게 하지 않고
**앞에서 만든 회로를 이어 붙여** 새 회로를 만든다. 10번 무접점 회로에서
**NAND IC 하나로 전체를 구현**하는 데까지 이어진다.

## 2 자기 유지 회로 (16~17쪽)

| 종류 | 쪽 | 뜻 |
| --- | --- | --- |
| **정지 우선** 자기 유지 회로 | 16 | 기동과 정지가 동시에 들어오면 **정지가 이긴다** |
| **기동 우선** 자기 유지 회로 | 17 | 동시에 들어오면 **기동이 이긴다** |

> **자기 유지가 시퀀스 제어의 첫 번째 고비다.** 버튼에서 손을 떼도 동작이 유지되려면
> 출력이 자기 입력으로 되먹임되어야 한다. 여기서 **회로가 "상태"를 가지기 시작한다.**

**안전 쪽에서는 정지 우선이 기본이다.** 사람이 멈추라고 했는데 기동이 이기면 안 된다.
PM 정리 3장에서 FAT 필수 검사에 **비상정지·인터록**이 들어간 이유와 같은 생각이다.

## 3 인터록 회로 (18쪽)

> "**동시에 서로 반대되는 동작을 방지하기 위해 사용**"

정회전과 역회전이 동시에 걸리면 안 된다. 한쪽이 동작 중이면 **다른 쪽 회로를 끊어 둔다.**

## 4 연동 제어 회로 (19~20쪽)

| 종류 | 쪽 |
| --- | --- |
| **선행 동작 입력 우선** 회로 | 19 |
| **후행 동작 입력 우선** 회로 | 20 |

인터록이 "**둘 다 안 된다**"면, 연동은 "**순서를 정한다**"이다.
먼저 들어온 쪽을 살릴지, 나중에 들어온 쪽으로 바꿀지가 갈린다.

## 5 타이머 동작 회로 (21~22쪽)

| 종류 | 쪽 | 뜻 |
| --- | --- | --- |
| **한시 동작** 제어 회로 | 21 | 입력 후 **일정 시간이 지나야** 출력이 나온다 |
| **일정 시간 동작** 제어 회로 | 22 | 출력이 **일정 시간만** 유지되고 꺼진다 |

## 6 계수 제어 회로 (23쪽)

카운터로 **횟수**를 센다. 교재 소제목이 22쪽과 같은 "일정 시간 동작 제어 회로"로 적혀 있는데,
절 번호는 **6 계수 제어 회로**다 — **교재 소제목 오류로 보인다** (아래 확인 필요 참조).

## 7 온도 제어 회로 (24쪽)

온도 계전기를 써서 **바깥 물리량**을 접점 신호로 바꾼다.
여기서부터 회로가 **센서를 읽기 시작한다.**

## 8~9 전자 접촉기 · 전자 개폐기 (25~26쪽)

| | 역할 |
| --- | --- |
| **전자 접촉기** (MC) | 작은 제어 신호로 **큰 전류를 끊고 잇는다** |
| **전자 개폐기** | 접촉기 + **과부하 계전기(THR)** — 보호까지 포함 |

**제어 회로와 주 회로를 분리하는 지점이다.** 버튼이 모터 전류를 직접 받지 않는다.

## 10 무접점 제어 회로 (27쪽)

> "**NAND IC를 이용한 무접점 제어 회로의 예**"

접점(기계식 스위치) 없이 **반도체로** 같은 논리를 만든다.
1번에서 "NAND = AND + NOT"이라고 배운 것이 여기서 **실제 IC 한 개**가 된다.

| | 접점 방식 | 무접점 방식 |
| --- | --- | --- |
| 구성 | 계전기·접촉기 | 다이오드·트랜지스터·IC |
| 수명 | 접점이 닳는다 | 마모 없음 |
| 속도 | 느리다 | 빠르다 |

> **이 비교가 다음 장(NE555 기판)으로 이어진다.** 2장에서 직접 그린 기판에
> **NE555(IC)와 TIP120(트랜지스터)**이 올라가 있다 — 무접점 회로의 실물이다.

## 확인 필요 / 주의

| 항목 | 내용 |
| --- | --- |
| **교재 소제목 중복** | 22쪽(5절)과 23쪽(6절)의 소제목이 둘 다 "일정 시간 동작 제어 회로"로 되어 있다. 6절은 **계수(카운터)** 절이므로 소제목 오기로 보인다. 수업에서 확인 필요 |
| **회로도는 그림이라 옮기지 못했다** | 11~27쪽은 회로도 중심이다. 이 노트는 제목·설명 문장만 정리했고 **실제 결선은 교재를 봐야 한다** |
| **실습 결과가 없다** | 이 장에 적힌 것은 전부 **교재 기재 내용**이다. 내가 돌려 본 값이 아니다 |
| 쪽 번호 표기 | 교재 머리말의 절 번호가 쪽마다 "1 시퀀스 제어 기본 회로" / "5 시퀀스 제어 기본 회로"로 섞여 찍혀 있다 (13·17쪽). 내용과는 무관한 머리말 오류 |
