# PLC · 전기응용 — 전체 개요

**폴더**: `17-PLC`
**기간**: 2026-10-26 ~ (3일차 진행 중, 폴더 기준 10-27)
**교재**: `전기응용_PLC_김상식.pdf` — 126쪽 (저작권 때문에 저장소에는 올리지 않는다)
**도구**: XG5000 (LS ELECTRIC PLC 프로그래밍) · DIYLC (회로 기판 작도) · Python + OpenCV

> **이 과목은 "소프트웨어에서 하드웨어로 내려가는" 과목이다.**
> 지금까지의 과목은 데이터가 이미 파일로 있었다. 여기서는 **스위치를 누르면 실제로 램프가 켜진다.**
> 그리고 마지막 단계에서 다시 올라온다 — **웹캠이 손가락을 세고, 그 숫자를 PLC로 보내 램프를 켠다.**

## 교재 126쪽의 구조

| 쪽 | 묶음 | 내용 |

| 1~9 | **전자 부품 기초** | ATmega 핀 배열 · 저항/캐패시터/인덕터 표기값 · 트랜지스터 · DC 모터 원리 |
| **10~27** | **시퀀스 제어 기본 회로** | 논리 게이트 5종 · 자기 유지 · 인터록 · 연동 · 타이머 · 계수 · 온도 · 전자접촉기 · 전자개폐기 · 무접점 |
| 28~33 | C 반복문 | while · do~while · for |

| 49~68 | **서보·스텝 모터** | 서보 원리·볼륨/스위치/초음파 연동 · 스텝모터 구동 방식 |
| 69~73 | **모터 응용 3제** | 2축 태양광 추적기 · 3층 엘리베이터 · 9대 스마트 주차장 |
| 74~75 | FND | 2자리 온도 표시 (개별 / 다이나믹) |

| **122~126** | **영상인식 + PLC 연동** | OpenCV 손가락 인식 → **LS PLC / 미쯔비시 PLC로 값 전달 → 손가락 개수만큼 램프** |

**122~126쪽이 이 과목의 도착점이다.** 앞의 모든 것이 거기로 모인다 —
회로를 알아야 램프를 켜고, 시퀀스를 알아야 래더를 짜고, 파이썬을 알아야 손가락을 세고,
통신을 알아야 둘을 잇는다.

> **123~126쪽은 글자가 없고 화면 캡처만 있다.** 그래서 이 노트의 연동 부분은
> 교재 쪽 제목과 **내가 가진 실제 파일**(`gesture_doorlock.py`, `day3last.xgwx`)로 재구성했다.

## 확인 필요 / 주의

| 항목 | 내용 |
| --- | --- |
| **래더 내용을 전부 복원하지 못했다** | `.xgwx` 안의 래더는 base64 + bzip2로 압축된 **XG5000 전용 바이너리**다. 사용된 **디바이스 이름만** 꺼낼 수 있었다 (3장 참조). 회로 모양은 XG5000으로 열어야 보인다 |
| **`a.xgwx`는 빈 프로젝트** | 래더 영역이 8바이트다. 1·2일차 파일이 아니라 **새로 만들고 저장만 한 것**으로 보인다 |
| **1·2일차 파일이 없다** | `day3last`만 남아 있다. 앞 이틀 실습물이 덮어써졌는지 확인 필요 |
| **교재 123~126쪽은 이미지** | 연동 절차의 글 설명이 없다. 수업 화면 사진이 있으면 보강 가능 |
| **`plc 기판.diy`는 사실상 빈 파일** | 기판(Board) 2장만 있고 부품이 없다 |
| 강사 실명 | 교재 파일 이름에 들어 있다. 이 노트에서는 `<강사>`로 적었고 교재는 저장소에서 제외했다 |
