# 2. 회로 작도와 부품 (DIYLC)

**파일**: `NE555_사진재현.diy` (59,362 B) · `plc 기판.diy` (1,885 B)
**도구**: DIYLC — 만능기판(perfboard) 위에 부품과 구리 배선을 그려 보는 프로그램

> 파일 이름이 **"사진 재현"**이다. 수업에서 찍은 회로 사진을 보고
> **같은 기판을 다시 그려 본 과제**다. 회로도(schematic)가 아니라 **실제 배치도(layout)**라는 점이 다르다.

## `NE555_사진재현.diy`에 들어 있는 것 (실측)

파일을 열어 XML 요소를 센 결과다.

| 부품 종류 | 개수 | DIYLC 클래스 |
| --- | --- | --- |
| 만능기판 | **2** | `boards.PerfBoard` |
| 구리 배선 | **34** | `connectivity.CopperTrace` |
| 납땜 패드 | **17** | `connectivity.SolderPad` |
| 아일릿 | **4** | `connectivity.Eyelet` |
| DIP IC | 5개 요소 | `semiconductors.DIL__IC` |
| TO-220 트랜지스터 | 2개 요소 | `semiconductors.TransistorTO220` |
| 저항 | 3개 요소 | `passive.Resistor` |
| 세라믹 디스크 커패시터 | 2개 요소 | `passive.RadialCeramicDiskCapacitor` |
| 트리머 포텐쇼미터 | 1 | `passive.TrimmerPotentiometer` |
| LED | 1 | `semiconductors.LED` |
| 플라스틱 다이오드 | 1 | `semiconductors.DiodePlastic` |

> **요소 개수와 실제 부품 개수가 다를 수 있다.** DIYLC는 XML에 참조(reference)를 섞어 저장해서
> 같은 클래스가 여러 번 나타난다. **이름이 붙은 부품**은 아래 8개다.

### 이름이 붙은 부품

| 부호 | 값 | 종류 |
| --- | --- | --- |
| **IC1** | **NE555** | 8핀 DIP (`pinCount _8`, 핀 간격 0.1 in) |
| **Q1** | **TIP120** | TO-220 달링턴 트랜지스터 |
| R1 | — | 저항 |
| VR1 | — | 트리머 포텐쇼미터 (가변 저항) |
| C1 · C2 | — | 세라믹 디스크 커패시터 |
| D1 · D2 | — | 다이오드 / LED |

기판 규격은 **29 × 21** (구멍 간격 **0.1 in**), 배선은 두께 **0.8**로 그려져 있다.

## 이 조합이 무엇을 하는 회로인가

| 부품 | 역할 |
| --- | --- |
| **NE555** | 타이머 IC. 발진(깜빡임)이나 일정 시간 지연을 만든다 |
| **VR1** (가변 저항) | NE555의 **시간 상수를 손으로 조절**한다 |
| **C1 · C2** | NE555와 함께 시간 상수를 만든다 |
| **TIP120** | 달링턴 트랜지스터. **작은 신호로 큰 전류**(모터·램프)를 흘린다 |
| **D1 · D2** | 표시용 LED와 역기전력 보호 다이오드로 보인다 |

> **1장 10절 "무접점 제어 회로"의 실물이다.** 계전기 접점 대신
> **IC(NE555) + 트랜지스터(TIP120)**로 켜고 끈다. 1장에서 글로 배운 것이
> 여기서는 **납땜 위치까지 정해진 기판**이 된다.

그리고 교재 제목이 *"LED와 모터 제어 응용"*이다 — **TIP120이 그 "모터 제어"의 출력단**이다.
교재 37쪽 PWM, 38쪽 "모터 속도·방향 조절 배선도"로 이어진다.

## `plc 기판.diy`

**기판(Board) 2장만 있고 부품이 하나도 없다.** 1,885 B로 사실상 빈 파일이다.
작업을 시작만 하고 저장한 것으로 보인다.

## 왜 배치도를 따로 그리는가

| | 회로도 (schematic) | 배치도 (layout) |
| --- | --- | --- |
| 보여주는 것 | **무엇이 무엇과 연결되는가** | **어디에 어떻게 놓이는가** |
| 바뀌면 | 회로 동작이 바뀐다 | 동작은 같고 **만들기 쉬움·크기**가 바뀐다 |
| 여기서 | 교재 회로도 | `NE555_사진재현.diy` |

**같은 회로도라도 배치는 여러 가지다.** 배선 34개를 어디로 돌릴지는 사람이 정한다.
CAD 정리 6장의 **배치·지그 도면**과 같은 문제다 — 기능이 아니라 **놓는 방법**을 정하는 일.

## 확인 필요 / 주의

| 항목 | 내용 |
| --- | --- |
| **저항·커패시터 값이 비어 있다** | R1·VR1·C1·C2에 값이 입력되어 있지 않다. 값이 없으면 **발진 주기를 계산할 수 없다.** 사진을 보고 값을 채워 넣으면 노트에 주기까지 적을 수 있다 |
| **회로 동작은 추정이다** | 부품 구성(NE555 + VR + C + TIP120)으로 본 **일반적인 해석**이다. 실제 결선을 따라가 확인한 것이 아니다 |
| **원본 사진이 없다** | "사진 재현"인데 그 사진이 폴더에 없다. 비교 검증을 못 했다 |
| `autoSave.diy` | `NE555_사진재현.diy`와 크기가 같다(59,362 B). 자동 저장본이라 저장소에서 제외했다 |
