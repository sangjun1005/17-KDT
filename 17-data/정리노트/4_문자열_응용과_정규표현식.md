## 4-1. 바꾸기·분리·연결

```python
'hello, world'.replace('world', 'python')     # 'hello, python'

table = str.maketrans('aeiou', '12345')
'apple'.translate(table)                      # '1ppl2'
```

**`replace`는 문자열 단위, `translate`는 글자 단위다.** 여러 글자를 한 번에 1:1로 바꿀 때 `translate`가 빠르다.

### 분리와 연결은 짝이다

```python
text = 'apple pear grape pineapple orange'
text.split()                # ['apple', 'pear', 'grape', 'pineapple', 'orange']

text = 'apple, pear, grape'
text.split(', ')            # ['apple', 'pear', 'grape']

' '.join(['apple', 'pear', 'grape'])    # 'apple pear grape'
','.join(['apple', 'pear', 'grape'])    # 'apple,pear,grape'
```

**`join`은 구분자에 붙여 쓴다.** `['a','b'].join(',')`이 아니라 `','.join(['a','b'])`다. 순서가 거꾸로라 자주 틀린다.

`join`에 넣는 리스트는 **전부 문자열이어야 한다.** 숫자가 섞여 있으면 `TypeError`다.

```python
','.join(map(str, [1, 2, 3]))      # '1,2,3'
```

## 4-2. 대소문자와 공백 정리

```python
'python'.upper()     # 'PYTHON'
'PYTHON'.lower()     # 'python'
```

**문자열 비교 전에 `.lower()`로 맞추는 것이 관례다.**

```python
a = '   python   '

a.rstrip()    # '   python'    오른쪽만
a.lstrip()    # 'python   '    왼쪽만
a.strip()     # 'python'       양쪽
```

특정 문자도 지울 수 있다.

```python
a = ' ,. python z '

a.strip(', .')     # 'python z'
```

**인자에 준 글자들을 "집합"으로 보고, 양 끝에서 그 집합에 속하는 글자를 계속 지운다.** `', .'`은 쉼표·공백·마침표 세 글자를 뜻하지, `", ."` 이라는 문자열을 지우는 게 아니다.

## 4-3. 정렬과 채우기

```python
'python'.rjust(10)     # '    python'    오른쪽 정렬 (왼쪽을 공백으로)
'python'.ljust(10)     # 'python    '
'python'.center(10)    # '  python  '
```

```python
'35'.zfill(4)      # '0035'
'3.5'.zfill(6)     # '0003.5'
'035'.zfill(2)     # '035'    ← 이미 길면 그대로 둔다
```

**`zfill`은 자르지 않는다.** 길이가 부족할 때만 0을 채운다.

### 메서드 체이닝

```python
'python'.rjust(10).upper().strip()     # 'PYTHON'
```

왼쪽부터 차례로 적용된다. `rjust`로 공백을 붙였다가 `strip`으로 다시 떼었으니 결과는 대문자만 남는다. **체이닝은 순서에 따라 결과가 달라진다.**

## 4-4. 위치 찾기

```python
'apple pineapple'.find('a')      # 0      없으면 -1
'apple pineapple'.rfind('a')     # 10     오른쪽부터
'apple pineapple'.index('a')     # 0      없으면 ValueError
'apple pineapple'.rindex('a')    # 10
```

| | 없을 때 |
| --- | --- |
| `find` / `rfind` | `-1`을 돌려준다 |
| `index` / `rindex` | `ValueError`를 낸다 |

**있는지 없는지만 알고 싶으면 `in`이 가장 명확하다.**

```python
if 'a' in 'apple':
    ...
```

`find`의 결과를 `if pos:`로 검사하면 안 된다. **0번 위치에서 찾았을 때 `0`이 거짓이라 "못 찾았다"가 되어 버린다.** `if pos != -1:`로 써야 한다.

## 4-5. 서식 지정자와 format

### `%` 방식 (옛날 방식)

```python
'I am %s.' % 'james'              # 문자열
'I am %d years old.' % 27         # 정수
'확률 %f' % 72.4                   # 72.400000
'확률 %.1f' % 72.4                 # 72.4      소수점 1자리
'%10s' % 'python'                 # '    python'   오른쪽 정렬
'%-10s' % 'python'                # 'python    '   왼쪽 정렬
'Today is %d %s.' % (3, 'July')   # 여러 개는 튜플로
```

값이 여러 개일 때 **반드시 튜플로 묶어야** 한다. 괄호를 빼면 에러다.

### `format` 방식

```python
'hello {0}'.format('world')
'hello {0}{2}{1}'.format('100 ', 'python ', 'world ')    # 순서를 바꿀 수 있다
'hello, {a} {b}'.format(a='python', b='world')           # 이름으로
```

### f-string (지금 권장되는 방식)

```python
name, age = 'kwon', 27
f'I am {name}, {age} years old.'
f'{72.4:.1f}'        # '72.4'
f'{"python":>10}'    # '    python'
f'{3.14159:.2f}'     # '3.14'
```

| 방식 | 평가 |
| --- | --- |
| `%` | 옛 코드에 많다. 읽을 줄은 알아야 한다 |
| `.format()` | `%`보다 유연하다 |
| **f-string** | **파이썬 3.6+. 가장 짧고 빠르다. 새 코드는 이걸로** |

f-string 안에서도 `%`와 같은 서식을 쓸 수 있다. `f'{값:.2f}'`처럼 콜론 뒤에 붙인다.

## 4-6. 정규표현식

```python
import re

re.match('hello', 'hello, world')      # 문자열 '시작'이 패턴과 맞는지
re.search('world!$', 'hello, world!')  # 문자열 '어디든' 있는지
```

| 함수 | 하는 일 |
| --- | --- |
| `re.match` | **처음부터** 맞는지 |
| `re.search` | **어디든** 있는지 |
| `re.findall` | 맞는 것을 **전부** 리스트로 |
| `re.sub` | 바꾸기 |

**맞으면 Match 객체, 안 맞으면 `None`을 돌려준다.** 그래서 `if re.match(...):`로 바로 검사할 수 있다.

### 여러 후보 중 하나

```python
re.match('hello|world', 'hello')       # | 는 "또는"
```

### 범위와 반복

```python
re.match('[0-9]*', '1234')     # * 는 0개 이상 → 항상 매치된다
re.match('[0-9]+', '1234')     # + 는 1개 이상
re.match('[0-9]+', 'abcd')     # None
```

```python
re.match('a*b', 'b')       # 매치 — a가 0개여도 된다
re.match('a+b', 'b')       # None — a가 최소 1개 필요
re.match('a*b', 'aab')     # 매치
```

**`*`는 "없어도 된다"라서 거의 항상 매치된다.** 검사용으로는 `+`를 쓰는 게 보통 맞다.

| 기호 | 뜻 |
| --- | --- |
| `*` | 0개 이상 |
| `+` | 1개 이상 |
| `?` | 0개 또는 1개 |
| `.` | 아무 글자 1개 |
| `{n}` | 정확히 n개 |
| `{n,m}` | n개 이상 m개 이하 |

```python
re.match('abc?d', 'abd')        # 매치 — c가 없어도 된다
re.match('ab[0-9]?c', 'ab3c')   # 매치
re.match('ab.d', 'abxd')        # 매치 — . 은 아무 글자
re.match('h{3}', 'hhhello')     # 매치 — h가 정확히 3개
re.match('(hello){3}', 'hellohellohelloworld')   # 그룹도 반복할 수 있다
```

### 전화번호 검사

```python
re.match('[0-9]{3}-[0-9]{3,4}-[0-9]{4}', '010-3803-1620')   # 매치
re.match('[0-9]{3}-[0-9]{3,4}-[0-9]{4}', '010-3803-162')    # None
```

가운데 자리가 3~4자리라 `{3,4}`로 쓴다.

### 문자 범위

```python
re.match('[a-zA-Z0-9]+', 'hello1234')    # 영문+숫자
re.match('[A-Z0-9]+', 'hello1234')       # None — 소문자가 없다
re.match('[가-힣]+', '권상준')             # 한글
```

**`[가-힣]`이 한글 음절 전체 범위다.** 자모(`ㄱ`, `ㅏ`)는 따로 `[ㄱ-ㅎㅏ-ㅣ]`다.

### 제외와 시작 지정

```python
re.match('[^A-Z]+', 'Hello')     # None — 대문자로 시작해서 실패
re.match('[^A-Z]+', 'hello')     # 매치
re.search('^[A-Z]+', 'Hello')    # 매치 — ^ 는 "처음부터"
```

**`^`가 대괄호 **안**에 있으면 "제외", **밖**에 있으면 "문자열 시작"이다.** 같은 기호인데 뜻이 완전히 다르다.

| 위치 | 뜻 | 예 |
| --- | --- | --- |
| `[^...]` | 이 범위가 **아닌** 것 | `[^A-Z]` 대문자가 아닌 글자 |
| `^...` | 문자열의 **시작** | `^[A-Z]` 대문자로 시작 |
| `...$` | 문자열의 **끝** | `world!$` world!로 끝남 |

### 자주 쓰는 축약

| 축약 | 같은 뜻 |
| --- | --- |
| `\d` | `[0-9]` |
| `\D` | `[^0-9]` |
| `\w` | `[a-zA-Z0-9_]` |
| `\W` | `[^a-zA-Z0-9_]` |
| `\s` | 공백·탭·줄바꿈 |

### 전부 찾기

```python
re.findall('[0-9]', '1 2 fizz 4 fuzz 7 8')    # ['1', '2', '4', '7', '8']
```

`findall`은 Match 객체가 아니라 **문자열 리스트**를 돌려준다.

### 정규표현식을 쓸 때 주의

파이썬 문자열에서 `\`는 특수 문자라, 정규식과 충돌한다. **패턴 앞에 `r`을 붙이는 게 관례다.**

```python
re.match(r'\d{3}-\d{4}', '010-1234')     # r을 붙이면 역슬래시가 그대로 전달된다
```

## 이 장 정리

### 문자열 메서드 정리

| 목적 | 메서드 |
| --- | --- |
| 바꾸기 | `replace`, `translate` |
| 나누기 / 합치기 | `split` ↔ `join` |
| 대소문자 | `upper`, `lower` |
| 공백 제거 | `strip`, `lstrip`, `rstrip` |
| 정렬 | `rjust`, `ljust`, `center`, `zfill` |
| 찾기 | `find`(-1), `index`(에러), `in` |
| 서식 | f-string |

**문자열 메서드는 원본을 바꾸지 않는다.** 전부 새 문자열을 돌려주므로 결과를 받아야 한다.

```python
a = '  hi  '
a.strip()          # 결과를 버렸다. a는 그대로
a = a.strip()      # 이렇게 받아야 한다
```

리스트의 `sort()`, `append()`가 제자리에서 바꾸는 것과 정반대다. **문자열은 바뀌지 않는(immutable) 자료형**이기 때문이다.

### 자주 틀리는 것

- `join`의 순서를 거꾸로 쓴다 → `','.join(리스트)`
- `join`에 숫자 리스트를 넣는다 → `map(str, ...)`로 감싼다
- 문자열 메서드 결과를 받지 않는다 → 원본은 안 바뀐다
- `find` 결과를 `if pos:`로 검사한다 → 0번 위치를 놓친다. `if pos != -1:`
- `strip(', .')`이 그 문자열을 지운다고 생각한다 → **글자 집합**이다
- 정규식에서 `^`의 위치를 헷갈린다 → 대괄호 안이면 제외, 밖이면 시작
- 검사에 `*`를 쓴다 → 0개도 매치된다. `+`를 쓴다
- 정규식 패턴에 `r`을 안 붙인다 → 역슬래시가 먹힌다
