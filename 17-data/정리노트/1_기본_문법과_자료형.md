## 1-1. 첫 코드와 들여쓰기

```python
print("Hello, World!")
# Hello, World!
```

파이썬에서 **들여쓰기는 문법이다.** 다른 언어의 중괄호 자리를 공백이 대신한다.

```python
함수명 () :
    
```

노트북에는 이렇게 뼈대만 적어 둔 셀이 있다. 실행하면 당연히 에러가 난다. **구조를 눈으로 익히려고 적어 둔 것이지 실행용이 아니다.**

## 1-2. 숫자 계산과 형 변환

### 나눗셈이 세 가지다

```python
5 // 2    # 2      몫 (소수점 버림)
5 % 2     # 1      나머지
2 ** 10   # 1024   거듭제곱
10 / 4    # 2.5    일반 나눗셈 — 결과가 항상 float
```

**`/`는 나누어떨어져도 float을 준다.** `10 / 5`는 `2`가 아니라 `2.0`이다. 정수가 필요하면 `//`를 쓰거나 `int()`로 감싼다.

```python
float(10 // 3)   # 3.0   — 먼저 몫 3을 구하고 실수로 바꾼다
```

### 형 변환

```python
a = 3.3
int(a)          # 3      소수점 버림 (반올림이 아니다)

b = '10'
print(type(b))  # <class 'str'>
b = int(b)
print(type(b))  # <class 'int'>

float('5.3')    # 5.3    숫자처럼 생긴 문자열만 된다
```

| 함수 | 하는 일 | 주의 |
| --- | --- | --- |
| `int(x)` | 정수로 | 실수는 **버림**. `int(3.9)`는 3 |
| `float(x)` | 실수로 | `float('abc')`는 `ValueError` |
| `str(x)` | 문자열로 | |
| `type(x)` | 자료형 확인 | 디버깅의 첫걸음 |

### 연산 순서

```python
35 + 1 * 2      # 37   곱셈이 먼저
(35 + 1) * 2    # 72   괄호가 먼저
```

## 1-3. 변수와 입력

### 변수 이름 규칙

```
1. 영문자와 숫자를 쓸 수 있다
2. 대소문자를 구분한다          stand_alone / StandAlone / standAlone 은 전부 다른 변수
3. 숫자로 시작할 수 없다
4. _(언더바)로 시작할 수 있다
5. 특수문자(+, -, *, /, %)는 쓸 수 없다     stand-alone (X), stand alone (X)
6. 파이썬 키워드(if, for, while, def, class)는 쓸 수 없다
```

### 여러 변수를 한 번에

```python
x, y, z = 10, 20, 30      # 각각 다른 값
x = y = z = 10            # 전부 같은 값

x, y = 10, 20
x, y = y, x               # 값 교환 — 임시 변수가 필요 없다
print(x, y)               # 20 10
```

**`x, y = y, x`가 파이썬의 관용구다.** 오른쪽이 먼저 튜플 `(20, 10)`으로 묶인 뒤 왼쪽에 풀린다.

개수가 안 맞으면 에러다.

```python
x, y, z = 10, 20          # ValueError: not enough values to unpack
```

### 할당 연산자

```python
a = 10
a + 20
print(a)     # 10   ← 계산만 하고 버렸다

b = 10
b += 20      # b = b + 20 과 같다
print(b)     # 30
```

**`a + 20`은 값을 만들 뿐 `a`를 바꾸지 않는다.** 초보자가 가장 먼저 겪는 혼동이다.

### 입력 — `input()`은 항상 문자열을 준다

```python
a = int(input("첫 번째 숫자: "))
b = int(input("두 번째 숫자: "))
print(a + b)        # 30
```

`int()`를 빼면 `"10" + "20"` = `"1020"`이 된다.

### 여러 값을 한 줄에 받기

```python
a, b = input("문자열 두 개: ").split()          # 문자열 두 개
a, b = map(int, input("숫자 두 개: ").split())  # 정수 두 개
a, b, c = map(int, input().split())             # 세 개도 같은 방식
```

`split()`의 동작을 뜯어보면:

```python
"hello world".split()      # ['hello', 'world']   기본은 공백 기준
"10,20".split()            # ['10,20']            공백이 없어서 안 쪼개진다
"10,20".split(',')         # ['10', '20']         구분자를 직접 준다
```

`map(int, ...)`은 리스트의 모든 요소에 `int`를 적용한다.

```python
list(map(int, ["10", "20"]))   # [10, 20]
```

**주의 — 노트북에 실패 사례가 그대로 남아 있다.**
```python
a = 20
b = 30
c -= b          # NameError: name 'c' is not defined
```
`c -= b`는 `c = c - b`라서 **`c`가 이미 있어야 한다.** `+=`, `-=`는 새 변수를 만들 수 없다.
같은 노트북에 `del a` 뒤에 `a`를 쓰는 셀도 있는데 역시 `NameError`다. 지운 변수는 다시 만들어야 한다.

## 1-4. print의 sep와 end

```python
print(1, 2, 3)                 # 1 2 3        기본 구분자는 공백
print(1, 2, 3, sep=', ')       # 1, 2, 3
print(1920, 1080, sep='x')     # 1920x1080
print(1, 2, 3, sep='\n')       # 줄바꿈으로 구분
```

```python
print(1, end="")
print(2, end="")
print(3, end="")
# 123        ← 줄바꿈 없이 이어 붙는다
```

| 인자 | 기본값 | 역할 |
| --- | --- | --- |
| `sep` | `' '` | **값 사이**에 넣을 문자 |
| `end` | `'\n'` | **맨 끝**에 넣을 문자 |

둘을 같이 쓰면 형식을 자유롭게 만들 수 있다.

```python
year, month, day = 2000, 10, 5
hour, minute, second = 11, 43, 30

print(year, month, day, sep='/', end=' ')
print(hour, minute, second, sep=':')
# 2000/10/5 11:43:30
```

ISO 형식도 같은 방법이다.

```python
year, month, day, hour, minute, second = input().split()
print(year, month, day, sep='-', end='T')
print(hour, minute, second, sep=':')
# 1999-12-31T10:37:21
```

## 1-5. 불, 비교 연산자, 논리 연산자

```python
print(10 == 10)             # True
print(10 != 5)              # True
print("Python" == "python") # False   ← 대소문자를 구분한다
print(10 >= 10)             # True
```

### `==`와 `is`는 다르다

```python
print(1 == 1.0)       # True    값이 같은가
print(1 is 1.0)       # False   같은 객체인가
```

**`==`는 값을, `is`는 정체를 비교한다.** `1`(int)과 `1.0`(float)은 값이 같아도 다른 객체다.

`is`는 `None`, `True`, `False` 확인에만 쓴다. 숫자나 문자열에 쓰면 파이썬 3.8부터 `SyntaxWarning`이 뜬다.

```python
if x is None:       # 이렇게 쓴다
if x == 10:         # 값 비교는 == 로
```

### 논리 연산자

```python
print(True and False)   # False   둘 다 참이어야 참
print(True or False)    # True    하나만 참이면 참
print(not True)         # False   뒤집는다
```

우선순위는 **`not` → `and` → `or`** 순이다.

```python
not True and False or not False
# = (not True) and False or (not False)
# = False and False or True
# = False or True
# = True
```

헷갈리면 괄호를 쓰는 게 낫다.

### 범위 검사

```python
x = 15

if x > 0 and x < 20:    # 일반적인 방법
if 0 < x < 20:          # 파이썬만 되는 방법 — 이쪽이 읽기 쉽다
```

**연쇄 비교는 파이썬의 강점이다.** 다른 언어에서는 안 된다.

## 1-6. 문자열 만들기

```python
hello = "hello world"
hello = 'hello world'
hello = '''hello world'''
hello = """hello world"""
```

네 가지 다 같은 문자열이다. 따옴표 종류가 여러 개인 이유는 **안에 따옴표를 넣기 위해서**다.

```python
s = "Python isn't difficult."     # 큰따옴표 안에 작은따옴표
s = 'I said "hello world".'       # 작은따옴표 안에 큰따옴표
```

### 여러 줄 문자열

```python
hello = '''hello, world
안녕하세요.
Python입니다!'''
```

따옴표 세 개는 **줄바꿈을 그대로 담는다.**

**주의 — 노트북의 `SyntaxError` 실습**
```python
hello = 'hello
world'
# SyntaxError: unterminated string literal
```
따옴표 한 개짜리는 **한 줄을 넘을 수 없다.** 여러 줄이 필요하면 `'''`를 쓰거나 줄 끝에 `\`를 붙인다.

## 이 장 정리

### 자주 틀리는 것

- `a + 20`만 쓰고 `a`가 바뀌었다고 생각한다 → `a += 20`
- `input()`의 결과를 `int()`로 안 감싼다 → 문자열 덧셈이 된다
- `c -= b`로 새 변수를 만들려고 한다 → `NameError`
- `/`가 float을 준다는 걸 잊는다 → 정수가 필요하면 `//`
- `int(3.9)`를 4로 생각한다 → **버림**이라 3이다
- `is`를 값 비교에 쓴다 → `==`
- 따옴표 하나로 여러 줄을 쓰려 한다 → `'''`
- 대소문자를 무시하고 문자열을 비교한다 → `.lower()`로 맞춘 뒤 비교

### 입력 관용구 세 줄

```python
n = int(input())                          # 숫자 하나
a, b = map(int, input().split())          # 숫자 여러 개
words = input().split()                   # 문자열 여러 개
```

이 세 줄이면 코딩 테스트 입력의 대부분을 처리한다.
