# 파이썬 기초 정리 — 전체 개요

`17-KDT/17-data` 폴더의 수업 노트북 26개를 5개 장으로 묶어 정리한 문서입니다.
교재는 **파이썬 코딩 도장**이고, 파일명의 앞자리 번호가 교재의 유닛 번호와 같습니다.

---

## 노트북 → 장 대응

| 장 | 노트북 | 핵심 주제 |
| --- | --- | --- |
| 1. 기본 문법과 자료형 | `04`~`09` (6개) | 숫자 계산, 변수·입력, print, 비교·논리 연산, 문자열 |
| 2. 시퀀스 — 리스트·튜플·딕셔너리 | `10`, `11`, `12`, `22`, `23`, `assignment` | 인덱스·슬라이스, 리스트 메서드, 얕은 복사, 2차원 리스트, 딕셔너리 |
| 3. 조건문과 반복문 | `13`~`20` (8개) | if/elif/else, for, while, break/continue, 별 찍기, FizzBuzz |
| 4. 문자열 응용과 정규표현식 | `24`, `43` | split·join, 서식, f-string, 정규표현식 |
| 5. 클래스·예외처리·모듈 | `35`, `36`, `38`, `44` | 클래스/인스턴스 속성, 상속, try-except, import |

교재 유닛 번호가 21·25~34·37·39~42로 건너뛰는 구간은 노트북이 없습니다.

> **장 번호가 파일명 앞자리와 다릅니다.** 다른 과목은 파일명 앞자리를 챕터 번호로 쓰지만, 이 폴더는 유닛이 26개라 그대로 두면 챕터가 너무 잘게 쪼개집니다. **주제 단위로 묶고 위 표에 대응을 적어 두는 방식**으로 정리했습니다.

## 과정 전체에서 계속 쓰는 것

| 개념 | 나온 곳 | 나중에 쓰이는 곳 |
| --- | --- | --- |
| 리스트 표현식 `[f(x) for x in ...]` | 2-6 | 판다스 전처리, 데이터셋 만들기 |
| `enumerate` | 2-4 | 학습 루프에서 배치 번호 |
| 얕은 복사 문제 | 2-5 | 넘파이·판다스의 view/copy 경고 |
| `dict(zip(keys, values))` | 2-8 | 라벨 매핑, `class_to_idx` |
| 2차원 리스트 경계 검사 | 2-7 | 이미지 필터, 합성곱 |
| f-string 서식 | 4-5 | 학습 로그 출력 |
| 클래스와 `__init__` | 5-1 | `Dataset`, `nn.Module` |
| 상속과 `super().__init__()` | 5-4 | 파이토치 모델 정의의 첫 줄 |
| `try-except` | 5-5 | 파일 입출력, API 호출 |

**5-4의 `super().__init__()`은 나중에 파이토치 모델을 만들 때 매번 쓰게 됩니다.**

```python
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()        # ← 5장에서 배운 그것
```

## 노트북에서 발견한 버그 (원본은 수정하지 않음)

실행 출력과 코드를 대조해 확인한 것만 적었습니다.

| 파일 | 내용 | 영향 |
| --- | --- | --- |
| `17_while문` | `int(input(...))` 결과를 `count`에 대입하지 않고 `while i < count` 사용 | 주피터에서 앞 셀의 옛 `count`로 조용히 돈다 |
| `20_FizzBuzz` | 축약 버전에서 `'buzz' * (i % 3 == 0)` — 앞쪽이 `'fizz'`여야 함 | 3의 배수에서도 `buzz`가 찍힌다 |
| `assignment` | 딕셔너리를 `items()`로 순회하면서 `del` | `RuntimeError: dictionary changed size during iteration` |
| `assignment` | `values = map(...)` 를 `if values != 30`으로 비교 | map 객체라 항상 참. 조건이 무의미 |
| `16_for반복문` | `for x in x:` — 반복 변수와 리스트 이름이 같음 | 루프 후 `x`가 리스트가 아닌 마지막 값이 된다 |

### 참고 (실습 목적의 의도적 에러로 보이는 것)

| 파일 | 내용 |
| --- | --- |
| `06_변수와입력` | `c -= b` (c 미정의) → `NameError`. `+=`로 새 변수를 못 만든다는 걸 보여 주는 셀 |
| `09_문자열사용하기` | 따옴표 하나로 두 줄 → `SyntaxError` |
| `12_딕셔너리사용하기` | 리스트를 키로 → `TypeError: unhashable type` |
| `13_if조건문` | 들여쓰기 어긋남 → `IndentationError` |
| `08_불과비교` | `1 is 1.0` — `is`를 값 비교에 쓰면 안 된다는 예시 (파이썬 3.8+에서 `SyntaxWarning`) |
