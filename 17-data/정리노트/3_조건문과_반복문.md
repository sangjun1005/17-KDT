## 3-1. if와 들여쓰기

```python
x = 10

if x == 10:
    print("10입니다")
```

**들여쓰기가 블록을 만든다.** 파이썬에는 중괄호가 없다.

```python
if x == 10:
    print('x에 들어가는 숫자는')
        print('10입니다')        # IndentationError: unexpected indent
```

같은 블록 안에서는 들여쓰기 칸수가 같아야 한다.

```python
if x == 10:
    print('x에 들어가는 숫자는')

print('10입니다')        # 들여쓰기가 없으니 if와 무관하게 항상 실행된다
```

에러는 안 나지만 **동작이 달라진다.** 조건문 안에 넣었다고 생각한 줄이 밖에 있으면 찾기 어려운 버그가 된다.

### 내용을 비워 둘 때는 `pass`

```python
if x == 10:
    pass          # 아직 안 쓴 자리. 비워 두면 IndentationError
else:
    print("...")
```

### 중첩

```python
x = 15

if x > 10:
    print('10 이상')
    if x == 15:
        print('15입니다')
    if x == 20:
        print('20입니다')
```

바깥 조건이 거짓이면 안쪽은 아예 보지 않는다.

## 3-2. else — 참/거짓으로 취급되는 값

```python
x = 5

if x == 10:
    print('10입니다')
else:
    print('10이 아닙니다')
```

### 숫자와 문자열도 조건이 된다

```python
if 0:       # 거짓
if 1:       # 참
if 0x1f:    # 참 (31)
if 0b1000:  # 참 (8)
if 13.5:    # 참

if 'hello':  # 참
if ' ':      # 참 — 공백 한 칸도 내용이 있는 문자열이다
if '':       # 거짓
```

| 거짓으로 취급되는 것 | 나머지는 전부 참 |
| --- | --- |
| `0`, `0.0` | |
| `''` (빈 문자열) | `' '` (공백)은 **참** |
| `[]`, `()`, `{}` (빈 컨테이너) | |
| `None` | |
| `False` | |

**`' '`가 참인 것이 실수의 단골이다.** 사용자 입력을 검사할 때는 `if not text.strip():`처럼 공백을 지운 뒤 확인한다.

```python
if not 0:      # 참
if not None:   # 참
if not '':     # 참
```

### 조건을 여러 개 걸기

```python
x, y = 10, 20

if x == 10 and y == 20:
    print('통과')

written_test = 75
coding_test = True

if written_test >= 80 and coding_test == True:
    print('pass')
else:
    print('not pass')
```

`coding_test == True`는 `coding_test`라고만 써도 된다. 불 변수는 그대로 조건에 넣는 게 관례다.

## 3-3. elif

```python
x = 30

if x == 10:
    print('10')
elif x == 20:
    print('20')
else:
    print('10도 20도 아님')
```

**위에서부터 검사하다가 처음 참인 곳에서 멈춘다.** 그래서 순서가 중요하다.

### 자판기

```python
button = int(input())

if button == 1:
    print('coke')
elif button == 2:
    print('sprite')
elif button == 3:
    print('fanta')
else:
    print('error')
```

`else`를 두면 예상 못 한 입력도 안전하게 받는다.

### 구간 나누기

```python
x = int(input())

if 11 <= x <= 20:
    print('11-20')
elif 21 <= x <= 30:
    print('21-30')
else:
    print('해당 없음')
```

연쇄 비교(`11 <= x <= 20`)를 쓰면 구간이 눈에 바로 들어온다.

### 요금 계산

```python
x = int(input())    # 나이
y = 9000            # 정가

if 7 <= x <= 12:
    print(y - 650)
elif 13 <= x <= 18:
    print(y - 1050)
elif 19 <= x:
    print(y - 1250)
else:
    print('무료')
```

**구간이 겹치지 않는지, 빈 구간이 없는지 확인한다.** 여기서는 0~6세가 `else`(무료)로 떨어진다.

## 3-4. for

```python
for i in range(10):
    print(f'{i} hello world')

for i in range(5, 12):        # 5부터 11까지
for i in range(0, 10, 2):     # 0, 2, 4, 6, 8
for j in range(10, 0, -2):    # 10, 8, 6, 4, 2
```

### 거꾸로 도는 두 가지 방법

```python
for b in reversed(range(10)):   # 9, 8, ..., 0
for j in range(9, -1, -1):      # 같은 결과
```

`reversed()`가 읽기 쉽다.

### 시퀀스를 직접 돌기

```python
for i in [10, 20, 30, 40, 50]:
    print(i)

fruits = ('apple', 'orange', 'grape')
for fruit in fruits:
    print(fruit)

for letter in 'Python':
    print(letter, end=' ')       # P y t h o n

for letter in reversed('Python'):
    print(letter)                # n o h t y P
```

**인덱스가 필요 없으면 `range(len(a))` 대신 직접 돈다.** 파이썬에서는 이쪽이 정석이다.

**주의 — 반복 변수와 리스트 이름을 같게 쓴 코드가 있다.**
```python
x = [49, -17, 25, 102, 8, 62, 21]
for x in x:
    print(x * 10, end=' ')
```
동작은 하지만(반복 시작 시점에 원래 리스트를 잡아 둔다) 루프가 끝나면 `x`는 리스트가 아니라 **마지막 요소(21)** 가 된다. 뒤에서 `x`를 리스트로 쓰면 터진다. 이름을 나눈다.

### 구구단

```python
dan = int(input('단을 입력하세요 (2~9): '))

for num in range(1, 10):
    print(f'{dan} * {num} = {dan * num}')
```

## 3-5. while

```python
i = 0                    # 초기식
while i < 10:            # 조건식
    print('hello world')
    i += 1               # 변화식
```

**변화식을 빼먹으면 무한 루프다.** 주피터에서는 ■(정지) 버튼으로 멈춘다.

| | for | while |
| --- | --- | --- |
| 쓰는 때 | 횟수를 **안다** | 횟수를 **모른다** |
| 예 | 리스트 순회, 10번 반복 | 조건이 만족될 때까지 |

횟수를 아는데도 `while`을 쓰면 초기식·변화식을 직접 관리해야 해서 실수하기 쉽다.

```python
for _ in range(10):      # 변수를 안 쓸 때는 _ 를 관례로 쓴다
    print('hello world')
```

### 횟수를 모를 때

```python
import random

i = 0
while i != 3:                   # 3이 나올 때까지
    i = random.randint(1, 6)
    print(i)
```

`random.randint(1, 6)`은 **양쪽 끝을 포함**한다(1~6). `range(1, 6)`과 다르다.

### `while True` + `break`

```python
i = int(input())

while True:
    print(i)
    i = i - 1350
    if i < 0:
        break
```

**조건이 복잡할 때는 `while True`로 두고 안에서 `break`하는 게 더 읽기 쉽다.**

**주의 — 노트북에 `count`를 대입하지 않은 셀이 있다.**
```python
int(input('반복할 횟수 입력: '))    # ← 결과를 버렸다
i = 0
while i < count:                    # NameError (앞 셀에 count가 있으면 옛 값을 쓴다)
```
`count = int(input(...))`이어야 한다. **주피터에서는 앞 셀의 변수가 남아 있어서 더 위험하다.** 에러가 안 나고 옛날 값으로 조용히 돈다.

## 3-6. break와 continue

```python
# break — 반복문을 완전히 끝낸다
for i in range(10000):
    print(i)
    if i == 10:
        break

# continue — 이번 회차만 건너뛴다
for i in range(10):
    if i % 2 == 0:
        continue
    print(i)         # 1 3 5 7 9
```

### while에서 continue를 쓸 때

```python
i = 0
while i < 10:
    i += 1                # ← 증가를 먼저
    if i % 2 == 0:
        continue
    print(i)
```

**`i += 1`이 `continue`보다 뒤에 있으면 무한 루프가 된다.** for문과 달리 while문은 변화식이 자동으로 실행되지 않기 때문이다. while + continue를 쓸 때는 항상 이 순서를 확인한다.

### 끝자리가 3인 수 건너뛰기

```python
start, stop = map(int, input().split())

i = start
while True:
    if i == stop + 1:
        break
    if i % 10 == 3:
        i += 1
        continue
    print(i, end=" ")
    i += 1
```

`continue` 직전에 `i += 1`을 한 번 더 써 준 것이 위에서 말한 그 처리다.

## 3-7. 중첩 반복문 — 별 찍기

### 사각형

```python
for i in range(5):
    for j in range(5):
        print('*', end='')
    print()              # 안쪽 루프가 끝나면 줄바꿈
```

**바깥 루프 = 행, 안쪽 루프 = 열.** `print()` 한 줄이 줄바꿈을 담당한다.

### 직각삼각형

```python
for i in range(5):
    for j in range(5):
        if j <= i:
            print('*', end='')
    print()
```

`j <= i`가 조건이다. 0번 행은 1개, 1번 행은 2개… 로 늘어난다.

`for j in range(i + 1)`로 쓰면 if가 없어도 된다. 더 짧지만, 조건으로 쓰면 모양을 바꾸기 쉽다.

### 오른쪽 정렬 삼각형

```python
for i in range(5):
    for j in range(5):
        if j < i:
            print(' ', end='')
        else:
            print('*', end='')
    print()
```

공백과 별을 조건으로 나눈다.

### 피라미드

```python
height = int(input())

for i in range(height):
    for j in range(height - i):    # 공백
        print(' ', end='')
    for k in range(2 * i + 1):     # 별
        print('*', end='')
    print()
```

| 행 i | 공백 개수 | 별 개수 |
| --- | --- | --- |
| 0 | height | 1 |
| 1 | height−1 | 3 |
| 2 | height−2 | 5 |

**별이 `2i+1`개인 게 핵심이다.** 가운데 한 개를 기준으로 양쪽에 i개씩 늘어난다.

## 3-8. FizzBuzz

```python
for i in range(1, 101):
    if i % 3 == 0 and i % 5 == 0:
        print('FizzBuzz')
    elif i % 3 == 0:
        print('Fizz')
    elif i % 5 == 0:
        print('Buzz')
    else:
        print(i)
```

**공배수 조건을 맨 위에 둬야 한다.** 순서를 바꾸면 15가 `Fizz`로만 찍힌다. `elif`는 처음 참인 곳에서 멈추기 때문이다.

### 한 줄로 줄이기

```python
for i in range(1, 101):
    print('Fizz' * (i % 3 == 0) + 'Buzz' * (i % 5 == 0) or i)
```

어떻게 되는지 뜯어보면:

```
i = 15  →  'Fizz' * True + 'Buzz' * True  →  'FizzBuzz'   →  or 앞이 참이라 그대로
i = 3   →  'Fizz' * True + 'Buzz' * False →  'Fizz'
i = 1   →  'Fizz' * False + 'Buzz' * False →  ''          →  or 뒤의 i 가 나온다
```

**`True`가 `1`, `False`가 `0`으로 계산되는 성질**과 **`'' or i`가 `i`가 되는 성질**을 함께 쓴 것이다. 영리하지만 읽기는 어려우니, 짧게 쓰는 것 자체가 목적일 때만 쓴다.

**주의 — 이 축약형은 에러로 알려 주지 않는다.**
```python
print('fizz' * (i % 3 == 0) + 'buzz' * (i % 5 == 0) or i)
```
두 자리에 같은 문자열을 쓰면 **3의 배수에서도 뒤쪽 단어가 찍힌다.**
문법은 멀쩡하고 출력만 틀리니 **출력을 눈으로 확인하는 수밖에 없다.**
노트북에 남은 출력은 고치기 전의 것이다.

## 이 장 정리

### 흐름

```
if / elif / else    3-1~3    조건에 따라 갈라진다
   ↓
for                 3-4      횟수를 안다
while               3-5      횟수를 모른다
   ↓
break / continue    3-6      루프 중간에 빠져나가거나 건너뛴다
   ↓
중첩 반복           3-7      행과 열
   ↓
FizzBuzz            3-8      조건 순서가 결과를 바꾼다
```

### 자주 틀리는 것

- 들여쓰기를 잘못해 조건문 밖으로 나간다 → **에러가 안 나고 동작만 달라진다**
- `' '`(공백)을 거짓이라고 생각한다 → 참이다
- `elif` 순서를 잘못 둔다 → 좁은 조건을 위에
- while에서 변화식을 빼먹는다 → 무한 루프
- while + `continue`에서 증가를 뒤에 둔다 → 무한 루프
- `int(input())`의 결과를 변수에 안 담는다 → 주피터에서는 옛 값으로 조용히 돈다
- 반복 변수와 리스트 이름을 같게 쓴다 → 루프 후 변수가 바뀐다
- `random.randint(1, 6)`을 `range`처럼 5까지로 생각한다 → 6을 포함한다
- 중첩 반복에서 `print()` 위치를 잘못 둔다 → 줄바꿈이 어긋난다
